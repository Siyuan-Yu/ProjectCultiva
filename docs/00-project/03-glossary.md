# 术语表

> 状态：持续维护 | 最后更新：2026-07-29
>
> 规则：**代码标识符、配置表字段、文档用词必须与本表一致。**
> 新增概念时先来这里登记，再去写代码。这一条是长期可维护性的关键，也是交接时对方最需要的文件。

## 使用约定

- 代码：英文 PascalCase / camelCase，取本表 Code 列
- 配置表 ID：`小写下划线`，取本表 Code 列的 snake_case
- UI 与文档：中文，取本表 中文 列
- 禁止同义词混用（例如不要 Cultivation / Practice / Training 混着指同一件事）

## 核心概念

| 中文 | Code | 含义 | 备注 |
|---|---|---|---|
| 境界 | Realm | 角色修行的纵向阶段 | 全局进度主轴 |
| 小阶段 | RealmStage | 境界内的细分（初期/中期/后期/圆满） | |
| 突破 | Breakthrough | 从一个境界升到下一个 | 可失败 |
| 天劫 | Tribulation | 突破时的考验事件 | |
| 灵根 | SpiritRoot | 角色的先天五行亲和 | 决定功法适配 |
| 五行 | Element | 金木水火土 | 全局元素规则 |
| 生克 | ElementRelation | 五行相生相克关系 | |
| 功法 | Technique | 可修习的能力载体 | 分类见下 |
| 神通 | Skill | 战斗中可主动释放的能力 | |
| 词条 | Modifier | 附加在功法/装备上的可组合效果 | 构筑深度来源 |
| 灵气 | Qi | 修行消耗/环境资源 | 环境与角色两种含义需区分 |
| 修为 | CultivationPoint | 修行积累的进度值 | |
| 心境 | MindState | 影响修行效率与事件的心理状态 | |
| 心魔 | InnerDemon | 修行失败引发的负面状态/事件 | |
| 弟子 | Disciple | 受玩家管理的角色 | 仅宗门玩法适用 |
| 宗门 | Sect | 玩家经营的组织 | 仅宗门玩法适用 |
| 事件 | Event | 配置化的叙事/抉择单元 | |
| 抉择 | Choice | 事件中的玩家选项 | |
| 世界状态 | WorldLedger | 记录玩家历史抉择的全局状态表 | 差异化 1 的载体 |
| 传承 | Legacy | 角色死亡后传给下一代的内容 | |
| 秘境 | Realm**Zone** | 可探索的副本区域 | 注意与"境界"英文冲突，故用 Zone |
| 机制能力 | RealmAbility | 由大境界解锁、会改变实际操作规则的超凡能力 | 如飞行、灵力外放、护体 |
| 核心修士 | CoreCultivator | 可逐个养成、装备和战术控制的修士角色 | 长期目标上限约 30–50 人 |
| 凡人人口 | MortalPopulation | 按人口组、岗位和政策管理的普通居民 | 不逐个模拟完整角色 |
| 据点 | Settlement | 可探索、占领、建设和管理的战略节点 | 城镇、村庄、农田、矿区等 |
| 领地 | Territory | 玩家势力控制的一组据点及其人口、资源 | |
| 小队 | Party | 由少量核心修士组成的行动或战斗编组 | |
| 自动结算 | AutoResolve | 战力悬殊或玩家选择跳过时进行的战斗结果计算 | 结果必须可溯源 |
| 暂停即时 | RealTimeWithPause | 时间持续流逝，但玩家可暂停并下达指令的玩法结构 | 简称 RTwP |
| 业力 | Karma | 衡量杀戮与行为因果的长期状态 | 影响天谴、心魔、声望等 |
| 道心 | DaoHeart | 角色修行信念与稳定程度 | 与普通心境区分 |

## 时间与指令

| 中文 | Code | 含义 | 备注 |
|---|---|---|---|
| 时间刻 | Tick | 逻辑层最小时间单位 | 1 Tick = 15 游戏分钟，一日 96 Tick |
| 时段 | TimeOfDay | 清晨、上午、黄昏、深夜等表现层分段 | 仅用于 UI，逻辑层只认 Tick |
| 指令 | Order | 玩家下达给角色的意图 | 角色自动执行，可排队、插队、取消 |
| 指令队列 | OrderQueue | 单个角色待执行的指令序列 | 每个角色独立持有 |
| 行动 | Action | 指令被分解后的可执行单元 | 移动、采集、制作、修炼等 |
| 自动暂停 | AutoPause | 触发条件时把控制权交还玩家 | 触发规则见 21 号文档 |

## 义务与隐匿

| 中文 | Code | 含义 | 备注 |
|---|---|---|---|
| 每日配额 | DailyQuota | 监工下达的当日任务指标 | 由若干条目组成，有验收时限 |
| 监工 | Overseer | 下达配额并执行惩戒的管理者 | 后期对应宗门执事、上级势力 |
| 口粮 | Ration | 完成配额换取的官方食物 | 维持生存，对修炼无益 |
| 怀疑度 | Suspicion | 管理者对角色的在意程度 | 0–100，暗面行动的统一代价 |
| 私藏物 | Contraband | 未上报的私有物资 | 被搜出则没收 |
| 藏匿点 | Stash | 存放私藏物的地点 | 属性为容量与隐蔽度 |
| 掩护 | Cover | 指派角色引开靠近同伴的 NPC | 降低被保护者的怀疑度积累 |
| 秘密灵地 | HiddenQiSite | 营地外灵气浓度显著更高的地点 | 前期偷偷修炼的核心目标 |
