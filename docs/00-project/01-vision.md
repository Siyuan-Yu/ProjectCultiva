# 项目愿景

> 状态：概念框架 v0.5 | 最后更新：2026-07-31
> 当前处于**架构冻结阶段**：以 `33`／`32` 为契约完善设计；不进入编码与 Demo 功能扩展。

## 1. 一句话定位

一款以**修仙成长**为核心的 **2D 单机实时暂停式战略 RPG**。

它融合个人修仙 RPG、RTS 式的世界与战斗、领地经营、宗门经营、人物关系与江湖系统。玩家从凡人小人物开始，通过探索、关系、修炼和战斗获得会实际改变操作规则的超凡能力，逐步占领并经营领地，最终成长为拥有领地与宗门、能影响天下格局的修仙势力。

## 2. 核心体验

期望玩家能够这样描述游戏：

> “我不是把修为数字从一百练到一千；我突破以后真的会飞了，于是能越过山脉偷袭敌后，也能在战斗中从空中压制凡人军队。我靠这个能力打下第二个据点，才真正把三个流浪凡人发展成了一个宗门。”

另一个重要体验：

> “我杀死的不是随机路人，而是某位长老的弟子。动手前我知道他的关系网，动手后也真的迎来了报复。”

## 3. 设计承诺

1. **大境界必有玩法质变**：突破解锁真实操作和规则，不只是属性倍率。
2. **个人成长与势力扩张闭环**：领地供养修炼，修炼能力推动扩张。
3. **世界记住玩家行为**：关系、占领、杀戮与恩怨会产生延迟后果。
4. **修炼需要准备**：时间、地点、功法、资源和人际支持影响突破质量。
5. **规模扩大不增加等比例微操**：核心修士逐个培养；凡人真实存在于世界中，但模拟深度分层处理（**深度待确定**）。
6. **力量越大，限制越多**：世界不是正善魔恶二分；杀戮按情境判定；玩家会从被体系压迫者成长为体系一环，长期主题是改变体系还是维护体系。

## 4. 已确认的方向

| 项目 | 当前方向 |
|---|---|
| 玩家身份 | 从凡人小人物逐步成长为势力经营，不在开局直接扮演“宗门天意” |
| 战斗 | 2D；**直接在世界地图中进行，不切独立副本**；RTS 实时行动，可随时暂停下令；悬殊战斗可自动结算 |
| 世界 | 3 块大陆、约 30 座城市，下属村庄、荒村、资源点与野外区域；自由缩放、连续无缝的视觉切换 |
| 单位规模 | 修士逐个养成，长期目标上限约 30–50 人；凡人真实存在，分层模拟深度待确定 |
| 经营解锁 | 未取得领地前不显示城镇管理；取得第一据点后逐步解锁 |
| 核心差异 | 每个大境界带来机制层面的新能力，能力要同时进入战斗、跑图、探索或经营 |
| 时间 | 可暂停、可倍速；角色行动、修炼与领地产出共享时间轴；每天没有命令次数上限 |
| 世界事件 | 存在规模远大于玩家的正魔大战；前期玩家只是偏僻小势力，可暂时寄人篱下 |

## 5. 目标玩家

### 主要玩家

- 喜爱修仙题材并重视“修炼过程感”的玩家。
- 喜爱角色构筑、暂停即时战术和势力扩张的策略 RPG 玩家。
- 能接受一定系统学习成本，愿意观察长期因果与角色关系的玩家。

### 非主要玩家

- 追求高速即时动作和连招手感的玩家。
- 只想挂机看数值增长、不愿做策略取舍的玩家。
- 期待无缝 3D 开放世界和大量演出的玩家。

## 6. 成功标准

| 层级 | 标准 |
|---|---|
| 概念验证 | 纸面上能跑通“三人小队 → 取得村庄 → 借领地产出突破 → 用新能力夺取第二据点” |
| 最低成功 | 做出一个可连续游玩 60–90 分钟的垂直切片，境界机制、战斗和领地形成闭环 |
| 中期成功 | 一个区域内有多个势力、关系后果和至少两条不同扩张路线，玩家愿意重复游玩 |
| 商业成功 | `[待确认：是否计划 Steam 上线、目标愿望单与销量]` |

## 7. 当前最大风险

项目同时包含角色 RPG、即时暂停战术、世界模拟、领地经营、关系网络和修炼系统，完整目标接近中型策略游戏。最大风险不是“想法不够”，而是多个复杂系统同时展开导致长期无法形成可玩闭环。

控制方式：

- 第一阶段只做三名角色、一个村庄、两个可争夺据点和凡人→炼气的一次机制质变。
- 先用据点槽位或管理面板验证经营，不立即制作自由建造模拟。
- 先做少量关系与事件验证因果，不立即生成完整天下 NPC 网络。
- 先验证一种境界能力能否同时服务战斗与跑图，再扩展境界表。

## 8. 仍待确认

这些问题暂不阻塞概念整理，但会阻塞后续原型边界：

1. 每周可投入时间、是否商业化、希望何时出现第一个可玩版本。
2. 美术来源：自己制作、购买素材、AI 辅助或先用占位资源。
3. ~~战斗采用连续即时暂停，还是短回合/行动冷却式表现。~~ 已定：RTS 实时行动 + 随时暂停下令，且不切换独立副本。
4. 领地采用自由空间建造，还是据点槽位与政策面板。
5. 主线最终目标与胜利条件。
6. 炼气期具体解锁哪些能力（候选：灵气感知、灵力攻击、自然恢复增强、灵气护体）。
7. 肉身飞行解锁于金丹还是元婴。
8. 凡人的分层模拟深度，以及凡人军队的参战表现方式。
