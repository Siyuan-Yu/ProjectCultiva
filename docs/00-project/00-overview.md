# 修仙游戏策划案总览

> 状态：概念框架 v0.3 | 最后更新：2026-07-30
> **本页只放最高层大纲。** 任何细节都拆到独立文档，见第六节索引。

## 一、一句话定位

一款**从个人修仙逐步成长为势力经营**的 2D 单机策略 RPG。玩家从数名无家可归的凡人开始，通过探索、关系、修炼与战斗获得会实际改变操作规则的超凡能力，占领并经营村镇，招募有限数量的核心修士，最终扩张出自己的地盘与道统。

## 二、玩家身份的五个阶段

游戏不是"个人 RPG"与"宗门模拟"二选一，而是让玩家亲手经历从个人到组织的尺度跃迁。

| 阶段 | 身份 | 玩家在做什么 |
|---|---|---|
| 1 | 凡人劳役 | 直接控制两三名角色完成每日配额换取口粮，无修为、无居所、无自由 |
| 2 | 初入仙途 | 靠偷来的时间与私藏资源秘密修炼，踏入练气；仍以角色 RPG 为主 |
| 3 | 一地之主 | 取得第一个村落或洞府，解锁领地管理 |
| 4 | 修仙势力 | 控制多个据点，招募修士、经营人口、处理外交与战争 |
| 5 | 一方道统 | 争夺城镇、资源地与高阶洞天，参与世界格局 |

## 三、五个设计支柱

| 支柱 | 一句话 | 详细文档 |
|---|---|---|
| 1. 境界带来玩法质变 | 大境界解锁实际操作能力（飞行、外放、护体、化形、神识），不只是数值 | `20-systems/22-realms-and-abilities.md` |
| 2. 角色与领地互相供养 | 领地供养修炼，修炼能力推动扩张 | `20-systems/26-territory-management.md` |
| 3. 江湖关系产生真实后果 | 杀一个人会招来他师父的报复；关系可被利用也会反噬 | `20-systems/28-jianghu-relations.md` |
| 4. 修炼需要环境与准备 | 突破要挑时辰、地点、灵气、丹药、护法 | `20-systems/25-cultivation-and-breakthrough.md` |
| 5. 规模扩大不增加微操 | 凡人按群体管理，修士逐个养成 | `20-systems/27-characters-and-population.md` |

## 四、三层玩法结构

| 层 | 内容 | 详细文档 |

## 五、世界结构

大战略地图 + 分层据点：数十个主要城镇，各自下属村庄、农田、森林、矿区、渔村、秘境、灵地。不做无缝 3D 开放世界。详见 `20-systems/24-world-and-settlements.md`。

## 八、范围控制

完整概念的体量接近中型策略游戏，第一版不可能同时铺开。

**第一阶段只验证三件事：**

1. 境界机制是否真的改变操作——凡人 → 练气后，至少解锁一种同时影响战斗与跑图的能力。
2. 角色与领地是否形成闭环——三名角色取得一个村庄，村庄产出帮助修炼，修炼帮助夺取第二个据点。
3. 暂停即时战斗是否承载得住角色构筑——三人小队打两场有明显策略差异的战斗。

**第一阶段暂不展开：** 数十座城市的完整世界、30–50 名修士的后期管理、完整外交与大规模战争、全部境界与生产链、自由建造（先用据点槽位与政策面板验证）。

## 九、跨系统的未决问题

只列会同时影响多个系统的，各系统自己的问题写在各自文档里。

1. 战斗采用连续即时暂停，还是短回合／行动冷却？（影响 23、21）
2. 领地采用自由空间布局，还是据点槽位 + 政策面板？（影响 26、24）
3. 境界体系用传统命名，还是偏"斗气化翼"的自定义层级？（影响 22、25）
4. 主线最终目标：统一世界、最强道统、个人飞升，还是允许多种胜利方式？
5. 每周可投入时间、是否商业化、美术来源。（影响整体范围）
