# devlog 条目模板

> 用法：复制下面这段，粘到 `docs/40-process/42-devlog.md` 的**最上面**（倒序）。

```markdown
## YYYY-MM-DD — 一句话标题

**做了什么**
- 

**判断与理由**
- （为什么这么做，而不是另一种做法。这一节是未来的你最需要的）

**待解决（阻塞后续）**
- 

**下一步**
- 
```

## 写作要点

- "判断与理由"比"做了什么"更重要。代码本身能说明做了什么，但说不出为什么。
- 踩过的坑一定要写，包括失败的尝试。避免几个月后重复踩。
- 宁可一条两行，不要因为"这次改得少"而不写。
