# ADR 模板（架构决策记录）

> 用法：复制到 `docs/40-process/43-decisions/`，命名 `ADR-00XX-简短标题.md`，编号递增。
> 什么时候写 ADR：做了一个**以后想改会很贵**的决定时。例如引擎版本、存档格式、UI 方案、是否引入某插件、核心架构边界。
> 价值：几个月后的你（或接手的人）会问"当初为什么这么选"，这份文件就是答案。
