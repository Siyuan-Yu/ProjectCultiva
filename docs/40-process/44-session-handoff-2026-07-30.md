## 已确认的游戏方向

| 项 | 结论 |
|---|---|
| 玩家身份 | 从凡人小队 → 初入仙途 → 一地之主 → 修仙势力 → 一方道统 |
| 核心差异化 | 大境界解锁可操作的机制能力（飞行、外放、护体、化形、神识），不是纯数值 |
| 战斗 | 2D、暂停即时小队战术；悬殊时可自动结算；不做高速连招动作战 |
| 世界 | 战略节点地图；城镇下属村庄、农田、森林、矿区等；不做无缝 3D 开放世界 |
| 单位 | 凡人按人口组管理；修士逐个养成，长期上限约 30–50 人 |
| 经营解锁 | 没占领据点前不显示城镇管理界面 |
| 修炼 | 要挑时间、地点、灵气、准备；前期偏生存，后期偏养成 |
| 江湖 | 保留并深化关系后果：杀谁会招来谁的报复；关系也可被利用 |
| 时间 | 可暂停、可倍速；角色行动、修炼、领地产出共用同一时间轴 |
