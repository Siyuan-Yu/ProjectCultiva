## 已确认的游戏方向

| 项 | 结论 |
|---|---|
| 项目阶段 | **Demo v0.1 原型开发**；只做荒村垂直切片，不等待最终美术 |
| 定位 | 以修仙成长为核心的实时暂停式战略 RPG；融合个人 RPG、RTS 世界与战斗、领地经营、宗门经营、人物关系与江湖 |
| 玩家身份 | 从凡人小队 → 初入仙途 → 一地之主 → 修仙势力 → 一方道统 |
| 核心差异化 | 每个大境界必须带来机制层面的新能力，不是纯数值 |
| 战斗 | 2D；**直接在世界地图中进行，不切独立副本**；RTS 实时行动 + 随时暂停下令；悬殊时可自动结算 |
| 世界 | **3 块大陆 → 约 30 个城市区域 → 格子地图**；城市区域连续约 10 屏，大陆约 100 屏；出口由地图数据决定；小格子（角色 1 格／建筑多格）；不做 3D 开放世界 |
| 凡人 | **四层模拟**：修士高精度／关键 NPC 实体／势力战略／普通凡人群体统计；地图用代表性群体单位；不逐人模拟普通凡人 |
| 修士 | 逐个养成，长期上限约 30–50 人 |
| 经营解锁 | 没占领据点前不显示城镇管理界面 |
| 据点 | 可发展区域；占领=夺取控制核心，非杀光；斩首／瓦解／外交；夺权后可改时间表；可建洞府、生产、灵气、防御、学校；灵气来自地形／建筑／灵物／汇聚 |
| 人才 | 学校约每 2～3 月刷新候选（灵根／悟性／神识／性格／天赋 Tag）；可收弟子或任命管事；治理质量影响人才 |
| 修炼 | 修为达标只获得突破资格；玩家主动选地点、状态、时机并进入事件；小境界低风险，大境界改变生命层次；有异象、护法、势力介入与高境界渡劫 |
| 修炼节奏 | **约 40 分～1 小时入炼气**；开局→元婴约 60–100 小时；正常资质黄阶高级下炼气→筑基约 100 游戏天 |
| 江湖 | 关系后果真实；关系可被利用，并能影响宏观势力发展 |
| 时间 | 可暂停、2x、5x；暂定现实约 5～10 分钟 = 游戏一天；**每天没有命令次数上限** |
| 时间表 | 环世界式社会规则；劳役／外门／内门／长老／宗主不同；前期只可查看，后期可制定；Demo 可临时开放修改 |
| 角色控制 | 手动控制 + 自动跟随／按时间表；无命令默认待机；第一阶段无复杂自主 AI |
| 行为优先级 | 玩家命令 > 紧急事件 > 时间表 > 待机 |
| 主管愤怒 | 前期主要风险反馈；违规与被发现推高愤怒；目的是体现逐渐获得自由，不是单纯惩罚 |
| 前期身份 | 3 名因家贫被迫接受宗门底层劳役的感应境角色；拥有修仙潜质，但尚非真正修士 |
| 初始角色 | **半固定背景 + 玩家自定义**：家乡、身世标签、性格标签、天赋倾向、外貌；固定部分要真的产出剧情 |
| 前期体验 | **凡人觉醒约 40 分～1 小时入炼气**；随后**隐藏修士**（敛息藏修，不能立刻公开）；离开辖区高风险而非禁止 |
| 第一章草案 | 劳役→感应探索→NPC 机缘→多路线功法→秘密突破→隐藏修士→低级妖兽教学战→制度矛盾伏笔；人物地点事件可改 |
| 前期 NPC | 不只发任务，藏有可挖掘的经历与机缘（如砍柴人是失败修士，想传功法） |
| 第一卡点 | 宗门派驻的筑基初期管事弟子 |
| 境界名称 | 炼气、筑基、结晶、金丹、具灵、元婴、化神、悟道、羽化、登仙 |
| **感应境** | 三名核心角色的**开局默认状态**，且**只是一个境界，不是特殊视觉**：能感受天地灵气、基础吸收、进入正式修炼准备阶段；不能学正式功法、不能真正运转灵力、不能使用修士能力 |
| 普通凡人 | 世界中的大多数人不能感知灵气，与感应境角色存在本质区别 |
| **统一属性结构** | 玩家／NPC／凡人／修士／敌人**共用同一套属性**，区别只在开发程度；凡人也有神识、悟性、体魄 |
| 属性分类 | 肉身；灵魂（神识／悟性）；修仙（灵根／灵力／修为／境界）；社会（性格、背景、家乡、关系、声望、目标、欲望）；另有心境 |
| **神识** | 隐藏信息感知的真正来源（不是感应境）：社交洞察、探索感知、可控制的法宝／法术数量与上限、精神抗性；**不替代关系系统** |
| 悟性 | 学得更快、更易领悟；**不直接提升技能威力**，不替代熟练度 |
| 修为 vs 灵力 | 修为是成长资源（升境界），灵力是战斗资源（放技能）；两套系统不混用 |
| 炼气 | **正式进入修仙体系**，不是巨大跃迁：灵气池、战斗优先耗灵气、学功法、身体基础强化、基础灵力技能 |
| 功法门槛 | 多路线获得第一份功法（NPC／秘境／宗门／商人／事件）；首次成功运转后进入炼气 |
| **灵根** | 已与「属性亲和」合并为同一概念，用数值表示（如火灵根 15/30）；影响修炼速度、学习速度与威力；可跨属性学但效率低；基本固定，可被机缘提升 |
| 属性名单 | 火、金、土、木、雷、风、冰、毒；**不做传统五行相克**；「水」是否保留**待确定** |
| 功法定位 | 功法是成长核心，不是职业限制；角色原则上可以学习任何功法，灵根只影响效率；客观境界／身体／前置知识条件可存在 |
| 功法作用 | 影响修为获取、最大灵力、灵力恢复、灵力质量、续航与成长上限；功法决定如何修炼，不是技能列表 |
| 功法品阶 | 黄玄地天，代表完整程度与成长潜力；前期差距可有限，随境界提高逐渐放大 |
| 功法成长 | 大部分功法不可升级品阶，角色通过寻找和更换功法成长；少数特殊机缘功法可成长；掌握程度提升不等于品阶提升 |
| 功法／斗技 | 功法决定如何修炼，技能／斗技决定如何战斗；技能宜少而精 |
| **掌握程度** | 技能与功法有独立熟练档位：初学→入门→小成→大成→圆满→化境（命名待定）；受使用频率、时间、悟性、灵根适配影响 |
| 装备 | 降权；战力排序：境界 > 功法 > 斗技 > 角色属性 > 装备；不能靠装备跨境界碾压 |
| 灵气环境 | 自然地理浓度 + 属性环境；灵物不无限叠；阵法为宗门期高级系统 |
| 炼气变化 | 灵力资源、基础法术、灵力护体；伤害先经灵力防护，再伤肉身；具体基础技能待确定 |
| 筑基能力 | 控制外物与灵气：法器／法宝、灵气附武、驭器、远距离灵力攻击、驭器短飞 |
| 金丹能力 | 内丹、灵气外放／铠甲式护体、不同属性内丹风格；**真正飞行（方向倾向金丹，仍待最终确认）** |
| 元婴能力 | 灵魂出窍、神魂战斗、第二生命机会、神识压制低阶；出窍有风险 |
| 化神能力 | 神识领域（讨论中）；分神／化身方向仍保留 |
| 悟道能力 | 规则力量／道域；空间虫洞方向此前已讨论 |
| 羽化能力 | 可能涉及空间通道；与悟道空间权限边界**待确定** |
| 飞行／踏空 | 飞行＝空中移动能力；踏空＝改变移动规则（停留、自由转向）；踏空归属**待确定** |
| 战斗规模 | **小队级修士战斗**；不做数千人实时微操；大战用算法／战报表现 |
| 技能栏 | 可学很多技能，战斗最多装备 **6** 个；快捷键 1–6 |
| 技能释放 | 手动／半自动／自动三种模式；AI 细则待设计 |
| 普通攻击 | 随境界改变方式：凡人近战 → 炼气灵力强化 → 筑基附灵／远程 → 更高境界扩大范围 |
| 战斗资源 | 生命（归零＝重伤非即死）；灵力；灵力护盾→肉身承伤顺序 |
| 重伤与击杀 | 默认不攻击重伤敌人；可求饶／威胁／交易；放过可触发感恩／复仇／关系事件 |
| 战利品 | 按敌人实际携带结算，不是无关随机掉落 |
| 领地灵气 | 占领为修炼优势；多据点灵气可汇聚到主洞府 |
| 正魔大战 | 世界存在远大于玩家的战事；前期玩家只是偏僻小势力，可寄人篱下 |
| 掀桌后 | 宗门派使者检查；可通过了解喜好、送礼与关系影响使者回报 |
| 天道因果 | 世界非正善魔恶二分；力量越大因果越重；杀戮按情境判定；玩家长期主题是改变体系还是成为新的维护者 |
