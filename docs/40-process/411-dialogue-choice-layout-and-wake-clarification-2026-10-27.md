# 411 — 多选项对话布局与苏醒规则澄清

状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人提供三张现场截图，明确对话选项需尽量完整显示；随后澄清“100秒后没站起来”若因超过半血才苏醒则不改。故本轮仅修改对话体验，不恢复100秒计时、不改身体／伤势／财物规则。

## 苏醒澄清（不改代码规则）

408／ADR-0067现行规则仍有效：普通昏迷与稳定后的弥留按真实恢复、严格超过50%最大HP清醒。25/93仍低于46.5，继续倒地符合规则；不存在现行100秒站起来承诺。初始约1%HP、治疗、伤势和410战败处置保持现状。本轮最初考虑恢复计时的计划被制作人最新澄清撤回，不实施。

## UI实施指令

- 根因：默认UGUI底栏固定720×168，右侧选项可视区约140高，而每项占54高；八项被塞成只露两三项的滚动长列。IMGUI回退也有相同固定高度问题。
- 参考[《鬼谷八荒》求饶界面截图](https://www.taptap.cn/moment/620396206392083040)的短决策标签、正文／决策分区思路，不复制其美术资产。
- 对话框根据当前选项数量、屏幕可用空间和正文长度自适应宽高；通常3～6个选项一屏展开。更多选项在足够宽的画面使用两列，只有超出安全屏幕高度时才滚动，页面切换回顶部，不保留旧滚动偏移。默认UGUI与IMGUI同步。
- 求饶主页面仅五类决策：直接放过、索物、索钱、拒绝求饶、暂不处置。具体物品／灵石品阶放二级页面，带明确返回；空钱包／无携带物是主入口的不可用说明，不铺三行零余额。二级选择仍走410原真实物资与事务校验，不新增发钱或赠物。
- 缩短求饶文案，去掉正文中的开发实现说明；仍清楚说明放过保留伤势。字号与按钮间距提高，按钮可换行。决策页无需等待长打字动画结束才能操作，其他剧情对话保留原打字机。
- 不启动Unity、不写／运行自动测试；只离线基础编译Core／Data／Unity／Unity.Editor、最少引用与diff检查，不改地图／Freeze／ProjectSettings／Packages，不提交推送。截图现场显示、缩放和实际点击交制作人人工验收。

## 实施与检查

HostDialogueController.DefeatedMercy主页面保留五项，物品和正余额灵石进入带返回的子页；无资产时入口禁用并说明，不改变DefeatedMercyService真实事务。UGUI默认最大宽1040、每行60含8间距，五项主页面高328（Canvas参考坐标）；按正文完整内容估高，受屏幕可用高度限制。超过六项且宽度至少920时双列，超高才开放纵向滚动。字号为标题22／正文18／选项18，选项可换行；页面或布局切换停止惯性并回顶部，旧按钮销毁前先停用。求饶立即显示完整正文可选择，剧情打字机保留。IMGUI回退同步自适应与双列、换页回顶、文字换行。

Core／Data／Unity／Unity.Editor离线编译全部OK，git diff --check通过；本轮未修改Core苏醒、恢复、伤势、Snapshot或计时字段。未启动Unity、未写／运行自动测试，未提交／推送，内容0.0.46／v21不变。屏幕实际缩放、布局与点击仍待人工验收，不把编译通过等同体验通过。
