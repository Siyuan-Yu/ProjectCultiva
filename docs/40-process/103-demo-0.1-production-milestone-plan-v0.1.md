## 0. 完成标准（第一阶段 = Chapter 01 Playable Arc）

手操／自动化均可跑通：

```text
Day0 开局
→ 杂役任务
→ 自由安排三人
→ 探索发现机会
→ 秘密修炼
→ 第一次突破
（收束：隐藏＋权力伏笔，无战斗）
```

复用既有：Chapter／Quest／Event／StoryFlag／Location／Cultivation／Social／Schedule／RTS。  
**不新增大型系统。** Snapshot／Freeze／战斗硬停。
