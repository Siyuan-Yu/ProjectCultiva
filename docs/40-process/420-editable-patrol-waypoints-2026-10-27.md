# 可编辑城池巡视点实施

制作人批准的规则与边界见ADR-0071。范围：通用城池路线编辑、真实有序巡逻与短停留、主管随机点巡视、荒村初始8点、进度保存，以及与现有日程／惩戒／救护／暂停倍速的直接接线。

人工验收：新开局看荒村两班沿墙内8点循环且到点短停；主管只在巡视时间随机走点。占领后从工作→巡卫排班→巡视点编辑，在地图点选、调序、删除并保存，观察人员采用新路线；清空保存后不走旧工区，重新添加后恢复。暂停等待不减少、倍速加快；保存重载仍保留点位顺序、已清空状态与人物进度。敌方城池不得保存修改，非法／墙上点不得保存。战斗追赶及返床不能被旧路线接管。

状态：Design Confirmed，实施后补记；不启动Unity，不运行自动测试，不自动提交推送。

## 实施结果

Implemented / Producer Acceptance Pending。新增Core SettlementPatrolRoutes／SettlementPatrolRouteDriver及HostPatrolRouteEditor，NpcActivityDriver的Patrol／Inspect直接接真实路线；日程其它活动保持。沿既有Counter存路线与人物进度，Surface由本城CoreSurfaceId约束；默认仅荒村一次生成8点。旧地图版本仍0.0.47，Snapshot v21，不需要地图重发布，既有当前版本存档下一巡视时段可初始化默认路线。

UI入口：工作→巡卫排班→巡视点编辑。左键地图空地依次加点，右键结束添加，中键拖图、滚轮缩放；列表调序／删除／清空，保存前草稿不影响正在生效的路线。保存复验当前所有权、合法地面与点数；最大64点。清空保存后等待安排。人物显示真实前往／停留／受阻状态，不用“巡视”掩盖未设点。

等待以WorldTick推进，Drive每Tick只扣一次，移动不扣，读档保留当前位置目标及剩余等待。主管下一点由world.Random选择且排除刚离开的点，已选游标持久化；巡卫永不随机跳点。遇阻显示等待，8 Tick后重试，同一巡卫不跳过顺序。无行军任务的驻村小队仍保留成员关系；战斗、惩戒、救护和个人需求优先，切换活动清自己的巡视意图。
