# 350｜城镇墙体、石屋表现与 Chunk 地面接缝返修

> 2026-10-25。制作人现场反馈青石镇等城镇缺墙、石屋只有占地而没有可辨认墙面，并指出真实世界里规律的深绿色方格。本轮状态：**Implemented / Producer Acceptance Pending / 未提交推送**。沿用现有房屋普通／中型／高级及木／石建材、墙段、连续 Surface、道路和 Chunk 权威；不引入新玩法或 Snapshot 字段。

## 定位与实施边界

1. 固定的 108 处 Site 蓝图中，荒村和 27 处聚落有外墙摆放，青石镇与其余 79 处聚落没有。给缺墙蓝图配置石制外墙，沿用现有 `base:wall_segment_stone`，在道路入口留门洞；已有墙的蓝图不重复套墙。保留原有房屋、道路、Site 身份与实际行政范围。墙段沿用原有非逐格状态的语义，Host 改为每段／跨 Chunk 裁切后用平铺 Sprite 绘制，避免新增数万 GameObject。
2. 青石镇的 43 间中型石屋和 1 间高级石屋已经有真实 `room` 占地、房门及床位；当前 Host 却把石地板 Sprite 同时当成石墙使用，墙面与地面融为一体。为现有石墙和石屋围墙接一张独立的石砌纹理；木屋仍用荒村的木墙纹理。等级仍由现有建筑定义和实际尺寸表达，不把材质名称误当新功能。
3. 深绿色方格不是有意启用的 Debug 网格。截图线条 RGB 为 `(46,56,41)`，与正式相机背景色 `(0.18,0.22,0.16)` 换算到 8 bit 完全一致。根因是当前世界图缓存每格代表 **4 格真实地面**，而场景 Chunk 固定 **50×50 真实格**：旧场景代码用缓存格宽计算草地，`50/4=12.5` 取整为 12，只铺 **48 格**，每个 Chunk 末尾露出 2 格背景。现改按真实 50 格铺草地，粗采样缓存仅决定山林／水面覆盖色，并将覆盖矩形裁在 Chunk 边界；草地瓦片按实际 `grassStride` 跨度居中、边缘微量重叠。不改 Chunk 组织或导航。
4. 修改作者蓝图后用现有发布器重发正式运行地图和内容版本；仅做基础编译、必要的静态引用及文件完整性检查。Unity 外观、门洞通行和帧时由制作人人工验收。

## 落地与静态检查

缺墙的 80 份蓝图新增 **4,600 个**石墙短段，覆盖 **35,434 格**；其中青石镇新增 110 段／826 格。既有 28 份有墙蓝图没有重复摆放。现有 108 个固定 Site 在正式 `main_wilderness_surface_v1.json` 都有墙摆放，发布器输出 17,556 个蓝图对象、468 条道路；内容包版本升为 `0.0.21-town-walls-and-art`，旧档保留并需新开局。青石与其他 79 处的门洞根据邻近道路端点选位，缺少端点的一侧在中部留通道；未改道路导航与 Site 身份。石墙贴图保存在 Unity `Resources` 中，普通／中型／高级房屋仍复用既有房间与床位接线，木屋继续用旧木墙纹理，石屋及石城墙改用石砌纹理；铁制住房目前没有获确认的建筑定义，本轮没有增加。

新贴图 [ART-ROOM-012_stone_wall_solid_v01.png](../../Assets/Art/Environment/Resources/ART-ROOM-012_stone_wall_solid_v01.png) 由内置 ImageGen 根据项目原有木墙贴图编辑生成，提示词要点为：保留原图方形俯视墙砖、边缘透明与游戏质感，把木板替换成灰暖色交错石块、清楚的灰缝，不含建筑场景和文字。Core／Data 基础编译 0 警告、0 错误；复用 Unity 的编译参数单独编译 Host 0 错误；`git diff --check` 无空白错误。以上静态结果不代替 Unity 现场视觉与帧时验收。

## 人工验收

新开局进入青石镇，石墙与房间地板应能区分，房门和床位可见且可进入；沿主街从城外经门洞步行进出。观察连续行走跨越几道 Chunk 边界，草地不应露出深绿色方格。再走访一座此前无墙的小聚落和一座原本有墙的宗门主城，确认有墙但没有双层重叠，开 F9 留意跨界最慢帧。
