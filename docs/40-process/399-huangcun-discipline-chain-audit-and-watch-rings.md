# 荒村惩戒链路复核与巡视范围圈

状态：Implemented / Producer Acceptance Pending。沿用内容 0.0.46、Snapshot v20；本轮不改地图、内容版本或存档字段，可继续使用当前版本存档，未提交推送。

制作人明确主管压力也随倍速：1× 每五秒一点、20× 约每 0.25 现实秒一点，暂停不增加；保留 WorldTick 唯一推进和连续观察中断规则。要求复核发现违规、追赶、开战、战败昏迷、村民搬运与床位安置，并可视化巡视范围。

静态定位发现追赶 MovementIntent 可能被原巡逻、个人生活和凡人专职流程覆盖；本轮为已经开始的惩戒追赶提供明确的局部任务占用，取消原日程行动，追赶结束后释放。压力发现条件仍按 ADR-0065，不强制发现／战败或添加新手流程步骤。

巡视圈直接消费 Core 在岗资格和二十格半径，跟随真实人物脚下位置；在岗显示金色，正在追赶惩戒者显示红色。休班、休息、失能、解放后和独立战斗中隐藏；暂停保留静态范围显示，不推进规则。圈仅为 Host 表现，不是另一份侦测真源。

本轮不启动 Unity、不编写或运行自动测试；基础编译、必要静态接线核对和简短人工验收项记录如下，未提交推送。

## 本轮实际发现与修复

- 压力原本已逐 WorldTick 推进，Host 正常暂停时不执行 Tick、倍速决定 Tick 频率；保留这条唯一推进链，重复调用通过 LastObservationTick 去重。没有另加按帧或不受倍速影响的压力计时。
- 追赶满值时取消旧日程行动及其工位占用；NpcActivityDriver、ScheduleDriver、PersonalLifeService 和凡人普通活动不再抢写追赶目标。继续加载旧 v20 追赶存档时，也清理残留行动。案件结束／目标失能／巡查者失能或解放后释放占用，原日程可恢复。
- 追赶到旧目标点但玩家已经移开时重新追踪，避免 Host 已到达后仍停在旧点；对床上等目标共用现有“靠近人物”的空闲站位寻路，避免要求巡卫进入床的阻挡格。救护接近伤员仍走同一站位能力，实际床位安置保留严格入口与预约。
- 把正在执行救护的人员排除在新观察者之外，防止巡卫丢下正在搬运的伤员转去惩戒。正式荒村跳过旧抽象日终主管事件，日终劳动配额统计保留，惩戒只通过当前真实观察链触发。
- 已静态逐段核对怒气满值、PendingCharacterAttacker／Target、Host 正常战斗入口、惩戒不补刀、真实状态返回、跨势力劳役救护资格、医疗／住宅床选择、搬运预约与占床；这些均有现有正式调用，不用脚本瞬移或直接回血代替。

新增 HostPatrolWatchRings，并在 PlayableHostBootstrap 装配；只读取 Core IsOnWatch、ObservationRangeCells 和实际 Surface／EntityView 坐标。图形无碰撞、不接管输入，暂停保持显示；换场、换存档和卸载会清理，战场／世界地图／室内／解放后隐藏。

## 核对与人工查看

四程序集离线基础编译通过，新增脚本与 meta 完整、GUID 唯一；必要静态引用／文件检查和 git diff --check 通过。未启动 Unity，未运行自动测试；本轮未取得运行验收，不能据此宣称整条流程实玩已无问题。

1. 退出 Play 等脚本编译后继续当前存档或新开局，查看在岗人员脚下二十格金圈；休班／睡眠／失能时消失，追赶时变红，暂停只保留静态圈。
2. 在圈内持续违规，1× 五秒一点、20× 约 0.25 秒一点，暂停值不变；合规或离圈停止积累。圈内多个观察者不重复增加。
3. 满值后观察巡卫持续追踪移动玩家，包括原目标点已到达、玩家转到床上等情况；接近后只发起一场正常惩戒战斗，不被巡逻／吃饭／修炼改令打断。
4. 战败后确认一 HP 昏迷、原状态返回，村民接近搬运并优先放医床，满员再选住宅床；搬运途中存读档仍保留伤员、预约和剩余昏迷时长，醒来可恢复行动。观察案件结束后巡查者恢复正常作息。
