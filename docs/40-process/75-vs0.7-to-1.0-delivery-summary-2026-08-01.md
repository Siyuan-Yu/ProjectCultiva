## 3. 分层改动摘要

### Core（规则）

| 模块 | 内容 |
|---|---|
| Bootstrap | `SpawnEntityKind`；GameStart 支持 Character／Npc；`SpawnedByDefinitionId` |
| Settlement | `SettlementBoard`／库存／设施／`WorkRole`／日终生产；`AssignWork` |
| Exploration | `WorldRegionBoard`／`EntityLocation`／Travel／Explore |
| Input | `PlayerCommandKind`：AssignWork／Explore／Travel |
| Events | Stock／Work／Production／LocationChanged／LocationExplored（会话事件） |
| Entity whitelist | `WorkAssignmentComponent`、`EntityLocationComponent` |

**未入 Snapshot：** 关系、据点、分工、地点（避免升 schema）。

### Data（内容）

| 文件／类型 | 用途 |
|---|---|
| `characters.json` | personality／background／talent；村内可招者、采药童等 |
| `scenarios.json` | `openingScenario`：spawn／关系／settlement／worldRegion／workRole |
| `resources.json`／`facilities.json`／`settlements.json` | 资源、蒲团静室、青石洞府 |
| `world_regions.json` | 青石四地点邻接图＋表现坐标 |
| `cultivation.json` | 含木语心法样例 |
| SCHEMA | [Content/BaseGame/Data/SCHEMA.md](../../Content/BaseGame/Data/SCHEMA.md) |

Bootstrap：`OpeningScenarioApplier`、`SettlementBootstrap`、`WorldRegionBootstrap`；PlayableDay 全内容驱动开局。

### Unity Host（表现／输入）

| 能力 | 说明 |
|---|---|
| HUD | Personality／Relation／Faction／Settlement／Work／Location |
| 键 5–7 | Help／Slight／Recruit |
| 键 8／9／0 | 分工 Labor／Gather／Cultivate |
| 键 T／Y | Explore／Travel（邻接） |
| EntityView | 按地点 PresentationX/Z 俯视布局 |
| Camera | 更高俯视默认 |
| Demo 提示 | F1 HUD 上方路径条 |

## 4. Demo 手操路径（约 30 分钟）

1. 打开 `PlayableHost`：三人＋村口可招者，按地点分布  
2. 选主角 → **Y** 至洞口 → **T** 探索发现废弃洞口机缘  
3. **4** 修炼至凡人→炼气突破（F1 看 Realm）  
4. **8／9／0** 分工；推进跨日看洞府木材／灵草  
5. **5／7** 帮助／招募；F2 看社会事件  

自动化等价路径：`DemoVerticalSlice10AcceptanceTests`。
