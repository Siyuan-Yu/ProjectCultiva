# 违规分级、牢房周边禁区与床上休息返修

> 日期：2026-10-27。状态：Design Confirmed / Implemented / Producer Acceptance Pending；未提交推送。制作人明确要求区分日程违规与直接追赶，并修复右键床休息。

## 已批准并在本轮实施

普通日程违规：未在规定时间劳动或休息，被在岗主管／巡卫看到，仍沿 SupervisorAngerDriver 原规则持续五 Tick 加一点压力；满值惩戒保留。不能将所有不合规都升级为当场战斗。

牢房禁区：制作人把「被发现在牢房附近」列为直接追赶。本轮将402的房内条件扩为牢房实际矩形及外沿三Surface格（以最近矩形距离计算，转角为三格半径）。这是禁区距离，不是观察距离；仍要求原劳役玩家成员真实处于此范围且被在岗、清醒、非救护的主管／巡卫二十格观察范围覆盖。看到后立即进入既有追赶、近身正常Encounter，无需压力涨满。未被看到可以靠近／进入；占领后不因靠近自家牢房触发追赶，拘押范围继续有效。对白和照料仍要求进入同房、靠近具体囚犯，不恢复房屋菜单入口。

床休息返修：到达回调原先先开启BedRestAction，随后StopOne把新动作取消，出现走到床边却不睡的问题。改为抵达后先收尾旧移动／等待，再执行新任务回调；保留AtSite原移动语义。床入口不使用1.5表现距离替代Core使用格，已经在任一合法床边则直接开始；否则枚举真实床边候选并选择可达位置，精确到达后复核床用途、占用、人物和使用格。床上休息仍沿既有时长／精力／饱食规则，不增加瞬间回血或无限睡眠。床失效或不可达给出原因。

## 直接追赶的类似情况（仅设计候选，未实施）

| 情况 | 建议后果与边界 |
|---|---|
| 被看到撬锁、破坏牢门、解救／带走囚犯 | 属于明确劫囚行为，立即追赶；不能只看普通工作压力。需后续把具体行动事实接入发现，不凭想象判罪 |
| 未经允许取公库粮药、偷取管理人员物品 | 看见实际偷取才追赶；正常配给、合法采集、自己库存和批准交易不算。现有无偷窃玩法的入口不凭空增加 |
| 擅入明确标示的主管私室、武库／功法禁库 | 有清晰边界与权限后，实际被发现直接追赶；不能把普通住房或所有村内设施一律当禁区。当前部分设施仍是门禁，不在本轮放开 |
| 被确证秘密修炼或使用暴露修为的能力 | 可作为压迫者镇压的直接事件，但需与隐匿系统、实际能否识破修为一致；不把所有村外活动或尚未看见的修炼直接判罪 |
| 主动攻击人员、破坏议政厅等敌对行为 | 沿已有正常敌对／攻城战斗入口；不重复另开一场惩戒战，避免重复拉人 |

不建议直接开战：发呆、聊天、错过工作／睡觉、一般生活需求和合法探路；这些继续按日程压力或原有规则处理。以上候选不构成本轮额外功能启动。

## 人工验收与交付

看岗圈：牢内／外沿三格内被看到立即追赶，三格外单纯路过不触发本项，普通日程违规仍渐增压力；休班／睡眠／失能不发现，占领后停用禁区惩戒。

床：远处右键休息，实际到床边后持续BedRest而非被Stop取消；在床的任一侧合法使用格右键可直接睡；靠近但不在使用格时先移动；不可达、被别人占用／分配和途中被改用途有明确反馈；手动移动可正常起床，不把完成／取消视为治疗。按1×及加速观察卧姿、精力和存读档。

仅基础编译和必要静态核对，不启动Unity、不编写或运行自动测试，不自动提交或推送；实际运行待制作人人工验收。

实施：SupervisorAngerDriver.PrisonTrespassBufferCells=3，按人物实际位置到牢房矩形的最近距离与同Surface观察距离判定，原日程压力累计与满值收尾不变。开场、任务说明和生活面板已同步禁区范围。HostNpcContextMenu枚举真实床边候选，先筛选导航可走格再比较可达路径长度，抵达后复核Core使用格。HostMoveController.ApplyPendingArriveAction先停止旧接近再调用任务回调，既有AtSite保留逻辑不变，避免刚开始休息又被Stop取消；此顺序也适用于使用同一到达回调的恢复、拾取、牢床交接等入口，不新增玩法。

验证：Core／Data／Unity／Unity.Editor四程序集离线基础编译通过，开场／任务JSON和相关引用、diff静态完整性已核对。当前内容仍0.0.46、Snapshot v20；现有存档可以继续，不重初始化人物、地图或床位。实际卧姿、寻路、精力恢复、暂停／倍速及存读档仍待人工确认，不以基础编译代替运行验收。
