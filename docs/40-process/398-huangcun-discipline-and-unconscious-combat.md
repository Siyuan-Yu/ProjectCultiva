# 荒村巡查惩戒、昏迷和救护流程

状态：Implemented / Producer Acceptance Pending。未提交推送，未封板。

规则依据：[ADR-0065](43-decisions/ADR-0065-huangcun-discipline-and-unconscious-combat.md)。本轮范围为昼夜巡卫／主管近距发现违规、主管怒气、接近与正常惩戒战斗、昏迷和弥留分阶段、显式处决、战后真实状态保留及村民医疗／住宅床搬运，包含持久化和 Host 提示接线。

## 本轮交付

**计时最终确认：** 昏迷 1× 约 100 个现实秒，2× 约 50 秒，20× 约 5 秒；暂停不计时。制作人的最后补充覆盖此前“现实时间”选项可能造成的歧义。已核对当前实现符合此口径，本次不修改运行代码或存档格式。

### 制作人补充的体验边界

当前阶段优先实现能够自行运转的真实规矩、NPC 行为与后果，允许用巡查、追赶、正常战斗和救护等强烈反馈帮助玩家理解处境与可做的事。玩家可以遵守作息、躲避巡查、承担惩戒或反抗；结果来自具体人物、真实距离、日程、战力及身体状态。不得为让玩家走预定路线而强制发现、强制战败、凭空处罚或绕过已有世界规则。

本轮不进入新手流程制作，不增加“必须点击某个按钮／完成某个指定操作才能继续”的教程锁、步骤旗标、强制弹窗或固定通关顺序。后续新手引导另行设计；当前实现与验收以世界机制和选择后果能否闭环为准。此补充明确既有授权的实施方向，不自动授权开启其他新功能。

内容 `0.0.46-huangcun-discipline-unconscious`，Snapshot v20。须新开局使用新版昼夜巡卫日程；本轮不重烘焙地图，沿用 0.0.45 的房墙、树矿与城市布局。此次“完成”指制作人本轮明确列出的链路接线，不表示荒村全部体验已通过人工验收、复杂追捕／完整丹器制作等旧待办已完成，或获得封板与自动提交授权。

- 巡卫甲 06:00–18:00，乙 18:00–06:00 值守，其余作息相差十二小时；主管沿用间歇查工。正式荒村 openingScenario 与 roster 均绑定日／夜班定义。睡眠、失能者不观察、不拦路；既有门禁半径从 22 格同步为本轮 20 格。
- 原开局劳役人物作为当前主控时，违规且距在岗巡查者二十格内，连续五 WorldTick 增一主管压力／怒气，上限一百。多人观察不叠加，出范围、合规或自由时间重置本段五秒计数，已积怒气保留。识别真实 Labor／WorkAction、床上或 RestAction 休息、额外短工与实际农作输入执行；不是仅看动画或位置同名。
- 满值后由发现者通过现有 MovementIntent 真实接近，接入正常 CharacterEncounter。休班巡卫不强拉入惩戒战斗，议政厅与临时外援不加入此场；不强制胜负，不改双方战力。惩戒者不攻击已倒地者，战后怒气归零；后续再次积满可重新触发，不受上一场接敌抑制永久阻塞。普通主动攻城保留原战斗规则。
- 战斗首败为一 HP 昏迷，默认 100 秒；户外每 WorldTick 一秒，遭遇战按既有战斗时间推进，暂停不走、倍速影响。剩余时间写入存档，醒来保留实际血量和有效药物，不补满。未结束战斗中苏醒者可以重新战斗；胜负已结算后不会因继续逗留战场而重新开启。
- 对昏迷或治疗后恢复中昏迷者继续攻击，转零 HP 弥留；对弥留普通受击不确认死亡。右键提供“攻击昏迷者（使其弥留）”和“杀死”，真实接近后重新确认目标状态；死亡走原正式确认、关系后果与尸体 authority。弥留自然恶化、治疗和尸体腐烂规则保留。战报失能总类不再一律误标“弥留”。
- 战后原返回流程保留真实 HP 和生命周期，仅恢复空间。昏迷／弥留均进入既有搬运；优先医床、满员选择本人住宅床，再沿用空闲住宅床紧急后备。危急弥留优先于普通昏迷。原三名劳役人物在村内可由所属村落的村民跨势力救护；被囚同伴必须先解救，未开放任意跨阵营自动救护。

生命周期枚举 0–5 全部保留；以 Incapacitated 总类中的 `UnconsciousSecondsRemaining` 区分普通昏迷，不复用 Convalescing。Snapshot v20 持久化昏迷、怒气、五秒进度、追赶双方和惩戒进行状态；旧 v15–v19 JSON 沿原兼容入口追加零计时，不把旧弥留猜成新昏迷，内容版本限制仍保留。原 WorldTick、RelationshipLedger、Squad、CharacterEncounter、Core/Data 分层及 Freeze 不变。

## 核对与人工验收

Core、Data、Unity、Unity.Editor 离线基础编译通过，`git diff --check` 通过。必要 JSON／引用静态核对确认日夜日程 ID 唯一、两处正式绑定一致，日程连续覆盖 0–288 Tick；状态、存档读写、惩戒返回与右键交互已接线。不启动 Unity，不编写或运行自动测试。编译与静态引用检查不等同运行验收。

1. 新开局跨过 06:00／18:00，观察两巡卫交班、主管间歇巡查；在其二十格内违反工作／休息日程观察五秒增一点，实际工作、休息、自由时间和范围外不增加。
2. 怒气满后观察巡查者走到玩家附近再开正常战斗，只有发现者加入惩戒敌方；确认胜负按战斗实际决定，战败为一 HP 昏迷，退出战场后村民接近搬运，医床满时用本人住宅床。
3. 有其他敌人仍清醒时，等待倒地敌人约一百秒，观察其低血量苏醒、可重新战斗；所有敌方失能即判胜，继续停留或返回世界均保留实际状态。
4. 对昏迷者再次攻击变弥留，反复普通攻击不变尸体；右键“杀死”才变尸体。观察药物仍可影响恢复，弥留者优先被救护。
5. 分别在五秒观察进度、追赶、惩戒战场、昏迷、搬运和床上阶段存读档，确认怒气／时长不重置、双方身份和床位不串；苏醒后可恢复控制，解放后不再执行巡查惩戒。
