## 1. Demo 目标

设计第一个可以验证核心玩法的 Demo。

**不要设计完整游戏。只验证核心循环。**

要回答的问题：

> 玩家是否喜欢「从凡人到修士，再到势力建立」的过程？

若玩家走完闭环后感到「我想继续玩下去」，Demo 目标成立；若感觉冗长、空转或只是升级按钮，则需回调节奏与压力设计。

## 2. 明确不做

以下内容 **不在 Demo v0.1**：

- 多大陆／多城市区域／完整世界地图
- 全部境界（结晶及以后）
- 大规模战争、正魔大战、宗门使者完整政治线
- 复杂功法／斗技树、装备养成、五行相克
- 完整渡劫、空间虫洞、飞行／踏空
- 地图编辑器成品、复杂建造链
- 多人、3D、独立战斗副本

Demo 用**一个荒村区域**承载完整闭环；规则可简化，但体验顺序必须完整。

## 3. Demo 范围：一张荒村地图

地图：一个荒村区域（城市区域内的起始区块即可）。

必须包含：

| 区域 | 作用 |
|---|---|
| 凡人住宅 | 人口容量与群体表现 |
| 主管住所／主管府 | 控制核心；最终夺取目标 |
| 工作区域 | 白天配额任务地点 |
| 农田 | 生产与群体劳动表现 |
| 森林 | 采集、探索、资源 |
| 隐藏灵地 | 偷偷修炼的核心地点 |
| 妖兽区域 | 首次战斗教学 |

尺度建议：约 **1～2 屏**可玩范围（小于正式城市区域的 10 屏目标），保证玩家很快建立空间记忆。具体格子数**待确定**。

## 4. 玩家流程（六阶段）

总时长目标：与正式开局一致方向——约 **40 分钟～1 小时**内完成第一次炼气；整段 Demo 闭环建议控制在约 **1.5～3 小时**可通关体验（含隐藏、反抗、占领与短管理）。精确时长**待试玩校准**。

### 阶段 1：进入荒村

- 角色：3 人
- 身份：感应境（有感知与修仙潜力，无正式功法运转、无真正灵力、无修士能力）
- 体验：时间表、工作任务、NPC 交流
- 教学目标：三人分头下令、暂停／加速、提前完工能换自由时间

### 阶段 2：发现修炼机会

包括：

- 发现秘密灵地
- 获得第一份功法（Demo 可只做 **1～2 条**可得路线，例如 NPC 传承 + 探索发现）
- 第一次吸收灵气／在灵地积累（感应境低效吸收，为突破做准备）

### 阶段 3：第一次突破

- 三人中**选择一人**突破进入炼气
- 其他两人负责：放哨、保护、收集资源
- 结果至少覆盖：普通突破／失败中的可解释反馈；完美／瑕疵可先做简化版或文本差分
- 突破期间突破者无法正常行动，体现护法分工

### 阶段 4：隐藏修炼

进入炼气后**不能立刻公开**（主管为筑基级威胁，Demo 中可简化为明显强于玩家的敌人）。

- 白天：继续工作，维持表面正常
- 晚上：偷偷修炼、采药、探索
- 使用**敛息资源**隐藏身份
- 三人可分工：修炼／采敛息与资源／探索情报

### 阶段 5：夺取荒村

- 目标：主管
- 方式：攻击**控制核心建筑**（主管府），耐久归零后夺取；并击败／驱逐主管
- Demo 主推**斩首夺权**一条完整线；逐步瓦解／外交接管可只留接口或简化事件，标为可选

### 阶段 6：成为管理者

开放：

- 修改时间表
- 人口分配
- 建筑管理（极简：修／用已有建筑即可）
- 人才发现（学校刷新至少一轮候选；可收弟子或任命管事）

到此玩家应感到：从被时间表支配，变成给别人排时间表。

## 5. Demo 最小系统清单

必须实现（或用可玩原型等价物验证）的内容：

### 5.1 角色

- 三人控制
- 单独行动与独立指令队列
- 修炼行动（感应积累／炼气修炼）

### 5.2 时间

- 暂停
- 2 倍速
- 5 倍速
- 时间表：前期只可查看；夺权后可修改

### 5.3 NPC

| NPC | Demo 职责 |
|---|---|
| 主管 | 配额、压迫、最终卡点 |
| 商人 | 简单交易／信息 |
| 守卫 | 夜间门禁或巡逻风险 |
| 学校人才 | 夺权后至少刷新一批候选 |

另建议至少 1 名可挖出功法线索的隐藏经历 NPC（可与商人或村民合并）。

### 5.4 修炼

- 感应境
- 炼气期
- 灵力／灵气池（战斗优先耗灵力）
- 第一份功法（可极简）
- 主动突破（达标只给资格）
- 敛息资源

### 5.5 战斗

- RTS 操作：左键选择、右键移动／攻击
- 普通攻击
- **一个**技能
- **一种**低级妖兽（教学战）
- 主管战：可用同一套操作；技能／AI 可极简

不做：6 技能栏全开、半自动／自动 AI、完整重伤交互树（重伤可先做成「倒下＝退出战斗」的简化，正式规则保留在 `23`）。

### 5.6 管理

- 时间表修改
- 人口分配（群体岗位即可）
- 任命管事
- 控制核心夺取

## 6. 完成标准

玩家可以不靠读文档、仅靠游玩，体验完整闭环：

```
凡人
 → 修炼机会
 → 突破炼气
 → 隐藏成长
 → 反抗主管
 → 占领荒村
 → 开始管理
```

验收检查：

| 检查项 | 通过标准 |
|---|---|
| 压迫感 | 开局感到时间与资源不属于自己 |
| 发现感 | 主动找到灵地／功法，而非被系统弹窗塞升级 |
| 突破感 | 第一次炼气改变可用能力（灵力／技能），不是纯数字 |
| 隐藏感 | 炼气后仍需敛息与分工，不敢立刻摊牌 |
| 掀桌感 | 夺取控制核心并击败主管，身份翻转清晰 |
| 管理感 | 夺权后立刻能改时间表／分人口，感到自由增加 |
| 意愿 | 试玩者表示愿意继续玩正式版的下一章 |

## 7. 与正式设计的关系

| Demo 简化 | 正式设计来源 |
|---|---|
| 一张荒村图 | `24` 城市区域内部区块 |
| 40 分～1 小时入炼气 | `20`／`2G` 前期节奏 |
| 敛息＋隐藏修士 | `2F` |
| 主动突破＋护法 | `25` |
| 斩首夺控制核心 | `26` |
| 夺权后改时间表 | `21`／`26` |
| 学校人才一轮 | `27` |
| RTS 小队战斗 | `23` |

Demo 验证通过后，再向外扩展：使者审查、第二据点、灵气汇聚、更多境界与功法。**不得**把 Demo 未验证的系统提前做成完整版。
