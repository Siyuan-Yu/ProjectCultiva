> 2026-10-25。制作人决定：继续修复世界图路线偶发中断；一级城镇长宽改为当前的 0.75 倍。状态：Design Confirmed / 一级行政范围 Implemented / 旅行中断追因进行中 / Producer Acceptance Pending。

本轮以现有 `PlayerPartyWorldMotion` 的精确位置与旅行路线为唯一权威。Editor 日志已记录多次连续的 `TravelPlanVersion` +2 与地图中断提示，说明规划成功后确有取消。需要记录取消来源，并处理地图打开时表现层／斗气化翼系统的合法衔接；不能仅延长线条显示来掩盖已失效路线。手动停止、死亡、力竭和真正失去飞行续航仍可按既有规则中断，但应明确告知原因。

已接入 Editor／Development Build 临时取消调用栈记录（不入 Snapshot），待制作人复现场景以确认具体调用者。已修复两个可由静态代码直接确认的规划前状态缺口：个人精力已经归零但 Exhausted 标志还未在下一 WorldTick 更新，以及角色仍标记 Airborne 但已不满足化翼续航条件。此时现在明确拒绝旅行，不再先接受并显示路线、随后在下一 Tick／Host Update 清除。此项不等同于已证明全部偶发中断的根因。

地图保存已接受路线对应的主控与起飞状态；若后续真实取消，提示会区分主控切换、精力耗尽、化翼结束与尚未分类的中断，Editor 日志同时记录这些状态和取消调用栈。这里没有把已经无效的路线强行留在画面上。

尺寸配置已修改议政厅一级的理论行政控制范围：225×225 Surface cells 的长宽各乘 0.75，成为 168.75×168.75；二至五级保留 337.5／450／562.5／675 cells。运行包版本升为 `0.0.22-level-one-control-075`，新开局使用新范围，旧档保持旧文件并走内容版本门禁。

荒村实体蓝图目前为 220×200 cells，墙体与建筑布局是另一套作者数据，控制范围配置不会自动缩放它。对全部蓝图对象坐标机械乘 0.75 会造成至少五组房屋重叠，还会影响床位、人物、入口和城墙。制作人关于实体村落是否同轮缩至约 165×150 cells 的意图仍待澄清；明确前不移动这些作者坐标，也不声称实体村落已缩小。
