# 荒村开局盆地与墙外洞府实施记录（2026-10-25）

状态：**Design Confirmed / Implemented / Producer Acceptance Pending**。对应 [ADR-0057](43-decisions/ADR-0057-huangcun-enclave-patrol-and-exit.md)。本轮没有制作人人工验收结论，也没有封板。

## 运行结果与真源

- 一级荒村行政及实体围墙保持 180×180 Surface cells。开局准入改为以议政厅为中心、长宽各 720 cells 的盆地。作者蓝图扩为 780×720 以容纳崖外返程灵阵，原 975 个对象通过局部坐标对冲，绝对世界坐标不变。
- 旧洞府入口和原有洞内功法、斗技秘本保留相同身份，入口迁至当前围墙东北侧。盆地外围两格宽的山地阻挡构成闭合崖壁；城外增添林地表现、零星铁／铜／银／灵矿、崖石、小灵泉及三处可调查的旧石碑，逐步提示洞府和出口。洞府探索任务的方位文字已同步更新。世界图和局部世界都读同一 Surface 数据。
- 开局人物可到墙外；从村内越墙时，主管与巡卫甲乙若当下处于 Inspect／Patrol 排班且在穿越点 22 格内，则阻止出村。人物已在墙外时可继续行动、可返村。围墙与盆地是两个独立边界；没有修改占领后的建造/势力准入。
- 东侧崖内、崖外各有 `spiritGate` 实体；占领荒村前可调查但不可使用，占领后近距离右键可在同一 Surface 双向往返。世界图近距离缩放时标出两端位置。地面没有绕过灵阵的缺口；飞行越崖仍需先解除开局盆地准入。开局文案和主管说明改为与此一致，新增洞府外、灵阵两端及三处石碑的现场事件。
- `Content/BaseGame/manifest.json` 升至 `0.0.24-huangcun-enclave`；作者组合与三个正式 Runtime 发布物同步更新。需要新开局检视内容版本。

## 与第一章广义内容的边界

本轮复用现有洞府的功法书和斗技秘本、研读/学习服务、既有角色社交和关系账本；没有把这些旧功能重写。2M 人物社交 V1 已封板，但自动社交链、报复/追查、NPC 具体怀疑值的现场后果仍不是已完成的第一章体验。斗技/功法虽可学习并有既定战斗/属性作用，超出当前定义的元素联动与复杂特殊机制也未在本轮新增。巡卫发现玩家时目前是近场即时阻止，没有抓捕、罚款或追逃状态；这些需要先明确数值与剧情后果，再分别走 2F、2G 和关系系统，不应冒称已完整实现。

## 静态核对与人工验收入口

本轮只做作者数据发布、JSON/对象引用检查与基础离线编译；未运行自动测试、Unity、PlayMode 或 batchmode。制作人新开局可依次看：地图盆地与山崖、三处旧石碑、东北墙外洞府与洞内两本秘本；白天/夜间经过门岗和巡卫空档出村；返村；占领前灵阵提示、占领后两端往返传送；金丹化翼解锁后越崖；持续移动与跨 Chunk 帧时。界面内的山崖暂为山地/岩色占位，仍需美术验收。
