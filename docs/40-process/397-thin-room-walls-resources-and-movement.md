规则依据：[ADR-0064](43-decisions/ADR-0064-thin-room-walls-larger-resources-and-movement.md)。保留房间整体大小，房墙与城墙一格等厚；全图树矿长宽按 0.0.43 各乘二并重新疏排；步行当前 1.5 倍、飞行为调整后步行两倍，配置在 worldSpatialRules 内容中。

## 实际实现

### 荒村村内疏树追加

制作人进一步确认荒村内也需少量树木。保留当前两倍树木大小，从城外移回八棵中树，分散在西南空地、东北设施间及东侧空地；房门前保留至少三格净空，避开中央主路、田块及现有设施。树木总数、稳定 ID 和产量不变，其他城市不调整。此项覆盖下文“城内树矿移至城外”在荒村的全量执行方式；矿石仍留城外。追加版 `0.0.45-huangcun-sparse-trees` 已正式发布，须新开局；几何核对八棵树之间及其与其他物件至少三格净空、未压中央十字道路。发布后对照上一版仅八个荒村树物件改变，稳定 ID 集合不变、分块归属一致，地图／导航缓存匹配，`git diff --check` 通过。本次仅内容、既有作者脚本的重复执行保护与文档变化，不启动 Unity 或自动测试，待人工查看分布与通行，未提交推送。

版本 `0.0.44-thin-walls-resources-movement`，Snapshot v19，须新开局查看资源布局。房间仍保留外框长宽两倍；房墙改为一格厚，墙角横纵两段相接，共用原稳定墙段 ID 和生命值，任一部分受伤或拆除同步到另一部分。门洞宽度保持当前四格，门框和标牌深度回到一格。显示、热通行、冷通行调用同一薄墙矩形函数；既有床位和家具不移动，床边保守净空保留。

1944 棵树、250 处矿石按 0.0.43 的实际长宽各乘二，类型、数量、稳定 ID 与产量不变。树木之间保留至少三格空隙边带，矿点至少两格；密集城区内树矿移往附近城外，避开城墙、建筑、田块、道路、桥梁、水域、山体和开局出生点。不压缩／删除资源，也不改变农田大小或成熟周期。

作者蓝图画布除荒村外四边各扩 80 格以容纳城外资源；同时反向移动蓝图放置原点与所有局部坐标，保持原建筑、城墙、精确城址和地形细节在世界上的位置不变。荒村已有大画布，无需扩展。地点与资源绑定中心同步重算；行政范围不消费蓝图画布尺寸。

速度配置在 `Content/BaseGame/Data/Worlds/world_spatial_rules.json`：`walkSpeedMultiplier: 1.5`、`flightSpeedMultiplier: 2`。前者相对本轮前基础速度，后者相对调整后步行，合计飞行是本轮前步行的三倍。更改 JSON 后重新加载内容即可继续调参，无需改人物预制体或 Snapshot。WASD、点击路径、跨 Surface 覆盖边界、NPC 日程、离屏个人移动与小队移动均接入；全员飞行的小队才用飞行倍率，混合小队按地面速度。没有改变暂停／时间加速、起飞资格、灵力消耗、寻路类型或移动 authority。
