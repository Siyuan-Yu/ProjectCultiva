# 135 · 世界物只读况栏＋树木砍伐

> 状态：已落地｜日期：2026-08-16（2026-08-17 修产量／入包／树不挂 Work）  
> 相关：主管府耐久、住房工区、mapLayout placements  
> 收束：[137](137-skill-mastery-farm-veil-chop-rollup-2026-08-17.md)

## 拍板

- **框选只选己方可控人物**（原逻辑不变）。
- 左键点空地／建筑／耕种格／树墙 → 打开**只读物况栏**（无移动／交互／战斗球）。
- 第一刀：统一检视；第二刀：树有血量，打完掉粗木并销毁。
- 树**不**注册 Work 热点（避免误成林区劳动）；砍伐靠右键／F8。

## 交互

| 操作 | 效果 |
|------|------|
| 左键点空（未点中人物） | 按优先级检视：主管府 → 树／墙 → 耕种格 → 住房 → 其它工区 |
| 选中己方后右键树／墙 | 砍伐／拆毁 |
| F8 战斗模式点树／墙 | 同上 |
| 树耐久归零 | **先** `TryAdd` 粗木进背包，再销毁；产量小3／中**10**／大**40**（`DefaultWoodYield` 用小写 `treem`／`treel`／`trees`） |

## 况栏内容

- **主管府**：耐久、占领状态（只读；突击仍靠右键／F8）
- **住房**：归属／入住（只读；改归属另开管理入口，本刀不带按钮）
- **工区**：容量／标签／允许活动
- **药田／农田格**：空闲／成长中／成熟／损坏（字段齐；种植玩法后补）
- **树／墙**：耐久条＋砍伐说明
