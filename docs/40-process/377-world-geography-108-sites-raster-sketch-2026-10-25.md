# 世界地理与 108 城镇完整排布草图（2026-10-25）

状态：**Proposed，仅 PNG 草图；正式 Surface、Site 坐标、道路与城镇归属未修改，也未经制作人验收**。

本图沿用此前二维世界图的画风、地貌比例和信息层级，取当前正式作者数据的 **108 个固定人类 Site 身份及其现有归属**。每个 Site 恰画一次，并显示正式名称；没有隐藏既有据点，也没有凭空增加候选城。实色框表示当前等级的管辖范围，浅色虚线框表示同址升到五级后的满级范围，框色表示当前归属。草图把同一势力的城镇排成相邻组，并把原本位于拟议魔兽山脉、蛇人沙漠、极寒、磁乱、火山、飓风或雷暴内部的人类城镇**在图面上**迁到适居边缘。魔兽山脉中心、火脉群峰与镇岳地带示意为高原；荒村在西界河西侧的盆地，风雷相邻于东部，沙漠位于东南。

城镇的**身份、名称、当前等级与数量来自真实清单**，图中**重排坐标不是运行数据**。五级虚框按当前冻结的一级基准与 `1 / 1.5 / 2 / 2.5 / 3` 长宽等级表等比表示，但本图仍是缩略草图；批准落地前还要用 Surface 格坐标对全部 108 座五级行政框做精确不接触检查，并同步地貌、道路、蓝图与人物锚点。此轮没有改包版本，也不需要进入 Unity。

旧版图像文件已按制作人要求删除；现行定稿见 [378 世界地理定稿](378-final-world-geography-gate-handoff-2026-10-26.md)。
