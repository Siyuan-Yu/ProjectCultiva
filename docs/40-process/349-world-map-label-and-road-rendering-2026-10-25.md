# 349｜大地图名称裁字与道路层卡顿返修

> 2026-10-25。制作人反馈：世界地图据点名称上下被截断，打开大地图明显卡顿。本轮状态：**Implemented / Producer Acceptance Pending / 未提交推送**。仅改 Host 地图表现，不改 Continuous Surface、道路导航格、Site／Claim 权威、内容包或 Snapshot。

## 定位与一轮实施

1. Site 名称字体字号按世界投影缩小，但 `GUI.Label` 的矩形高度也直接取同一世界尺寸。小字号中文的真实字形／行高仍需要额外屏幕像素，造成上、下缘被矩形裁掉。标签改以投影点定位、使用屏幕像素的最小字号及足够的行高；命中框跟实际可见标签一致，视野外标签不参与绘制。
2. 当前 15200×6800 地理中，运行导航导出约 **60,656 段道路水平栅格游程**（277,859 个道路格）；WorldMap 的 `DrawGeography` 每个 IMGUI 事件扫描、投影所有游程并对可见者逐段 `GUI.DrawTexture`。正式地理同时已有 **468 条道路中心线、472 个线段**用于地图表现。总览层改用这份已有中心线，按当前视野裁剪后仅在 Repaint 画线；精确导航仍读原有道路格。世界图底图仍复用已有缓存纹理。
3. 保留原有桥、水域和行政范围的表现叠放顺序；无地理中心线时不重新扫描 6 万游程做逐帧回退，避免把大图卡顿带回产品。初次打开时底图只生成与当前地图面板像素规模相称的缓存纹理，减少对整幅 15200×6800 世界做过度显示采样和纹理上传；面板尺寸变化才按需重建。开关地理层应立即生效。只做基础编译及少量静态引用／文件检查；Unity 外观和实际 FPS 由制作人人工验收。

## 实施与基础检查

`HostWorldMapPanel` 的地理层现只在 Repaint 遍历现成道路中心线；Site 与玩家小队标签用 `GUIStyle.CalcSize` 计算屏幕像素行高和宽度，Site 命中区与可见标签一致。`HostSurfaceWorldMapRenderer` 只在 Repaint 生成／绘制底图，并按面板像素预算选采样步长。Core／Data 基础编译 0 警告、0 错误；复用 Unity 当前 `XianXia.Unity.rsp` 参数对改动后的 Host 源码单独基础编译，0 错误；`git diff --check` 无空白错误。以上不代表 Unity 现场画面、流畅度或 FPS 已验收。

## 人工验收

新开局打开世界地图，查看不同缩放下青石、宗门节点及长名称的上／下笔画是否完整，点击名称／图标是否仍选中对应 Site。开关“地理层”，道路应随之出现／消失，水域和桥梁位置保持正常。全图、青石附近和拖动／滚轮缩放各停留数秒，用 F9 对比打开地图前后的帧率与最慢帧。
