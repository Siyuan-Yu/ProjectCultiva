# 不规则险地与势力颜色二维图（2026-10-25）

状态：**Superseded / 历史图面草案**。后续设计见 [375](375-unclaimed-origin-and-plateau-entrances-2026-10-25.md)；本版的大片推断性势力色块不再采用。承接并取代 [373](373-fire-rim-towns-and-storm-city-hazard-corridor-proposal-2026-10-25.md) 的图面版本。

旧图棕色虚线是早期的**拟议据点交通联系**，并非已经铺设的道路。它穿过了后续调整的荒村盆地与河流，容易被误认成正式可走路线；本版将旧连线全部删除。灰色起伏线和三角形仍表示山脊／崖线，浅色方框虚线仍表示城镇全五级预留范围，荒村的蓝色虚框仍表示开局盆地。这些符号不自行确定步行、飞行或导航规则。

火山群峰改成贴合地图左下边缘的折转山带；磁乱谷改成贴合左上角的非圆形地貌。东部飓风区和雷暴区改为带状、不规则边界并填至东缘，两区在风暴城西侧相接。风暴城与火脉外围候选城镇的全五级框仍留在险地之外，沙海关仍位于雷暴南缘外。这只是自然地貌的平面示意，不把空白草地全部定义为灾害区。

图中的**同色实线据点框**按现有 `main_world.worldcomposition.json` 的 `ownerFactionId` 着色，色值读取现有 `factions.json` 和 `sect_lineages.json` 的 `mapColor`。淡色连续色块是以图上保留的现有据点位置作外推的**势力活动区提案**，不是已经发布的连续行政所有权，也不改变正式 Site 管辖。荒村因图面拟迁，在概念图中仍用执衡宗颜色；青石镇当前未填 `ownerFactionId`，本版继续用中性色。新增的外围候选城镇未获正式归属，也保持中性色。

因为前一版已经把位于拟议妖域、蛇人沙漠与极端地貌内的部分旧人类 Site 从**概念图**隐藏，本版只对仍显示且已有明确归属的据点画色块。没有显示颜色的宗门不等于其正式领地消失；旧 Site 的迁址、各势力最终边界，以及妖兽／蛇人聚落都需要后续单独设计。尤其是活动区与河流、山脊接近的地方，仅表达势力大致方位，不赋予跨河／越山的控制或通行事实。
