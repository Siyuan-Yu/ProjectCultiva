# 408 — 简化战斗伤势、断肢与金丹遗骸移接

状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人明确授权；最后补充覆盖先前细分伤口、疼痛和出血建议，割伤阈值经再次确认是低于50%。本页为本轮唯一实施指令，承接 ADR-0067。遗骸移接仍为 Design Confirmed / Not Implemented。

## 当前实施：简化伤势

不建立“左手割伤／胸口割伤”等伤口列表，不引入疼痛、出血量、止血或感染操作。保留整体HP，新增可共存的割伤、重伤、缺肢和经脉断裂；仅缺肢区分左右臂／腿以便持久化真实身体和显示。伤势是原因，失能和清醒是结果，拘押仍独立。

首版可调数值（未指定概率和时长由本轮给出初值，非平衡验收）：

| 实际战斗身体受伤后 | 首版判定 |
| --- | --- |
| HP严格低于50% | 当前没有割伤时，每次身体受击20%发生割伤 |
| HP严格低于25% | 当前没有重伤时，每次身体受击25%发生重伤 |
| 首次被打昏 | 必有重伤；每次10%失去一条尚存手臂、5%失去一条尚存腿、20%经脉断裂；各项独立判定 |
| 主动补击昏迷／恢复期使其进入弥留 | 95%经脉断裂；已经断裂不重复抽取 |

完全被护盾吸收、闪避、无伤害、读取存档、战后返回不掷伤势随机。角色创建也不自动补掷旧伤；原有战斗惩戒禁止补刀的规则保留，断肢并非死亡。

割伤降低少量战斗／移动能力，重伤进一步降低；一臂缺失攻击明显下降，两臂缺失降到极低，腿缺失影响移动，两腿缺失不能自主地面移动但可在原地交互。经脉断裂显著压低灵力与战力，暂停获得修为／突破，不删除已有境界、功法和修为。全部属性减益走既有 Modifier 管线；不降低MaxHP制造二次击倒，不重建当前池。模块人物隐藏真实缺失肢体，不更换身份／位置；旧整体精灵至少用身体面板准确展示缺失。

## 治疗与苏醒

- 废止固定100秒苏醒。首次战败仍留1HP昏迷，持续自然恢复及已有真实药物治疗；严格超过50%最大HP才恢复清醒。弥留经治疗稳定后同样按HP恢复清醒，缺肢／经脉断裂不要求先治愈才能醒。
- 非弥留者基础自然恢复为每秒最大HP的0.1%（千分之一HP定点累计）；已有每份药+0.4HP/s、医疗床+0.2HP/s、恢复属性继续生效。基础自然恢复不抵消弥留的−1储备/s；弥留仍须正净治疗才能稳定。非弥留不再无条件扣−1恢复率。
- 割伤与重伤的愈合负担分别等同25%／75%最大HP的有效恢复量，累计正恢复逐渐减少，并分别在HP达到50%／75%后解除；满HP仍继续必要伤势恢复。普通受击不无限刷新已有负担，再次被打昏／弥留会重新加重至完整重伤负担。普通治疗、吃饭、恢复处补满血、离场都不能接回断肢或修复断裂经脉。
- 正常进食维持恢复条件，不直接回血；饥饿至零不产生正恢复。医者可照料有可恢复伤势／未满HP的床上病人，不只救弥留；监管及同伴送药沿原真实物资与近场操作，不复制物资。
- WorldTick户外推进，遭遇内复用既有战术时间与衰减累积推进，暂停冻结、倍速影响身体恢复及恶化；不另建世界时钟。战后苏醒不重开已结算战斗，返回不恢复HP／肢体／经脉。

## 后续设计：金丹遗骸移接（本轮不实现）

金丹起才能移接他人遗骸的完整对应部位，前期残肢是真实长期损失。遗骸保留原主、部位、境界、肉身品质、保存完整性、属性与功法适配来源；收集、移接、交易、配方、关系后果及再造均不增加执行入口。

移接分手术接合、虚弱排斥、初步融合、持续炼化、高度融合。金丹移接元婴肢体只获得受自身境界与契合限制的局部能力和成长潜力，不直接获得元婴整体战力。使用超承受力的力量可消耗过大或伤及经脉；保存完好且契合的低境界部位可能优于损坏／冲突的高境界部位。经脉修复用后续专门丹药／神通设计，不由普通灵草或肢体移接顺便根治。

## 数据与兼容

新伤势组件为唯一伤势真源，HP／生命周期仍用现有组件。Snapshot新增v21（旧枚举与版本号不重排）；保存缺肢、经脉、割伤／重伤恢复量与无固定倒计时的昏迷标记。v15～v20通过既有JSON内存迁移：原倒计时昏迷转为伤势恢复型昏迷、保持HP／药量／拘押／位置；不臆造断肢或经脉，不自动覆写原档。旧程序拒绝v21。伤势减益读取时按真源重建，不能叠加或掉失。

## 验证边界

只离线编译Core／Data／Unity／Unity.Editor及最少静态引用和diff检查，不写／运行自动测试、不启动Unity，不提交推送。人工验收：阈值内多次实际身体受击看随机伤势，护盾吸收不出伤；打昏／弥留后真实恢复、不固定时间醒；伤势减益和断肢显示、药物消退普通伤、断肢经脉不被补血清除；倍速暂停、冷热移动、战后及存读档保持状态；原牢房照料／医者继续真实取送物资。

## 本轮实际接线及限制

- `CombatInjuryComponent`保存割伤／重伤恢复负担、四肢缺失bit与经脉断裂；`CombatInjuryService`用世界IRandomSource只在实际身体受击／首次昏迷／主动转弥留时判定。近战、技能共用伤害链及据点防御均接入，旧档不补掷。
- 减益来源固定为 `StatusEffect + base:combat_injury + EntityId`，重建前按此来源移除；割伤／重伤攻击分别−5%／−25%，单臂／双臂额外−60%／−90%，经脉断额外−35%，总攻击减益封顶−95%；经脉断灵力上限−80%。地面移动受割伤／重伤0.9／0.65及单腿0.4乘算；双腿不能步行，可合法飞行者仍沿原飞行规则。NPC Squad按最慢成员身体状态调整，无法步行的在队成员阻止直接旅行，不能随宏观旅行自动移动。
- 普通割伤不按部位细分；肢体丢失按真实左右隐藏模块骨骼显示。双腿缺失者为清醒卧地姿态，不伪造昏迷；当前尚无专用独臂武器动画、假肢、清醒残疾者专用搬运工作或手术界面，不能据此声称完整残疾生活已做完。
- `MedicalRecoveryService`统一正恢复、普通伤愈合及HP苏醒条件；医者扩展到普通床上伤员，危急优先，普通伤最多补到三份药、弥留最多五份，避免饥饿等阻断恢复时无限加药。监管／原同伴满HP但仍有可恢复普通伤也能送药；仅残肢／断经脉不再骗取普通药。面板有独立身体卡，探视／管理对白同步伤势。
- 遭遇保存独立的身体恢复小数累积，复用战术时钟，不新增世界时钟；原尸体留存仍按既有现实秒，不随本轮身体倍速更改。返回不操作伤势组件，显式处决与旧锁敌不自动补刀规则保留。v21保存并校验新字段，v15～v20原JSON迁移沿既有读取入口。
- 四程序集离线基础编译通过，必要静态引用／字段与diff完整性检查通过；未启动Unity／自动测试，运行与保存加载仍待制作人人工验收，未提交推送。内容包仍0.0.46，Snapshot现为v21；两份既有地图previous备份保持未触碰。
