# 空手普攻动画返修

日期：2026-10-28。状态：Implemented / Producer Acceptance Pending。

## 单轮实施指令

制作人反馈主控普攻没有明显动画，要求一并检查其他未装备／未展开纱衣人物。静态确认手动近战已经调用PlayArtAttack，但其持续SetRangedAim使共用骨架末尾瞄准IK覆盖右臂攻击；Unarmed又回落普通持械挥动分支，没有独立出拳动作。

本轮只修Host表现：手动空手攻击只设置面向、不套远程举手瞄准；共用骨架增加空手蓄力—出拳—收拳、另一手护身和适度躯干发力，近战攻击姿势不得被末尾瞄准IK覆盖。主控、同伴与NPC沿已有实际出手入口共享，挥空也有动作；伤势缺肢、睡眠／失能／抱持及暂停抑制保持，边走边打不冻结腿部步态。保留武器挥动、纱衣施法与原出手事件，不新增装备数据或伤害时钟，不改0.85秒间隔、命中／射程／灵力／世界位置。

先记文档，再改表现代码；仅基础离线编译及最少调用／diff检查，不启动Unity、不编写或运行自动测试、不提交推送，保留既有修改与本地地图备份。

## 实施结果

HostDirectionalRangedAttack在近战时清除远程举手瞄准、保留鼠标面向，展开纱衣才提交SetRangedAim。HumanCommonRigView增加Unarmed独立护手／蓄力／伸拳／收拳分支，真实手掌姿态沿固定肩部socket和原伸缩限制计算，叠加小幅躯干发力；末尾瞄准IK不再覆盖正在进行的近战。动作仍使用已有0.36秒攻击表现窗口，不引入第二套伤害或位移时钟。

静态复核主控实际挥空／命中、CharacterEncounter、NPC自动战斗及本地近战经PlayArtAttack／共用打击表现进入同一骨架；没有另给主控做独占动画。Unity／Unity.Editor／Tests离线编译通过（仅编译），diff及最少调用检查通过。两处已有测试源码警告保留，未启动Unity、未运行自动测试、未提交推送；实玩动作幅度和观感待人工确认。

## 人工验收

无武器未开纱衣时，朝不同方向点按／长按左键、挥空／命中均能看到护手、蓄力、挥拳和收势；WASD边走边打腿部不僵停。观察同伴及普通空手NPC出手同样有动作；原持械巡卫动作及筑基纱衣瞄准发射不回退。暂停冻结、失能和抱持不可出拳，断臂仍保持缺肢显示。伤害与攻击节奏不因动画变化。
