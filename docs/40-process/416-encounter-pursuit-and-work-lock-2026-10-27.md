# 416 — 战场追击与工作禁用接线返修

状态：Design Confirmed / Implemented / Producer Acceptance Pending。

制作人反馈拉开距离后敌人停留房间附近，且战斗中仍能点击耕田、砍树等工作。本轮覆盖实际参战者从入场至结束结算前的普通工作禁用，以及战场持续追击接线。

## 单轮实施指令

1. 参战人物的普通工作、修炼、采集入口与执行中提交统一禁止；已有普通工作、日程移动、休息及床位占用在战场接管时取消，普通日程不能覆盖战场路线。保留正式战斗中的破墙、拆除战斗目标、移动、攻击和俘虏处置。
2. 追击以当前实际敌方参战者与可用战场路线为准，不依赖普通工作／睡眠状态、摄像机显示或旧日程接线。有效原路线续走；失效目标重新选择；目标移动使用受限重寻，追击更新不依附普攻冷却。
3. 对无路径、身体限制等真正失败补有界诊断；不凭截图虚构距离脱战规则，不以瞬移、穿墙、自动放弃战斗补救。战斗中工作按钮明确显示禁用原因，拒绝工作不得先下发移动或停止现有攻击。
4. 更新交接／devlog／系统说明，执行四程序集离线基础编译与最少静态检查。按 AGENTS 不启动 Unity、不编写或运行自动测试、不提交推送。

## 人工验收

房内开战后把所有仍可战斗的我方成员移至数排房屋以外，敌人应经门和通路追到新位置；再持续移动、改变方向及切换 1×／20×。若还有我方人物留在敌人近处，敌人可正常攻击该人物。战斗中右键农田、树木及通用工作点，不能开始工作或打断当前战斗指令；开战前正在工作或休息者应停止旧任务。正式战斗破墙救人仍可执行。

## 实施与证据

现有追击没有按距离退出的规则，但原执行依赖攻击冷却；站位分配还要求人物具备可渲染身体、未被普通睡眠状态占用。Core 的战场接管此前只复验空间，并没有统一取消原工作／休息；旧 BedRest 及 civilian SleepPhase 可继续阻止移动，普通工作入口也不完整。截图未能直接证明当前角色具体命中哪个分支，故不声称已经现场复现。

已接 Core CancelForEncounter：取消普通行动及队列、工作预约、旧移动意图和睡眠；入场与恢复绑定释放可行动者床位，保留身体原位置／伤势与正式俘虏关系。NPC 日程执行器在接触旧 intent 前按 revision 释放自己下发的旧路线，之后跳过战场所有者。

Host 追击独立为 0.4 实时秒更新，保持原有效路径和攻击射程；失效／已退出目标重新选择，战场导航不要求身体渲染。无法下发追击时以 EncounterPursuitBlocked 记录实际门禁原因，仅原因／目标变化时报告，区分失能、运输、伤势、疲惫、导航范围和无空闲攻击位。

工作菜单显示“战斗中禁止工作”，快捷入口／到达劳动指令／Host 发令／Core 输入与入队在副作用前拒绝；Work／Labor／Cultivate 执行也复验。原耕田检查保留并补反馈；普通资源伐木、工作循环停止，实际资源伤害提交复验。合法墙体战斗破坏仍可执行。
