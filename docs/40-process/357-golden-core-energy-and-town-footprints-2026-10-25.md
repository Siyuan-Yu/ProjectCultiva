# 357｜金丹精力与城镇实体范围统一

> 2026-10-25。制作人确认：上一轮一级 0.75 缩尺改为旧值 0.8；一级荒村的实体也须调整，全部固定城镇按等级重整，墙体沿各自行政范围边缘。状态：**Design Confirmed / Implemented / Producer Acceptance Pending / 未提交推送**。

## 本轮单一实施范围

1. SiteCore 1～5 级长宽从旧一级 225 格按 0.8 与既定 1／1.5／2／2.5／3 倍计算，依次为 **180／270／360／450／540 Surface cells**。不改等级、Site ID 或连续 Surface 坐标权威；六处与真实议政厅偏离的 Site 中心按下文校正。内容版本升级，新开局取新配置。
2. 108 处固定 Site 的作者蓝图与理论范围同心并按当前等级取整格尺寸。保留议政厅、住房、床位、工作设施与人物锚点的精确世界位置；把原外围墙移至新范围边缘，路口留通行门洞。荒村原 220×200 蓝图改为 180×180 的一级完整范围；其非墙体建成区集中在内部，不能机械压缩家具和房间而造成重叠。其他现有据点取各自等级范围，目前 5 处一级、103 处三级。墙段使用现有木／石建材和跨 Chunk 平铺表现，避免逐格新建渲染对象。道路与墙洞须对应，场景行政淡色与实体墙分别保持真实语义。
3. 金丹及以上修士不再因普通 WorldTick 日常需求消耗精力；低阶仍按现有规则。已耗尽精力的金丹人物恢复到可行动阈值，解除由耗尽导致的行动锁；受伤、灵力、战斗与其他阻止飞行的条件保留。此改动用于解除精力归零造成的旅行拒绝与中断，不把所有旅行中断都归因为精力，既有取消来源追踪保留供现场复现。
4. 使用既有 WorldComposer 兼容发布器重发正式运行地图；只作基础编译和静态完整性检查，不运行自动测试或 Unity。新开局由制作人检查荒村与青石镇墙洞、房间／人物位置、各等级地图大小、飞行旅行及帧时。

## 实施记录

作者源中 108 个固定据点已按当前核心等级重做蓝图边界：5 处一级 **180×180** 格，103 处三级 **360×360** 格。六处旧地图中心与实际议政厅偏离的 Site 以真实议政厅中心对齐，Site ID／Owner／等级均未改变；原有 8,988 个非围墙物件保留，仅将越界的 62 处树木／矿石和 1 处荒村洞府入口向内移动。原 8,568 个围墙物件替换为沿新边界的 **660 格荒村逐格木墙**与 **3,819 段其余城镇围墙**，每侧预留中央入口和既有道路交汇门洞。墙段上限 50 格，沿用既有木／石建筑定义及跨 Chunk 平铺表现；荒村围墙 ID 保持开局村界绑定前缀。新增城墙圈内的空地保留为后续扩建空间，不虚构已具备服务功能的建筑。

世界空间规则现为 180／270／360／450／540，五级 540 格方框重新核对后的最近轴向净距为 **231 格**。现有 WorldComposer 兼容发布器已把作者源重发至三份正式运行世界数据，运行据点 108、蓝图对象 13,467、议政厅 108、房间 1,748、床 1,914；内容包版本为 `0.0.23-town-footprints-080`，需新开局。金丹及以上非凡人日常与打坐的精力扣减已关闭，旧低精力状态在下一次需求推进时恢复到可行动阈值；心境、饱食度、灵力和战斗状态仍分别按现有规则处理。

Core 基础编译 0 错误；发布器的作者格式校验和必要的静态边界、对象计数检查已完成，`git diff --check` 无空白错误。未运行自动测试或自行启动 Unity。世界图偶发路线取消的其他来源仍需制作人以已接入的开发日志现场复现，不能仅凭精力修正声称全部原因已排除。
