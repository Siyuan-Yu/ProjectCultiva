# 414 — 放你一马不再永久锁定处置

状态：Design Confirmed / Implemented / Producer Acceptance Pending。

制作人最新明确：“放你一马”效果应同“暂不处置”，只结束本次对话，之后仍可处置，不应产生“已获放过（伤势保留）”状态。该要求覆盖410／ADR-0068与412／ADR-0069中的Spared退出和醒后不再参战条款；不改变身体、拘押和半血苏醒规则。

## 单轮实施指令

1. spare只关闭本次处置，不标Withdrawn／Spared、不写永久处置锁、不取消捕获请求、不治疗、不解除拘押或改变势力。之后可再次右键继续攻击进入求饶、俘虏；醒来作为本场未退出敌人正常续战，尚未结束时不能因点过放过而跳过该敌人。
2. 同一战败财物索取最多一次，但“已经索取”仅限制再次索钱／索物，不能禁止再打开处置、俘虏或拒绝求饶。索财后关闭本次对话，也不自动退出战斗。拒绝求饶沿原受击转弥留，不清掉已有索财事实。金额、物品均来自真实资产，防止重新打开刷物。
3. 未提交的既有战场清理旧Spared的Withdrawn／WithdrawalKind；旧spare结果1可清，已索取结果2／3保留防重复交易。真正已提交战果与玩家正式撤退不重开。与原Flee／Surrender旧自动退出修复共用有限兼容入口，不改Snapshot v21协议或稳定枚举。
4. 去除头顶、结束原因和菜单中的“已获放过”特殊状态／门禁；正文与财物标签不再承诺永久放走。普通身体、攻击、距离、主控和抱持负担校验保留。
5. 只离线四程序集编译与最少静态检查，不启动Unity、不编写／运行自动测试，不提交推送，不改Freeze、地图备份、ProjectSettings／Packages。
