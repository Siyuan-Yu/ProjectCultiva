# 普通违规提示、跟随督工与旧暴露条退役

> **2026-10-28 最新追加已由[429](429-retire-personal-exposure-mechanic-2026-10-28.md)／ADR-0074覆盖暴露边界：** 制作人进一步要求直接删除，正式暴露组件、修炼累计和G降值入口已移除，仅保留旧档字段读取／旧命令号／旧资源ID兼容。下文保留Component和使用动作是本轮较早历史；督工、提示和惩戒规则不变。

日期：2026-10-28。状态：Design Confirmed / Implemented / Producer Acceptance Pending。规则决定见 ADR-0073。

制作人要求核对无实际作用的暴露值，并在巡视者发现未履行日程时明确提示“被发现没在做什么、现在该做什么”，发现者跟随，直到实际开始规定活动。

## 单轮实施指令

1. 旧 PersonalConcealmentRisk 当前只由修炼增加、敛息草降低并持久化，没有接当前范围／视线发现、追赶或惩戒。移除正式 HUD 的全局暴露条；保留既有 Component、存档及稳定输入协议，不擅自新增暴露数值后果。敛息草旧降值兼容也不表述为可躲过真实巡视。
2. 当前 50 格、真实视线、室外清醒资格与移动中当前位置继续有效。普通劳动／休息违规第一次实际被发现便显示发现者、违规者、“未劳动／未休息”和当前应做的活动；低于压力15时由发现者近身跟随督工，不在接触时自动开战。
3. 督工使用真实移动及个人控制权，持续跟随同一实际违规者，保持可用站位；玩家只是下令或正在走向工区／床不算已履行。真实开始规定活动或课表转为自由时结束督工，巡视者恢复自己的日程，不清零现有压力，仍按既有每 WorldTick 被发现+1／否则-1。
4. 原压力15满值惩戒、牢房禁区、秘密修炼／营地即时追战保留，直接执法优先于低压督工；已升级的惩戒不会因临时开始工作自动取消。失能、空间改变、解放或合法指令接管应释放督工所有权，不能留下死目标或强迫跟随玩家人物。
5. 沿既有黄村追赶人物引用与 ContentCounters 持久化一个督工模式标记：无标记的旧档沿原惩戒解释，不改变 Snapshot v21；普通督工不满足 IsPunishmentPair，不自动变惩戒战。接通日程、个人生活、Host 人物接近、冷热移动与读档。
6. 仅离线四程序集基础编译和最少静态检查，不启动 Unity、不编写或运行自动测试，不提交推送。保留427未提交修改和本地地图备份。

## 人工验收

巡视者移动途中发现误工／不休息，HUD及时显示双方姓名、缺失和要求，发现者实际跟来；低压近身不自动开战。远离原圈但还未履行，仍继续跟随，压力沿实际发现增减；真正开始耕田／规定劳动或休息后跟随结束，压力不突然归零。走向工区、暂停或只选中工作按钮不能提前解除。

检查劳动到休息的课表变化、同伴违规、重叠观察者不重复加压、压力15升级、督工中进入牢房／被发现秘密修炼的即时追战，以及督工与正式惩戒各自存读档。正式HUD不再显示旧暴露条，地图和战斗等原布局仍可操作。

## 实施与验证

SupervisorAngerDriver增加低压督工模式，复用原双方人物引用，ContentCounters持久化模式标记；首次真实发现设置要求，持续使用真实世界位置跟随，规定活动实际执行后释放原督工移动意图。使用既有日程所有权优先级、冷热导航、近人空闲站位及视线复验，旁边隔墙不算到达。原即时违法优先于低压督工；正式升级清模式标记，IsPunishmentPair明确排除低压督工。

HUD撤下暴露条，顶栏与操作提示区展示督工及具体要求，人物状态显示督工目标；旧数值Component、敛息草兼容操作和Snapshot字段保留。主管压力15／50格和原普通违规事实来源保留，农作仅原实际Work阶段算履行。
