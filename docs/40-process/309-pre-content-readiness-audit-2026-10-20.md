## 内容制作前建议收口顺序

1. **先收最近现场返修（P0，待人工结果）。** 307 的物件框／议政厅边界／蓝点／石牌，308 的上床、立即接人、四方向搬运和睡者参战姿态均为已实施待制作人复看；可集中在一次短场景中观察，失败按单一复现返修。306 的 Formal／Demo 工程外工具与存档槽隔离尚无逐项结果，可在下一次需要出 Demo 包时顺手核对；制作人已验过的基本打包／存读档、民生整套不重复要求。
2. **处理真实可见的“假功能”（P0，待设计选择）。** 正式工作面板枚举并允许选择 Medic，但 `MortalCivilianSystem` 明确显示专职行为未接入且 `MedicCare` 分支为空。不能让医疗床、搬运或动画暗示已经能治疗。内容体验若需要医者，先定治疗对象、药品、恢复量与出院规则再实施；若首段内容不需要，应在正式面板明确禁用并说明暂不可用。装备／制造、跨 Site 物流、完整交易等同属已明确延期的新阶段，不作为本次基础收口自动补做。
3. **做一小片统一美术样本（P0，美术／表现待制作人选择）。** 273 仍有 39 项 P0：26 项“已接入待验”、8 项“待确认”、3 项“待制作”、2 项“程序表现”。未达接入待验的真制作缺口为修炼垫／恢复点 `ART-ROOM-009`、石地／矿区底色 `ART-GROUND-004`、正式 HUD 皮肤 `ART-UI-001`；林地、田／药田、树木损毁、搬运组合、受击／工作反馈及整体风格样张有候选但需实际画面判定。用一处真实房屋、床、田、树、矿、人物与常用 HUD 在正常镜头下统一尺寸、落脚、遮挡、接缝、明暗和信息可读性，再决定批量替换；不以“55 项全部生成”作为开内容门槛。
4. **校准现行台账和正式 UI（P1）。** 307 已撤掉通用地点石牌，而 273 的 `ART-UI-007` 仍写“已接入地点牌匾”；`ART-UI-006` 也未记入新物件选中框，`ART-ANIM-003` 需区分本轮位置修复与尚无搬运动画。以当前运行接线修正 273 TSV，再同步 XLSX，历史记录保留。工作面板目前直接显示 ScheduleId、Bed StableAssetId、MovementOwner 等技术字段；正式面板应优先说明在做什么、为何停下、目标何处，技术 ID 留在诊断工具。
5. **最小声音反馈可随视觉样本补入（P1，非框架硬阻断）。** 当前 `Assets` 未找到音频文件，正式 Host 脚本未见 `AudioSource`／`PlayOneShot` 接线。若要让首次内容体验具有基本反馈，可优先给交互、工具接触、命中、收获／突破等高频事实配少量声音；不因此扩成完整配乐或音频中间件任务。

## 不作为内容前置的事项

不重开 Hex／Army／Legacy 退役；不删除 Demo 参考；不因为有 P0 美术登记就一次性重做全部人物／资源。Medic 全套、装备制造、跨 Site 物流、泛化 NPC AI、全地图地形装饰和完整音频系统都需要独立设计与授权。Formal 正式剧情开局、经济和 20～30 分钟游玩段本身属于下一步内容设计，不在准备阶段擅改参考开局或平衡。
