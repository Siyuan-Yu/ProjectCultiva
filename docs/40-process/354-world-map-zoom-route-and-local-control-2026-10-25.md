# 354｜世界图全景缩放、远程路线与场景行政范围

> 2026-10-25；制作人反馈世界图可缩得比整图还小、远距离右键规划等待过长，并希望在真实场景中淡淡区分各城镇的行政范围。状态：**Implemented / Producer Acceptance Pending / 未提交推送**。

本轮把世界图最远缩放限制为在当前 Game 窗口内基本完整显示主 Surface、四周留少量边距；初次打开也采用这一全景尺寸，缩回全景时自动居中。近距离放大、拖拽、选择与 exact WorldPosition 不变。

远程路线仍遵守精确地面逐格可走、禁穿角和已有通行规则。原先直线受阻后使用整个 15200×6800 网格做稀疏 A*；远距离路线可搜索大量无关格。本轮扫描地理时记下可走桥面各行的左右端点，直线受阻后先尝试经过桥两端的三段精确可走路线；仍找不到时，稀疏 A* 先在起终点连线两侧 96 格、再 384 格内搜索，最后完整范围兜底，不牺牲合法远路。规划继续在独立读工作区异步运行；取消仍可中止。

真实场景只增加轻量 Host 表现：从现有 TerritoryClaim／实际行政控制派生各 Site 区域，按势力色给镜头范围极淡的填充与边界，世界图打开时不重复绘制。缓存只在权威输入变化后重建；当前大陆各 Site 矩形不重叠时直接构造可视区域，若未来出现重叠则退回原有精确权威分区。它不参与导航、碰撞、土地权威或存档，也不把城墙解释成行政边界。城墙是实体建成区／防御设施，议政厅等级决定的是理论行政范围，两者本来不要求相同。表现随接管、升级和读档状态更新。

Core 与 Host 使用当前 Unity 响应文件基础编译均为 0 错误；静态差异检查无空白错误。未运行自动测试，未自行启动 Unity。路线缩时幅度、桥梁选择和场景淡色的实际观感仍须人工验收。
