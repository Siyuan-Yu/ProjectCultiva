## 1. 目标与非目标

把正式开局从“测试三任务”升级为可自由探索的荒村首段：认识生活秩序、接触村民、获得修行线索、在打坐点积累、尝试突破、自己选择后续方向。
不增加纹理尺寸、复杂模型或常驻特效；复用现有村民、将老、主管、守卫和设施。不给同伴甲乙强加固定身世或政治立场。
不声称完成从感应到筑基夺权的全部第一章，不使用任务旗取代实际战斗/外交/势力服务。

## 2. 接入方式

新增独立 openingScenario、characterRoster、chapter、quest、contentEvent 文件。正式绑定改用新开局，参考关、验收关及其稳定 ID 留存。

验收/骨架事件及任务用 missingFlag story:huangcun_production 排除正式模式；原参考模式仍可用于手动验收。
角色沿用现有 Character 定义；正式名册去掉青石验收假人，正式初始 Squad 去掉明确的验收队，不重新设置世界关系或 NPC 人生。
开局资源为首版内容调优值，写在独立剧本中，与参考关调试金钱分离；不改交易/产出/突破公式。

## 3. 内容路线

- 主管：说明配额压力与村内规矩，附庸仓库取用按当前权限；不强制接取每日教程。
- 田地、药田、木工村民：各自的现实小事和可选委托；交付通过现有 characterCommission 与物资扣除。
- 将老：保留每日棋局传承；“改日再来”不暗中接受任务，保留回头答应入口。
- 林边/药坡/洞府：用既有地点与探索事件记录发现；危险说明不凭文本自动战胜敌人。
- 修行：明确到打坐点、顾及饱食/精力/心境、感应积累与炼气学习门槛；任务只观察真实状态，不直接送境界。
- 后续：给继续劳动/结交、探索、去坊市的方向，不设章节结束按钮或自动夺权。
