# 人物动画语义、步态与附件绑定复核

> 状态：Implemented；Unity 人工验收待完成 | 优先级：P0 | 最后更新：2026-10-18

制作人反馈人物动作不流畅、劳动误绑和工具/攻击混用，授权本轮通查并修复。继续使用 Unity Transform/SpriteRenderer 共用骨架，不修改 Core、Content JSON、场景布局、Packages 或玩法结算；旧逐帧仅兼容回退。文件级清单与273资产族真源分离。

## 已确认根因与实施范围

1. `WorkAction` 既包括 Labor，也包括 Patrol/Inspect/Rest/Idle 等；旧 `IsWorking` 不区分，导致驻足巡逻、休息拿镰刀摆臂。改为读取 Running 状态、Activity、工区 Tags 和实际执行阶段，未知劳动不猜工具。
2. 受管居民农作/施工由 MortalCivilianState、MovementIntent 与实际 Host 农田/树木 executor 驱动，不能用残留 WorkAction 代替。行走、待寻路、失败、等待材料不做劳动；农作按播种/照料/收割/清理区分手势。
3. 工作手势、工具外观、战斗武器独立。播种/照料可以空手，砍树/采矿可持可替换工具；工作斧不自动成为战斗武器。当前没有正式装备物品 authority，本轮只提供可替换视觉附件，不新增装备玩法。
4. 旧骨架每种 Work 都是同一正弦摆臂，手臂左右图反绑，身体倾斜时头/臂不跟随。修正层级、关节、手握点和手势，动作之间插值。
5. 步态在 Walk/Idle 切换时归零；低速位移门槛偏大；到达最后一帧移动标志提前移除。改为由有效移动源提供本帧位移，保留相位并平滑停走；不把分离/传送/搬运位置同步当步行。
6. 议政厅、势力旗缺人物出手通知；远程与近战动作没有区分。补实际成功出手通知，视觉时钟与既有暂停/时间倍率协调，动画不触发伤害。
7. 部件相对排序可能与别的角色/建筑交错，标签压在部件下。骨架使用 SortingGroup，身体内排序与整人脚点排序分开。检查睡眠、弥留、尸体、Removed、搬运与新旧驱动切换。

## 验证边界

只做离线编译与必要的静态路径/资源完整性检查。遵守 AGENTS：不启动 Unity、不编写或运行自动测试。实际姿态、方向遮挡、步态、附件握点和性能由制作人在现有 LevelTester 人工验收。25 身份映射不等于全部动作绑定正确，前轮接线记录不能替代本轮语义复核。

本轮最终静态结果：152个Unity源码离线编译通过；25/25现有名录身份仍有映射；17份布局共126部件在源图范围内且rect互不重叠，归档/运行JSON相同；原PNG/运行PNG仍与原manifest SHA一致；新增17份布局meta和2份代码meta的GUID在Assets范围内唯一。Core/Data/Content/Packages/ProjectSettings/场景/Prefab无本轮改动，273未重写。

## 本轮实施结果

- 新增 `HostCharacterVisualContext`：读取真实农田执行 Phase/CropStage、在范围内的树木 Session、WorkAction.Activity/Status、工区或地点 Tags、受管居民 Activity/HostArrived、已交材料的施工 job、进食阶段及 Cultivate/RecoveryAction。行走、待寻路、失败、等待材料、巡逻/检查/休息、尚未接入的医者意图不播劳动。通用农田批量结算只有“到达并农作”的信号时播放照料，不虚构逐格播种/收割阶段。
- `HumanCommonRigEquipment` 单独管理工作工具与战斗武器。`WorkTools` 以手势枚举覆盖 Sprite/握点/尺寸/角度，空 Sprite 可隐藏工具而保留工作手势；`Override Weapon` 独立控制战斗 Sprite 和 Unarmed/Swing/Thrust。`EntityView.EquipmentVisual.SetWorkToolAppearance`、`SetWeaponAppearance` 可供未来正式装备适配器调用。当前仅 View 生命周期内的视觉参数，重建后不冒充存档或装备物品权威。Idle/Walk 可持当前战斗武器；劳动不借战斗武器；结束工作不会把斧头带入空手普攻。拳/爪主动技按现有定义使用空手手势，远程普攻使用 Cast；睡眠、倒地、被搬时隐藏手持物。
- 两批17张图导出126个 alpha 连通部件范围：12套九部件、12个方向头像及6件工具/背篓。`*_layout.json` 记录 rect、肩/髋/颈 Pivot、标准显示高度和握点；运行/归档副本同 SHA，manifest 关联。布局缺失或非法时拒绝骨架初始化并回退，移除固定九格及经验工具分割线的运行残留。原PNG和已有PNG `.meta` 均未改。
- 左右臂改为画面左右正确分配；头与双臂跟随 UpperBodyBone，工具挂在真实手握点；停走保留相位、降低过快步频并插值关节姿态。移动执行者逐帧记录实际位移，包含到达末帧，不再依赖提前清理的 IsMoving。Squad 的实际 tick 投影只把已观测位移分摊为持续步态，首帧加载不当作行走；没有改变宏观根位置的 WorldTick 投影方式。攻击视觉时间参考现有倍率并限速，暂停不推进姿态。
- 实际成功的树木劳动与战斗攻击分开；补议政厅、势力旗、远程、主动技与缺打击特效组件时的出手通知。动画不触发伤害或产出。初始 Rebuild 和后续 AddMissing 均接相同驱动；Profile 重配会清理旧 Skin，实体失效会隐藏骨架/卧姿/攻击残影。
- 整套骨架增加 SortingGroup，避免多角色/建筑与单个肢体交错；标签始终在整人之上。EntityView LateUpdate 排在搬运位置同步之后；被搬者仍是本人 Skin，使用侧向静态姿态；搬运查询按世界/帧集中缓存。

## 仍需明确的边界

医者 Profession 的 `MedicCare` 在当前 Core 选择/执行路径尚未接入（已有诊断为“专职行为尚未接入受管凡人执行：Medic”），本轮不新增治疗玩法或假治疗动画。正式物品武器装备系统也尚不存在；更换视觉附件不会改变背包、伤害或存档。旧 LegacySprite 的整身帧本就包含工具，保留兼容时仍有自身动作/装备限制，不能作为可换工具骨架来承诺。

现有人物手臂/腿仍主要复用正面图，部分原躯干带袖形、侧背剪影/不对称差分仍需美术返工；本轮修正确认的范围、层级、Pivot 和接线，不能凭编译确认所有关节外观合格。宏观NPC根位置仍按WorldTick投影；本轮只平滑对应步态，未更改该移动/碰撞接线。高时间倍率步频上限也意味着不能保证完全无滑步。

## 最少人工验收

1. 正常镜头观察主角/同伴、巡卫、居民停走、慢走、转向及1×/2×/5×暂停恢复，核对脚底、肩颈、握点、标签和相邻人物遮挡。
2. 播种/照料空手，粮食收割持镰、药草收割手采，清理持锄；伐木、采矿、施工用各自手势；前往目标、阻挡、巡逻和休息不做劳动。受管批量农作与逐格农作按各自真实阶段检查。
3. 在人物的 HumanCommonRigEquipment 中替换或清空 Chop 的工具 Sprite，确认砍伐手势保留；独立替换 Weapon 并选择 Swing/Thrust，确认劳动不覆盖武器，空手拳/爪或远程动作不拿出劳动斧。记录附件切换后的握点/尺寸。
4. 抽查普通战斗、议政厅/旗帜出手、救援/押送/材料搬运、床/地睡眠、弥留/尸体，以及切回旧驱动。当前只完成离线编译及静态资源检查，未声称现场通过。
