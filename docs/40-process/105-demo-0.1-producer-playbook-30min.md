# 105 · Demo 0.1 制作人手操脚本（约 30 分钟）

> 入口：Unity 打开 `Assets/Scenes/DemoParityHost.unity` → Play  
> Scenario：`base:scenario_ch01_reference`  
> 若组件缺失：菜单 `XianXia/Demo Parity/Create Or Update Sample Level Scene`

## 操作底线（开局弹层也会写）

| 操作 | 说明 |
|------|------|
| 左键 | 选人；可框选三人 |
| 底栏 | 移动／停止／交互／战斗(占位)／修炼 |
| 交互 | 再左键工区：麦田／树林／药田／矿洞 |
| 修炼 | 再左键灵泉／洞府 |
| 右键 | 空地移动；热点可前往交互 |
| 首次入区 | 自动勘察 |
| Space／F10 | 暂停／显隐 HUD |

**己方三人不会按课表自动干活**——必须你点。

## 时间线（目标 ≤35 分钟）

### 0～3′ · Day0

1. 读开局事件 →「知道了，开始巡视」  
2. 已在农田：走开再走回，或点交互勘察农田 → 完成「巡视杂役区」

### 3～10′ · 杂役＋三人分派

3. 任务「调度·三人分派」：凑齐粗粮≥1、粗木≥1、灵药≥1  
   - 建议：一人麦田、一人树林、一人药田（也可一人连跑）  
4. 粗木≥2、灵药≥2 → 完成伐木／采药交差  
5. （可选）进矿洞听老倔怨气

### 10～18′ · 探索发现

6. 进灵泉 → 听异响选项  
7. 再进树林 → 砍柴老人「愿闻其详」（或枢纽再探索找行商）  
8. 经枢纽进废弃洞府 → 探索完成

### 18～28′ · 秘密修炼＋突破

9. 在洞府点「修炼」→ 领悟青云诀（残篇）  
10. 再入定／站稳洞府 → 暗修任务  
11. 再入洞府 →「引气入体」→ 多次修炼至炼气

### 28～35′ · 收束

12. 回房屋区 → 三人隐藏约定  
13. 回道路枢纽 → 权力伏笔 → 弧完成（`story:ch01_ref_arc_complete`）
