## 5. 制作人手操脚本（约 25～35 分钟）

见同目录 [105](105-demo-0.1-producer-playbook-30min.md)。摘要：

1. Play `DemoParityHost` → 开局弹层「知道了」  
2. 勘察农田 → 分派三人凑粮／木／药 → 交差伐木采药  
3. 灵泉听异响 → 树林老人（或枢纽行商）→ 洞府  
4. 修炼学诀 → 再入定／引气 → 炼气  
5. 房屋隐藏约定 → 枢纽伏笔收束
