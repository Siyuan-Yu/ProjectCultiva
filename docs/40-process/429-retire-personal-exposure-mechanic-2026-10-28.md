# 移除旧暴露值机制

日期：2026-10-28。状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人明确“暴露值没什么用了，可以直接删”，本轮覆盖428只隐藏HUD条、保留运行机制的旧边界。决定见ADR-0074。

## 单轮实施指令

1. 删除正式运行的PersonalConcealmentRisk组件、修炼暴露计算和相关Unity meta；取消创建人物、开局补件和读取存档时挂载该组件，修炼不再累计暴露。普通日夜显示改读既有DayClock，不依赖旧暴露规则。
2. 清除剩余HUD／调试快照风险读数、敛息草顶栏、G降暴露快捷键及降值成功反馈；敛息草不再有降暴露使用动作，新开局公库停止自动放入旧专用品。既有资源ID和玩家已持有物品仍兼容，不擅自改成新药物、删除背包物品或退款。
3. 旧输入枚举UseConcealGrass=14保留为退役编号，不重排稳定数字。收到旧命令在中断行动、下棋、移动或扣物资前明确失败；Host残留调用同样不得停止现有指令或消耗物品。
4. Snapshot v21保留只读旧字段兼容位置，但不再将旧值写入运行人物，新写JSON停止输出personalConcealmentRisk。旧档缺字段或带旧值均可读取；不抬升格式号，不更改其它字段和身体／督工存档。
5. 正式发现继续由当前50格、实际视线、室外清醒与行为事实决定，主管压力15和督工／正式惩戒不改。Demo Runtime依AGENTS只读保留其独立旧原型，不将其玩法迁入正式运行，不修改Freeze／ProjectSettings／Packages。
6. 文档先更新，基础离线编译及最少静态引用、内容JSON检查；不启动Unity、不编写／运行自动测试，不提交推送，保留427／428工作和本地地图备份。删除的已跟踪代码可从Git历史恢复。

## 人工验收

新开局、读取旧档后修炼及保存，不出现暴露数值／风险读数；日夜时钟正常；G不再使用敛息草，旧命令不扣库存或打断当前活动。旧敛息草物品可正常留在旧背包／公库，正式巡视、督工提示、按日程解除及压力15惩戒保持。
