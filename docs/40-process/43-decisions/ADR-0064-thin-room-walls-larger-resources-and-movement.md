# ADR-0064：等厚房墙、资源放大疏排与移动倍率

状态：Design Confirmed / Implemented / Producer Acceptance Pending。

制作人要求房间保持已扩大的整体尺寸，但墙体不能随房间放大：房墙与外城墙同为一 Surface cell 厚。全图树木、矿石按当前 0.0.43 的长宽各乘二，重新疏排；人物步行速度为当前 1.5 倍，斗气化翼速度为调整后步行的两倍，参数需可继续调整。

后续制作人明确荒村内也留少量树木：从城外移回八棵现有中树至村内空地，保留两倍大小，稀疏且避开房门、道路和农田药田；不按“城内全部清空”执行。其他城市不变，具体位置与交付见 397 的疏树追加。

- 房屋外矩形、家具位置、逻辑墙段及可破坏 ID 不变。渲染和冷热通行同步采用一格厚边缘，角落使用相接的横纵薄墙；门洞保留已有宽度，门框深度回到一格。外城墙边界与厚度不变。
- 全部树木、矿石扩大真实矩形，保留稳定 ID 与资源类型／数量。城内留通路并降低密度，空间不足的树矿移至附近可行走的城外地带；作者蓝图画布可扩展，但城址、城墙、建筑、行政范围、地形与河流道路不移动。资源之间留空隙，避开房门、田块和主路。
- 现有 worldSpatialRules 内容增加 `walkSpeedMultiplier=1.5`、`flightSpeedMultiplier=2`，后者相对步行。WASD、点击寻路、NPC、离屏个人与小队移动读取同一参数，不修改世界时间倍率、移动 authority、起飞资格或灵力消耗。混合空地小队按地面倍率，全体起飞才使用飞行倍率。
- 不新增 Snapshot 字段，不修改 Core/Data 分层或 Freeze；未来调整直接编辑内容参数。作物五／十日成熟及此前住房、设施权限规则保留。

交付与人工查看见 [397](../397-thin-room-walls-resources-and-movement.md)。不启动 Unity，不编写或运行自动测试，基础编译与必要静态文件／几何核对后由制作人实玩验收。
