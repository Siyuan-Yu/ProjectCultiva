# ADR-0067：简化战斗伤势、恢复苏醒与金丹遗骸移接方向

日期：2026-10-27。状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人本轮明确授权，以最后“无需疼痛、出血、止血、具体部位割伤”的补充为准。

采用[408](../408-simplified-injuries-and-remains-grafting-2026-10-27.md)的唯一实施指令及首版可调参数：50%以下可能割伤、25%以下可能重伤、打昏可能断肢／断经脉、弥留95%断经脉；普通伤随真实恢复消退，残肢／经脉不会因补HP消失。首次战败保留1HP，但废止ADR-0065的固定100秒苏醒，昏迷和稳定后的弥留统一超过50%HP才恢复清醒；倍速影响身体进度。已有明确补刀和显式死亡确认保留。

新增独立伤势组件及Snapshot v21，不改已冻结空间、时间、控制、队伍权威和稳定枚举值。旧JSON按已有迁移路径转成新恢复模式，不补掷随机伤势。属性减益按已有Modifier管线派生。

金丹后移接他人遗骸、跨境界承载限制、适配与炼化为Design Confirmed / Not Implemented，本轮不做遗骸物品生产、移接手术或经脉修复系统。运行边界及人工验收见408，编译不等同人工验收。
