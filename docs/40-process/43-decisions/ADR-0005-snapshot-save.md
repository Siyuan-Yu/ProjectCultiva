# ADR-0005：快照存档，不做完整事件回放

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

世界账本与因果需要可追踪，但完整 Event Sourcing／全游戏回放成本过高，且与频繁改规则的开发期冲突。

## 选项

**A. 完整 Event Sourcing + 回放** — 可追溯强；存档体积、迁移、性能与实现复杂度高。  
**B. 纯快照无历史** — 实现简单；失去差异化“世界记得”。  
**C. 快照 + 未执行 ScheduledEvent + 必要 Ledger／短日志**  

## 决策

选 **C**。不做完整游戏回放。只保证存档恢复、固定 Seed 测试可复现、关键事件可追踪。

## 影响

- 见 `2E`、`33` §1／§6。开发期破坏性变更升 `SaveVersion`。
