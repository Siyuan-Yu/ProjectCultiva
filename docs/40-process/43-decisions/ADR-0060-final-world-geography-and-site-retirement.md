# ADR-0060：定稿世界地理与旧据点逐项退役

> 日期：2026-10-26。状态：**Producer Design Confirmed / Implemented；Producer Acceptance Pending，未封板**。制作人明确批准按[378 定稿图与实施交接](../378-final-world-geography-gate-handoff-2026-10-26.md)迁移正式地图，退役图外据点；旧档原文件保留，新内容版本提示新开局。本 ADR 只修改主世界新开局的内容集合，不修改 Snapshot schema、枚举数值或 Core／Data 权威边界。

> 制作人随后明确选择**八个人类宗门，严格按定稿图图例**。九宗是此前讨论阶段的数量，不作为本次发布目标。现有非宗门边境势力与无主城镇是否保留，按逐 Site 表和最终作者落位明确，不因颜色相近自动并宗。

## 决定

### 2026-10-26 两个集中宗门追加授权

制作人要求从当前 22 个无主城中划出两个各 4～5 城且尽量集中的宗门。按 [388](../388-two-compact-sects-and-next-step-2026-10-26.md) 落地为天麓宗、听雨宗各 4 城，分别位于魔兽山脉北侧和东部河流下游；保留 14 个无主城，总数仍 66。当前有城势力为 10 个人类宗门加朔风堡，覆写上方此前“八宗”的内容规模，不改变既有权威边界或重开迁移。仅新增势力 Content、初始归属和地图主城；人物、任务及专属系统不在本轮范围。

### 2026-10-26 风暴城与雷暴双关追加授权

制作人按红黄框批准 [383](../383-storm-thunder-gates-2026-10-26.md)：风暴城迁到东侧，飓风／雷暴区域共享边界填补中间平原，雷暴区西、南两处新增入口城并用外围山体与城墙约束地面进出。实现名雷西关／雷南关，中立三级，保留五级空间；现有 64 城保留，总数增至 66。只迁风暴城，不挪其余 63 城；不新增天气伤害或修改飞行规则。

### 2026-10-26 两处小盆地封口与桐溪镇迁址追加授权

制作人确认 [382](../382-basin-seals-and-tongxi-relocation-2026-10-26.md)：西阵／东阵盆地、南赢镇盆地改为封闭山圈，取消原自动道路缺口；南赢镇及盆地整体南移 360 格，与魔兽山脉分开；桐溪镇移至魔兽山脉与极寒雪原之间。此项替代这两盆地旧入口城语义与两城旧坐标，其余 62 城和全图尺寸、飞行规则保持不变，不增设传送或暗门。

### 2026-10-26 圆形盆地与魔兽四关追加授权

制作人确认 [381](../381-round-enclave-and-beast-gates-2026-10-26.md)：荒村用约 960 格直径自然圆形替代 720 格切角方形；魔兽山脉外围新增连续山带及四座中立入口关城，原定稿 60 城不动，合计 **64 城**。保留内部高原、原城镇实体及扩建空间；独立增补作者数据不重新解算原全球压缩，西侧山线局部接合河东岸西关并新增过河桥，北侧山线避让桐溪镇五级空间。此为经批准的地理增补，替代此前“仅定稿 60 城”的内容数量限制，不修改移动速度或通行规则。

### 2026-10-26 空地压缩追加授权

同日后续局部覆写：制作人明确要求荒村盆地恢复 **720×720 格**，不沿用图面放大后约 1250×1163 的山圈。按 ADR-0057 保留五级城框和每边 90 格空间、山带向外铺设，保持城心及全球地理不变。作者配置 `openingBasinSizeCells` 在全球压缩映射确定后才应用，因此局部收圈不会再牵动其他城市／河流。

制作人批准在保留 60 城、城镇实体尺寸及 540×540 五级扩建空间的前提下，适当压缩空地；宽高减少约 15% 是方向而非硬指标。此授权替代下文“全部距离统一等比”的要求，不替代定稿地理关系：山脉包围、盆地内外、关口与城市绑定、河流两岸及入口顺序必须保持。飞行和世界旅行速度本轮不改。

实施采用有保护区间的单调坐标压缩，同一映射用于地形、城址、河道、道路和锚点；小盆地整体、关口邻域和紧邻城镇间距优先保护，城镇蓝图只平移，不缩尺寸。以作者源生成三份运行地图并提升内容版本，旧存档不自动迁移。同步修复北部角色排序消失，复核床位几何与床边出生修复，针对现有性能采样中的已知热点优化；未经新人工采样不得声称帧率回升。实施与验收见 380。

**2026-10-26 制作人追加确认：以定稿图实际 60 个城镇图标为准，允许补齐漏城、撤下图上不存在的城。** 原 57 城及图例部分数量为首版误读；本轮 56 个旧 Site 保留、52 个退役、新增 4 个稳定 Site。城市中心、地貌轮廓、关口、山脊与河道以同一图面坐标等比复原，图面并非仅供“大致方位”参考；具体数字化转换和精度见 378。荒村仍全封闭，但盆地边界按定稿多边形而非旧方形，灵阵两端绑定实际作者物件。八个人类宗门不变，实际青霄 5 城、镇星 4 城，以图标覆盖图例旧数字。此为本 ADR 的内容细化，不新增玩法权威。

1. 主世界正式 Site 以逐项迁移清单为发布依据。**图上没有的正式城镇应真正从新开局世界中退役，不能只在地图层隐藏。** 旧的 108 个固定 Site 不再因 [ADR-0055](ADR-0055-fixed-council-hall-sites-and-five-level-control-range.md) §2 而必须全部留在新开局主世界。保留者沿用原 ID；退役 ID 不复用于其他城镇。若新增定稿城镇，赋予新的稳定 Site ID。每个旧 ID 必须有 `保留并迁址`、`合并至目标 Site` 或 `退役` 结果，并清理其正式蓝图放置、地点、人物、任务、经济、道路与宗门归属引用。
2. 新旧内容包采用版本隔离。发布新主世界时提高 BaseGame 内容版本，旧存档不被覆盖或静默平移；读档按现行 `IncompatibleContentVersion` 路径提示新开局。不得修改现有 Snapshot schema 数值、旧档的 Site ID 字符串或原存档文件。若日后要求导入旧档，另行设计离线转换。
3. 地形、河流、城市、势力与关口按 [WORLD-REF-020 定稿 PNG](../../../ArtSource/References/WORLD-REF-020_world_geography_final_concept_v01.png)排布；图片仅是地理意图，正式精确位置由作者源的 Surface Cell 坐标表决定。荒村及其全封闭开局盆地原样保留，当前等级城框与五级理论框的含义不变，所有五级框需有明确间隙。
4. 镇岳、极寒、火脉、青霄／青草盆地及蛇人沙漠的地面入口以真实可走坡口或隘口连到对应固定关口城；其他周缘以 `Mountain`／`Solid` 阻断。无飞行资格的地面路径不能越过山崖，也不能因世界图旅行、道路绘制或城市理论范围而穿越。金丹及以上沿既有 [ADR-0059](ADR-0059-plateau-entrances-and-flight-crossing.md) 的斗气化翼越崖，落在合法可走格；仍保留同伴与荒村开局限制。
5. 人类城镇只在定稿图所示适居地、地貌入口及特别注明的风雷夹地落位。魔兽山脉核心、蛇人沙漠内部及极端气候核心不因旧 Site 存在而保留人类城市。妖族／魔兽部族后续用独立标识和内容设计，不把被退役人类 Site 偷换为妖族城。

## 与已有决定的关系

- 替代 ADR-0055 §2 中“102 个旧旗 Site 全部保留原 Site ID、名称及对外引用身份”的**主世界新开局内容数量**要求；其唯一固定 SiteCore、等级 1～5 行政范围、升级与接管规则继续适用于本轮保留或新建的 Site。
- ADR-0056 的五级范围互不接触继续有效。ADR-0057 的荒村闭合开局盆地继续有效。ADR-0058 的开局无主旧营与玩家后续建势力规则继续有效，若该旧营在最终定稿没有城市图标，须在逐项清单中明确身份和开局玩法落点，不得静默删除。
- ADR-0038 的 Continuous Surface authority 不变；不重新引入 Hex／Army Runtime 路径。

## 发布门槛

正式发布必须有逐 Site 迁移清单、精确新坐标与五级间距、所有入口城到山崖通道的几何对位，以及作者源与三份运行地图的同源发布记录。基础编译与最少量静态引用检查只证明接线；地图外观、地面／飞行通行、读档提示及开局体验仍由制作人人工验收。未获人工验收不标记 Producer Accepted。
