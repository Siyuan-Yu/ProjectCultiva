# ADR-0007：多队伍分级模拟

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

玩家将同时拥有多支分散队伍。全部完整加载渲染不可行；全部只做战报又损害实时战略感。

## 选项

**A. 所有地图始终全仿真全渲染** — 不可扩展。  
**B. 切走即冻结** — 违背统一世界时间。  
**C. 镜头全仿真 / 同区远处简化 / 跨区低频实体 / 远方抽象 Tick**  

## 决策

选 **C**。“持续模拟”不等于“始终完整加载渲染”。

## 影响

- 见 `33` §8。远景 UI 显示队伍位置、任务与危险摘要。
