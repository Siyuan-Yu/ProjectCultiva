# ADR-0007：多队伍分级模拟

- 状态：**已采纳**（**2026-08-22：修士 LOD 由 [ADR-0024](ADR-0024-real-cultivators-and-army-strategic-model.md) 进一步明确**）
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

玩家将同时拥有多支分散队伍。全部完整加载渲染不可行；全部只做战报又损害实时战略感。

## 选项

**A. 所有地图始终全仿真全渲染** — 不可扩展。  
**B. 切走即冻结** — 违背统一世界时间。  
**C. 镜头全仿真 / 同区远处简化 / 跨区低频实体 / 远方抽象 Tick**  

## 决策

选 **C**。“持续模拟”不等于“始终完整加载渲染”。

## 2026-08-22 补充（ADR-0024）

ADR-0024 进一步明确：**所有修士都是持久真实 Character**，但仍按 LOD 分级模拟（Cold / Strategic / Hot），与 ADR-0007 **不是冲突关系**：

- ADR-0007：多队伍／多区域的**模拟与渲染粒度**
- ADR-0024：修士**数据实体**必须真实 + Army 战略载体

两者叠加：离屏修士保留 CharacterState 并低频推进；仅 Hot 层实例化 LocalMap Actor。
