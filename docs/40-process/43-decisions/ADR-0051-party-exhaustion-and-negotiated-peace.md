# ADR-0051 队伍力竭与多轮停战谈判

> 日期：2026-10-21。状态：Design Confirmed / Implemented / Producer Acceptance Pending。规则与当前实施记录：[318](../318-npc-ai-closure-and-peace-negotiation-2026-10-21.md)。不改 Freeze 数值／稳定 ID。

1. 玩家主动休息安排全队；队员不自行离队找粮。低需求提醒，精力耗尽时本人保留真实位置原地卧倒，恢复后再行动。力竭不是弥留、死亡或新人物身份。
2. 多轮停战谈判由 Core 持有、Host 编辑展示。条款限定实际公库资源、双方实际俘虏释放及整个对方势力附庸；普通自由人物不可交易，释放不等于招募。没有新增押送过程，原主动捕获链保留。
3. 成交停止双方势力战争，复用现有绑定参战方的 War，不另造一次接触停火 authority。保留原阵营、伤势、地点所有权与关系历史；新附庸复用既有 Vassalage 与 Alliance 边界。
4. 先校验完整条款，再同步成交一次。提案、反提案、轮次与成交记录存档；读取只恢复状态，不重放交付。人物位置、冷却、需求、资源、关押、战争仍各归原有真实 authority。
5. 保持 v17，以可选字段延伸 wire，旧档默认没有新谈判；不改已封板版本数值，不删除存档。首版 AI 还价与需求阈值属于待人工验收的实施参数，见 318。
