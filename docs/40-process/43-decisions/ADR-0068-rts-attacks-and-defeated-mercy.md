# ADR-0068：战中RTS攻击与战败求饶处置

日期：2026-10-27。状态：Design Confirmed / Implemented / Producer Acceptance Pending。依据制作人本轮明确追加，按[410](../410-rts-attack-and-defeated-mercy-2026-10-27.md)接通当前荒村独立战斗直接链；其他空间／通用个人背包的边界以410为准。

覆盖317／409的NPC低血劣势自动撤离／投降：NPC继续到约1%HP昏迷失能，清醒敌人红色攻击光标右键直攻；倒地后再右键继续攻击，进入战败求饶处置，放过／索真实物品／索真实灵石／拒绝转弥留，弥留再显式击杀生成尸体。放过不回血、改势力或解除原拘押。

不修改已冻结空间／时间／队伍权威或稳定协议值。战败轮次／处置事实复用已持久化ContentCounter，财物复用真实钱包、背包和携带权威；目前无通用NPC个人背包，物品候选仅列真实可交付携带物，不能生成假战利品。遗骸移接不在本轮。
