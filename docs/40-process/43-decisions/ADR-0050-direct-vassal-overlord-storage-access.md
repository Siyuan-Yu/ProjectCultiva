# ADR-0050：直接附庸访问宗主势力仓库

> 日期：2026-10-21｜状态：Design Confirmed / Implemented / Producer Acceptance Pending
> 制作人本轮明确选择“开放完整仓库取用”，而非仅允许 NPC 生活进食。定向覆写已封板 [VASSAL-WORK-01](../260-vassal-work-01-direct-vassal-labor-access-2026-09-24.md) 的“宗主仓储隔离”条款；其农作、建造、拆除和行政权限结论不变。

## 决定

1. 行动势力就是据点 Owner，或行动势力是该 Owner 的**直接附庸**且双方未处于战争状态，才可访问该 Owner 在有效据点的势力仓库。联盟、兄弟附庸、宗主反向访问附庸、中立及已解除附庸均不授权。关系从现有 `FactionDiplomacyRelationQuery` 实时读取，不缓存附庸标记。
2. 玩家在有权限的宗主据点内，可像在己方据点一样打开“势力仓库”、查看可用战略资源并按现有背包容量规则取出；战略资源消费继续使用现有原子扣除／回滚。仓储网络按**当前据点的真实 Owner** 聚合其有效仓库，不把宗主资产改记为玩家资产，也不使玩家离开有权据点后继续远程取用。现有 UI 没有存入操作，本决定不新增存入功能。
3. 处于当地、具有同样权限的非队内附庸人物，可按原有热区抵达储藏室／冷区同 Site 抽象扣粮流程吃一份公粮；受管凡人与非凡人使用同一资格。无粮、无有效储藏室或失去附庸关系时不得凭空进食。非凡人队员沿用队伍背包自动取食；凡人队员保留既有 Site／背包取食优先序。玩家可从有权仓库按既有 UI 取出食物。
4. `TryResolveCurrentManagingSite` 与建设、住房、日程、SiteCore、拆除等严格管理 authority 保持原语义：附庸能取仓储资源，不获得 Site Owner 身份或建造权。解除附庸或进入战争后，下一次查询及实际扣除立即拒绝，不依赖打开面板时的缓存。

## 兼容与验收

- 不改 Snapshot schema、ID 或旧存档数据；权限从已持久化的附庸／战争关系实时派生。
- Ch01 新开局在青石荒村：玩家势力作为黄村势力直接附庸，应能打开仓库、看到宗主真实库存并按现有规则取至背包；初始粗粮库存实际为 **0**，因此须待真实收获或用现有验收入口补粮后，再核查未入队同伴甲乙饥饿时确实扣除一份当地公粮，不能因授权而凭空进食。解除附庸、宣战或离开有权据点后应失去该仓库入口与扣粮资格；玩家仍不能在宗主地建造或管理住房／日程。8 程序集离线编译通过，未运行 Unity 或自动测试；人工验收未完成。
