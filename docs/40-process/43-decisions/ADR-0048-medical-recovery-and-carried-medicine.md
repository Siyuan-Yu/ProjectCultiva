# ADR-0048 医者床边治疗与伤势恢复权威

> **2026-10-27 医疗续接：** [ADR-0067](ADR-0067-simplified-combat-injuries-and-remains-grafting.md)／[408](../408-simplified-injuries-and-remains-grafting-2026-10-27.md)新增非弥留自然恢复与简化伤势愈合，昏迷及稳定后的弥留均实际超过50%HP清醒，固定苏醒计时退役。医者也照料未痊愈的普通床上伤员，普通药不能修残肢／经脉。真实药物取送、床位及拘押权威保留；身体进度随模拟倍速，新增v21存档及旧JSON迁移，不重排稳定枚举和旧版本值。

> 2026-10-20 后续授权补充：[313](../313-medical-closure-and-ground-loot-2026-10-20.md)将未使用药草的转职归还/死亡落地接通；GroundLootState仅记录物品、数量和精确地表落点，Pickup复用原服务，View随加载区派生。Snapshot v17保存此新增权威，v15/v16 JSON在内存补齐，原档不自动改写；v15的零HP Captured由于旧实现已清弥留计时，明确补一次200储备救治窗口。其他医疗数值、库存权威与时间入口不变。

日期：2026-10-20。状态：Accepted（制作人本轮授权），Implemented / Producer Acceptance Pending，未封板。

## 决定

以[312](../312-medic-bedside-treatment-2026-10-20.md)为本轮已确认数值与实施范围。替代此前医疗床永久停止弥留、Medic延期的临时规则，不修改WorldTick、控制或库存权威，也不增加生命周期枚举值。

1. `LifecycleComponent`持有本次伤势储备、持续药效、恢复中昏迷标记及小数HP。`MedicalRecoveryService`在现有WorldTick/遭遇真实秒入口推进；恢复中仍为Incapacitated，严格超过50%HP才苏醒。Captured是拘押权威，带伤Captured同时可失能；苏醒不得解除拘押。死亡仍按既有统一确认入口执行。
2. 单位采用整数千分之一，防止−0.2/+0.2的累计丢失。属性`HealthRecoveryRateMilli=23`在现有Modifier管线叠加外部恢复来源。骨骼或动画事件不参与治疗结算。
3. 已从库存扣除、尚未施用的一份药由医者civilian state持有；患者目标、取药来源与操作进度一同持久化。领取和施用是两个独立原子步骤，读档不重演领取。患者床位仍由真实设施占用权威决定，不用标签替代。
4. Snapshot v16保存这些新增权威；v15由JSON读取器在内存显式补齐为v16，保留其余身份、位置、库存、日程、床位与进度，不自动覆盖原文件。v16缺少关键医疗字段应明确拒绝；v1～v14按已有床位权威边界拒绝，不静默重置。旧程序拒绝v16，避免旧代码丢掉新增医疗权威。

## 本轮不做

主动灵力疗伤、功法/装备内容生产、工作优先级矩阵、玩家Party成员自动抢占移动、专用医疗动画及新床等级系统均未实施。当前医疗用途床统一按中级+0.2处理。
