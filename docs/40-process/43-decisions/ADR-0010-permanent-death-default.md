# ADR-0010：角色默认永久死亡；剧情重要≠不死

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结增量）

## 背景

需要决定重要 NPC／队友是否“剧情锁血”。锁死后世界因果与选择感变弱；全员可死后又怕卡主线。

## 选项

**A. 剧情重要默认不死** — 简单；削弱后果。  
**B. 全员默认可死 + 可选 TemporaryProtection** — 后果真实；作者显式保护关键窗口。  
**C. 自动复活／替身** — 破坏永久死亡语义。  

## 决策

选 **B**。`IsStoryImportant ≠ CannotDie`。默认 `DeathProtectionMode = None`。

## 影响

见 `33`／`34`。复活若存在须极高阶单独设计，非默认能力。
