# ADR-0054：金丹境界与斗气化翼

2026-10-24，制作人明确批准337整套框架扩展与美术。Design Confirmed，Implementation状态维护于337；未人工验收。

新增GoldenCore=3，保留0/1/2；金丹、结丹均能解析。当前单段筑基之后追加金丹门槛：修为30000、基础成功率25%、大境界突破；奖励生命120、攻击35、防御25、灵力120、神识20、体魄12。沿用既有修炼、突破仪式和成败规则，暂无金丹小境界及元婴。宏观境界权重追加30（筑基10、炼气3不变），避免新境界落入凡人默认权重。

FlightComponent是Core飞行状态，Snapshot v18保存开关、Surface/战场上下文、最近合法落脚点及混合队伍分离信息；v15/16/17读取时缺省落地，禁止修改现有枚举和ID。正常位置仍由既有Continuous Surface/exact WorldPosition负责。

F3展开/收起，金丹起，展开耗80灵力且至少留1点，不另外叠加每秒耗灵；灵力仍承担既有护盾消耗。F2仍单独展开远程纱衣。山水墙林可飞越，边界／荒村解锁／空间准入仍生效。手动落地需合法地面；失能、灵力归零时优先落到附近合法格，必要时用同上下文的最近合法落脚点，重验地形后提交。不能删除校验靠读档强塞进障碍物。

非飞行角色对飞行角色的合法攻击，在接触时独立以IRandomSource做75%闪避；多段斗技逐段判定。空对空不额外闪避，空对地不加倍率。建筑算地面。飞行不能扩大攻击距离，未展开远程模式不能用地面近战攻击距离攻击另一高度的人物。无状态免疫、无飞行无敌。

地面同伴不得共享空中位置；跨障碍时保留各自位置并由原可通行路线跟随，不能直接传送。户外遭遇沿用原战场位置／返还权威。室内洞府禁飞，进入前先落地。

双翼采用程序化低面数光翼、轻摆与离地偏移、阴影，复用现有材质，不引入高分辨率贴图。Host只处理输入、导航坐标适配和表现，不决定境界、闪避概率或伤害。
