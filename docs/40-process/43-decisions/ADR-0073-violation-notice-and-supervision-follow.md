# ADR-0073 — 普通日程违规先提示并跟随督工

> **暴露部分已由[ADR-0074](ADR-0074-retire-personal-exposure-mechanic.md)／[429](../429-retire-personal-exposure-mechanic-2026-10-28.md)覆盖：** 不再保留正式运行组件与累计／降值动作，仅保留旧档只读兼容和稳定编号。本ADR的违规提示、督工与正式惩戒区分继续有效。

日期：2026-10-28。状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人授权范围及编译／人工验收边界见428。

## 决定

发现普通日程违规不再只有无说明的压力变化。显示发现者、目标、未做的规定活动和当前要求；压力未满15时，发现者真实跟随目标督工，直到目标实际履行当前日程或进入允许自由活动时段。接触督工目标不自动开战。主体失能、空间或管理关系失效则释放督工；正常遵守只结束督工，不重置共享压力。

保留50格观察半径、实际墙体视线、每WorldTick压力增减、暂停和倍率。压力满15仍升级既有追赶近身惩戒；牢房禁区与秘密修炼／营地即时追战优先，不能借督工模式或刚开始工作取消已成立的正式惩戒。

旧暴露值只是修炼风险累计显示，不是当前发现判定。正式HUD撤下其全局条，保留稳定Component／序列化与旧输入兼容，不新增基于该值的发现、投掷或惩戒。

## 边界与持久化

Core拥有发现、活动合规及督工模式，Host只显示要求并执行原导航。复用HuangcunSurvival既有人物引用，加ContentCounters模式标记；旧档无标记维持原追赶含义，Snapshot v21不变。督工须与正式惩戒明确区分，不改变宣战、身体、派系、招募、俘虏或空间真源。详细人工验收和实施结果进入428。
