# ADR-0035：统一行动小队与固定范围独立遭遇

> 日期：2026-09-13
> 状态：Design Confirmed；CW-U0 Producer Accepted / Sealed；CW-U1 Implementation Completed / Producer Acceptance Pending；独立遭遇与关系介入仍待后续。
> 制作人 CW-U0 最新决定。实施与验收入口：[220](../220-cw-u0-design-and-manual-entry-placement-2026-09-13.md)。

## 1. 唯一行动小队

每个正常活动角色属于唯一行动小队，单人也是一人小队。玩家、NPC、旧巡逻／守备军队使用同一组织模型；多人小队实际同行并共享行动目标，但人物各有真实位置、移动、生命与物品。落后、绕路、弥留不会自动解散或免费传送归队。

PlayerParty 最终只表达玩家所控小队与单 Active，不维护第二份可独立写入的成员名单。保留最多六人、固定顺序失能接替。队伍关系不改人物 Faction、HomeSite、家庭、私人关系。FormalArmy 不再是具有专属战斗入口的正式玩法类型；旧类只作迁移适配，不机械改名删除。飞舟运输延期，目的地倾向建筑仅为后续方向，飞舟不替代小队。

## 2. 统一玩家遭遇生命周期

普通人物、玩家成员、旧 Army 成员统一走：实际接战前确认 → 同源临时独立战场准备 → 初始双方入场 → 战斗及有限合法介入 → 唯一结算／战报 → 各回自己的战前世界锚点。当前地形、门墙桥、建筑与破坏状态必须真实；不把旧模板改名，不创建能独立死亡／掉落／获益的 Character 副本。

主世界暂停，本场战术时间运行；返回只恢复空间，保留伤亡、消耗、关系、建筑损伤等真实战果，禁止恢复整份战前快照。远处无玩家的 NPC 战斗仍自动处理，不加载全世界独立场景或冻结世界。人物冲突与正式战争后果继续区分。

## 3. 战场范围唯一规则

2026-09-13 制作人补充锁定：一级议政厅与一级势力旗共用核心等级 Content 配置，控制范围均为以核心真实 Continuous 世界位置为中心的 **500×500 世界单位正方形（X/Y 各 ±250）**。这是控制/行政/建设管理/遭遇范围，不是建筑自身 placement、sprite 或 collision 尺寸。预设旧核心缺等级仅按旧格式幂等迁为一级；损坏的新格式拒绝恢复。不做逐 Site override，不预设二/三级数值。野外 Encounter 单独配置，V1 同为 500×500，但以实际接战位置为中心。重叠沿用现有有效控制归属规则，不借此扩展 CW-04。

以实际接战地点解析有效 WorldSite。在 Site 内，取该 Site 当前议政厅／旗核心的控制范围定义，中心必须为核心真实位置，大小／形状与核心控制范围一致；新旗站与预设城镇相同。重叠按有效控制选中一个 Site，不合并多个范围，不另造脱钩的物理场地范围。

没有有效 Site 时，使用以实际接战点为中心的固定正方形，边长来自真实世界单位的 Content 配置。500×500 只是示例，不是 500 Unity 单位常量。不能以 HomeSite、Faction、Army marker、Hex、相机或 loaded window 选择范围；双方跨 Site 边界也不自动改用野外。范围入场准备时固定，追击、人数、介入、核心损伤或易主均不改变中心／尺寸。

若固定范围不能合法容纳必要成员／通路，实施时必须在入场前明确处理，不能继续沿旧“为必要通路自由扩边”的建议暗中扩场。

## 4. 初始双方与有限关系候选

初始名单只含发起者当前小队和目标当前小队。第三队不因势力、守备身份、附近、同／邻 Hex 自动加入，不使用 OptionalFriendly／Hex support。双方同队成员不随机缺席，但必须验证各自真实位置、生命和会话占用。必要成员不能合法纳入已选战场时，进入前报告，不漏人、不扩场、不用群体锚点传送远方队员。

开战时按真实空间查询固定范围内的人物；初始双方之外，符合关系条件者只进入有限候选。候选暂不显示、不可攻击、不计胜负／报告。范围外者本场永不补入候选，不递归朋友网络。双方对称，按人物／小队有限时点和概率判定，避免每帧重抽及同队逐人放大概率。

已判定、决定、待到场、已加入等事实必须持久化；读档不重抽、不重复加人／结果。正式加入通过明确事件追加实际名单，让显示、攻击、控制资格、胜负、报告一起更新。本场身份固定不意味着名单永久不可追加。入场位置与返回锚点取候选自己的真实位置，不任意从边缘或玩家背后刷新。临时援助不修改永久小队、玩家控制、背包权限、Faction。

最终结算前最多一次有限续战；未决定者不能无限阻止结束，最终结算后不接受加入。

## 5. 入口与阶段

统一地面遭遇上线后，退役玩家 WorldMap 右键敌军直接攻击、宣战接战和追击后自动攻击；保留查看、普通选点／前往，保留地面战斗、战争数据与 AI 合法服务。UI、命令和旧回调一起核查。本轮只记录。
