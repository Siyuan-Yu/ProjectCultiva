# ADR-0065：荒村巡查惩戒与昏迷／弥留分阶段

状态：Design Confirmed / Implemented / Producer Acceptance Pending。依据制作人本轮明确流程要求，不扩展到未指定的完整制作或自由扩张系统。

制作人补充确认：当前先落实真实运转的规矩、NPC 行为和后果，可以有强硬的世界内反馈，让玩家逐渐理解处境与玩法；玩家保留遵守、躲避、承担后果和反抗的选择。不得为预定体验强制发现或战败。本轮尚未进入新手流程制作，不加入必须点击某项才能继续的教程步骤、操作锁或固定顺序；后续引导单独设计。

**昏迷计时最终澄清：** 制作人在选择“现实时间 100 秒，暂停除外”后进一步明确倍速必须影响苏醒，20 倍速应为约 5 个现实秒。因此以最后澄清为准：一倍速基准 100 秒，N 倍速约 100/N 现实秒，暂停不推进；保持现有世界 Tick／战斗时间计时，不改为与倍速无关的现实秒倒计时。

制作人再次明确主管压力同样随倍速：每连续五个 WorldTick 增一点，一倍约五现实秒、二十倍约 0.25 现实秒，暂停不增。新增在岗巡视范围圈，直接展示 Core 二十格范围和在岗资格；已开始的惩戒追赶临时占用 NPC 局部行动，不能被普通巡逻／生活任务覆盖，结束后释放。整条接线复核与表现交付见 [399](../399-huangcun-discipline-chain-audit-and-watch-rings.md)。

- 两名巡卫昼夜错班，甲 06:00–18:00 巡逻，乙 18:00–06:00 巡逻，其他作息相差十二小时；主管沿用间歇巡查。仅能行动、处于 Patrol／Inspect 日程的人员观察，同 Surface 精确位置二十格半径内发现主控原开局劳役人物没有按规定工作或休息，每累计五个世界秒主管怒气加一（上限 100）；多人同时看到不重复叠加。自由时间、实际工作／休息、合理农作执行及失能不算违规，离开观察范围中断本次五秒积累。
- 怒气满后由发现者实际接近发起正常 CharacterEncounter，不锁定胜负、不额外扣血、不宣战／自动占村。惩戒敌方不补刀倒地人物；首败保留至少一 HP、进入昏迷，允许玩家正常击败巡查者。此流程在解放后停止。战后怒气归零，记录和战斗身份需持久化以免读档绕过或错发起。
- 既有村界巡卫门禁同步使用二十格观察范围与同一能值守判定；失能、休息或非巡查人员不继续拦路。门禁作为既有移动规则保留，不把发现违规改成无条件开战，也不扩大盆地开放范围。
- 战斗第一次打空生命进入“昏迷”，不是弥留；保留一 HP，不自动补满。昏迷不能行动／战斗，倒地身体与位置保留；清醒前再次遭主动攻击才转为弥留（零 HP）。弥留普通攻击不转尸体，右键显式“杀死”通过现有正式死亡确认。既有弥留自然恶化与治疗、尸体腐烂规则保留。
- 暂按现有身体计时的 1× 世界秒口径设昏迷 100 秒：户外每 WorldTick 计一秒，暂停不推进；遭遇战冻结世界时按对应战斗时间推进，倒地者可在战斗仍进行时苏醒并重新参战，HP 仅保留实际恢复结果。制作人若补充计时口径则以补充为准。
- 所有敌方不能战斗时判胜，昏迷已算击败。战斗返回只恢复空间，不重建或覆盖 HP、昏迷、弥留、死亡状态；已结算战斗不会因战场逗留后的苏醒重新开启。
- 复用 LifecycleState.Incapacitated 失能总类，增加独立昏迷剩余时长，禁止借用医疗 Convalescing 标记或改既有枚举数值。Snapshot 追加所需计时／惩戒数据并升级 schema v20，不更改既有稳定数值、ID、Core/Data 分层或 Freeze。
- 医疗搬运复用原真实接近／搬运／床位预约流程，同时接受昏迷与弥留者。优先医疗床，满员再选病人自己的住宅床；仅对本次荒村原劳役人物允许村民跨势力救护，不开放通用跨阵营救助或绕过被囚同伴解救。

实施及人工查看见 [398](../398-huangcun-discipline-and-unconscious-combat.md)。不启动 Unity、不编写或运行自动测试；基础编译及最少必要静态接线检查后交制作人实玩验收。
