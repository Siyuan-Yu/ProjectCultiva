# ADR-0056：五级据点仍彼此分离的世界重排

> 2026-10-25。状态：**Producer Design Confirmed / Implemented / Producer Acceptance Pending**。制作人以世界图现场反馈确认此规则；本页补充 ADR-0055 的布局要求，不改五级范围、稳定 Site ID、Snapshot schema 或 Continuous Surface authority。实施与人工验收见[347](../347-five-level-town-separation-implementation-2026-10-25.md)。

## 决定

1. 108 个现有固定 Site 无论所属势力，均按未来**全部升为五级**的 675×675 Surface-cell 理论行政方框排布。任意两处方框不得相交或贴边，中间保留至少 **75 cells** 的轴向净间隔。此 75 格是本轮实施取的可见野外缓冲下限；城镇实体蓝图也不得互压。未来新增 Site 必须遵守同一布局预算。
2. 主 Continuous Surface 从 7600×3400 扩为 **15200×6800 cells**，格子世界尺寸、50×50-cell chunk、世界权威不变。108 个旧 Site 的 ID、名称、类型、Owner、初始等级和既得顺序不变；新开局重排中心、建筑蓝图、地点／人物／服务锚点、道路和地形制作坐标。行政间隔不是不可通行的空白：道路、林地、山地、资源与事件仍可布置在其间。
3. 当前三档初始等级不变（荒村一级，青石及 102 迁移据点三级，另四处一级）；五级 675 格只是**最终全升级布局预算**，不自动给所有据点升级。理论行政范围和实体城区仍分开。
4. 扩图发布必须避免将全图新增成本转嫁到每帧加载。作者数据与运行地图、世界图缓存和地理导航必须同步；采用保留现有精确格权威、按 Chunk/视野物化、世界图降采样缓存及必要的运行数据压缩。旧档继续以 BaseGame package version 隔离，文件保留，需新开局。

## 实施与验收

实施记录与迁移坐标表见[347](../347-five-level-town-separation-implementation-2026-10-25.md)。人工在世界图观察五级预演间隔、在荒村—青石及宗门据点间走路、跨 Chunk 与 20 倍速采样；编译或静态几何校验不等同于制作人验收。
