# ADR-0004：CSV／JSON 混合配置真源

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

需要可 Git diff、可 AI 批量编辑的配置，同时支持嵌套规则。纯 ScriptableObject 不利于合并与评审。

## 选项

**A. 仅 ScriptableObject** — 编辑器友好，diff 差。  
**B. 仅 CSV** — 平面表强，嵌套弱。  
**C. 仅 JSON** — 嵌套强，大表编辑体验一般。  
**D. CSV + JSON 混合，同类型单一真源；SO 仅缓存**  

## 决策

选 **D**。CSV 用于平面表；JSON 用于嵌套／复杂规则；同一数据类型只能有一种真源格式。

## 影响

- 加载失败必须报行列；禁止静默默认。  
- 见 `33` §1、`31`。
