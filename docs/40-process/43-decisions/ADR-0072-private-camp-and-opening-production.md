# ADR-0072 私人营地标记与荒村首版生产

日期：2026-10-27。Design Confirmed：制作人明确授权补全荒村首版，并追加“发现秘密修炼／营地即开战、先打人后拆建筑；无告密；先立小范围标记再建造”。Implementation：2026-10-28 已实施，Producer Acceptance Pending，完整清单与验收见[425](../425-huangcun-opening-completion-2026-10-27.md)。

## 私人营地不产生行政领地

复用原旗帜美术作为私人营地标记，禁止重新接回建旗创建WorldSite。城池所有权、TerritoryClaim及议政厅占领不变。普通Outdoor仍用SurfaceId与精确WorldPosition。

营地标记作为持久实际物件，占地1格；首版建材粗木4、半径24格。只能在无城池行政控制的可行走地面放置，封闭开局仍不能越出盆地；需要人物真实在附近。圈内可自行建已有可用房间、床、墙和粮田，不需要先拥有城池或招到建筑工。每个建筑完整占地必须落在同一合法营地圈内，保留重叠、地形、房门与家具几何约束。营地库存属于私人库存，每个实际房间独立存放粮木药／四矿三锭各30，旧存货迁入原房，不冒充城池公库。标记归属与营地成员关联用既有ContentCounters持久化，物件／位置／耐久用OutdoorConstructedAssets与既有毁坏状态，不改Snapshot稳定数值／ID，不改Freeze。

旧两个预设地点停止作为新建入口；旧已建营地保持真实资产，原房床可继续使用，玩家另立合法标记后可扩建。立标记不自动生成棚屋、床或资源。摧毁标记取消后续建设权，不凭空删除现存建筑／人物；实际建筑逐个受击毁坏。建造为实际到场、WorldTick耗时、完成时重新验位置和材料的行动，暂停／倍速同世界时间。

## 发现与惩戒

清醒未修炼且在室外的主管／巡卫，45格内有真实视线时观察。普通日程违规检查原开局在队自由人物，重叠观察和多人违规每Tick最多加一点。牢房禁区、村外秘密修炼、营地建造及发现私人营地属于立即追赶开战，不等待压力满；没有告密、随机全知搜查或离屏凭空发现。人物先沿真实战斗击败；巡卫存活、未被击败且附近无可战对手后，接实际接近与逐次攻击营地建筑，保留破坏和剩余物件。玩家可以反抗，不能固定必败；不对已昏迷者自动补刀杀死。

## 首版生产参数

矿点共享储量：铁／铜各24、银12、灵矿8，单份10 WorldTick，挖空十游戏日后恢复；玩家背包已有铁镐可缩短为7 Tick。矿工产出进所属城公库，玩家进私人背包；实际到场且有权限才开采。无工具耐久和高阶矿门槛，未来扩展不能冒充本轮完成。

基础加工为炼器室／丹室实际到场行动：铁／铜／银矿冶炼、铁镐、凝神器、疗伤散、培元丸；输入输出与耗时统一在BasicCraftService配置，成品必须有真实使用效果。普通药和丹药不修复断肢／经脉，不跨过突破瓶颈。取消／离开／战斗不扣未完成材料，完成事务复验。

## 边界

本轮实现首版，不引入完整强制教程、NPC告密、世界扩铺、金丹遗骸移接或完整高阶丹器树。珍稀作物与苛刻长期栽培未被本次追加规则明确要求实现，保持后续扩展；不将这些未来方向写成已交付。运行体验由制作人人工验收。
