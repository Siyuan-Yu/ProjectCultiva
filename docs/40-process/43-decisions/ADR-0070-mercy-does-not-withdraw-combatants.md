# ADR-0070：放你一马仅结束当前处置

日期：2026-10-27。状态：Design Confirmed / Implemented / Producer Acceptance Pending。

制作人明确覆盖ADR-0068／0069的Spared永久退出语义：“放你一马”同暂不处理，只关闭本次对话，人物状态、伤势、拘押、敌我和战场资格不变；之后仍能再次处置，苏醒后正常续战，不保留“已获放过”人物状态。索财成功也不使人物退出，仅保留同次战败已经索过财物的持久事实，禁止重复索钱／索物而非封锁所有处置；拒绝补击不覆盖该索财事实。

旧未提交Spared清理退出标记，旧索财记录保留；已提交战果与正式撤退不重开。复用既有ContentCounter和Encounter字段，不改稳定枚举／Snapshot v21／空间时间权威。实施与人工验收统一见414。
