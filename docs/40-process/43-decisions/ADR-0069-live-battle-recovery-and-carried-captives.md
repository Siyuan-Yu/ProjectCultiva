# ADR-0069：未结算战场苏醒续战与一对一抱持俘虏

日期：2026-10-27。状态：Design Confirmed / Implemented / Producer Acceptance Pending。

依据制作人本轮明确要求，补充ADR-0068：ReadyToEnd仅为当前可结束状态，未提交时双方重新有清醒未退出人物则续战，前端按钮和提交入口均复验；已放过人物、正式撤退和已提交战果不重开。苏醒仍按ADR-0067真实HP超过50%，不恢复100秒计时。定向修订ADR-0033／0034旧目标OR胜利的即时结束入口：目标已达成仍须处理存活交战者，Resolved与Active可并存；已真实占领／破坏事实保留，不撤销行政结果。

倒地敌人在实际靠近后可直接俘虏。复用Captured及CapturedEscorted／CarrierId持久事实，覆盖真实人物而非只限逃亡凡人；不生成匿名俘虏、不给修士新增凡人职业。每名抱持者最多一人，不能同时搬运另一人／建材；保留移动、原有飞行资格，禁止攻击和不兼容劳动。俘虏恢复仍拘押，抱持者失能或主动放下则原地解除抱持并保留身体；未放过且已清醒的人可以重返本场交战。战内位置跟随抱持者Tactical，返场后跟随抱持者正式位置，不能把战术坐标当世界坐标。

不改变稳定枚举值、Snapshot版本、Freeze或程序集边界。房间选择／面板是Host输入适配，规则和权限继续由既有Core房间服务负责。实施与人工验收统一见412。
