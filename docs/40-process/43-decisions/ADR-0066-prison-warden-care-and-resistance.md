# ADR-0066：监管真实照料与拘押抵抗

状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人明确批准；唯一实施说明见 [405](../405-prison-warden-care-and-recruitment-2026-10-27.md)。

监管作为真实凡人岗位，物资从合法储藏室取出、携带到本人附近才交付，取消玩家管理囚犯的抽象公粮及“吃睡降低原势力忠诚”。抵抗独立于忠诚及五维关系，以既有 ContentCounter／Daily 保存每日照料事实和进度；关系仍只读 RelationshipLedger。工作与活动枚举只追加末尾值，监管携带物增加可选字段，存档版本／稳定旧值不变。招募复用势力归附事务及对人对白，近场、管理权、清醒、抵抗和关系共用后端校验；不移动、不治疗、不自动入队。同伴乙免招募，保留原直接释放。

本决策局部覆盖267及ADR-0044的抽象囚犯取食／每日降忠诚／拘押招募条款，不改 Freeze、现代空间 authority 或既有投降等待招募规则。四程序集基础编译通过，人工运行验收待完成；未启动Unity、未运行测试、未提交推送。
