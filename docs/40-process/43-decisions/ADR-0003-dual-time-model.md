# ADR-0003：双层时间模型（WorldTick + ActionClock）

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

模拟类需要统一世界日夜与日程；RTS 战斗与移动又需要细粒度推进。单一时间轴要么过粗要么过细。

## 选项

**A. 仅细帧时间** — 世界日程难对齐，离屏贵。  
**B. 仅粗 Tick** — 战斗手感与施法过程难做。  
**C. WorldTick + ActionClock** — 世界用 Tick；场景行动用 ActionClock，且不独立跑世界日期。  

## 决策

选 **C**。1 Tick = 15 游戏分钟，1 日 = 96 Tick。暂停／倍速统一影响全世界。战斗不是独立冻结世界的时间模式。

## 影响

- 见 `33` §3、`21`、`35`。  
- Demo `GameClock` 映射为表现入口 + 双钟驱动，而非逻辑真源。
