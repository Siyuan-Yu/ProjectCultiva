# ADR-0053：筑基主控定向远程普攻

2026-10-24，制作人明确批准定向射击扩展。Design Confirmed；实施与人工验收分别记录于336。

沿用F2斗气纱衣、筑基门槛、原开销与普攻间隔。主控开启后WASD移动、鼠标瞄准、按住左键向固定方向发射；每发命中第一个合法敌对人物后消失，飞空不结算。Host适配鼠标、可见坐标、逐段扫掠与既有导航遮挡；Core校验施放者、合法敌对、战场及实际伤害。沿用现有可见弹体命中后调用Core伤害路径，不新增Unity依赖或存档字段。

不绕过独立遭遇确认；普通户外仍先使用原战斗入口进入战场。洞府等Separate Space保留原地战斗。中立、友方、投降撤离者和倒地人物不由连续扫射自动攻击；补刀和建筑攻坚仍使用原显式指令。只有当前主控切为手动射击；NPC与同伴保持原战斗调度，不能同时为主控自动锁敌攻击。显式交互／建设优先于射击，暂停／菜单／UI不发射，恢复输入后须重新按下左键；切主控、换世界或战场、失能时清理旧射击。

手臂朝鼠标瞄准、身体八向朝向复用现有骨架，腿部保持行走混合；不引入飞行、不提高贴图精度。固定射线不追踪目标，扫掠避免低帧率穿漏；墙体遮挡用现有通行网格的保守视线规则。
