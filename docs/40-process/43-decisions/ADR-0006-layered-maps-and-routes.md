# ADR-0006：分层地图与跨区域 Route

- 状态：**已采纳**
- 日期：2026-07-31
- 决策者：项目负责人（架构冻结收口）

## 背景

需要城市连续空间与跨城旅行，但不做整片大陆无缝 3D／巨型连续地图。

## 选项

**A. 整片大陆完全连续** — 内容与流式成本不可控。  
**B. 仅离散关卡瞬移** — 削弱飞行与途中遭遇。  
**C. WorldMap + RegionMap + InstanceMap + Route／EncounterMap**  

## 决策

选 **C**。RegionMap 尺寸可变；跨区域用 Route 与遭遇；Instance 状态永久保存。

## 影响

- 见 `33` §7、`24`。废弃“统一 1.5 屏”规格作为硬约束。
