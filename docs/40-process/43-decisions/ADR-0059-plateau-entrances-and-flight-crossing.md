# ADR-0059：高原入口与斗气化翼越崖

日期：2026-10-25。状态：**Producer Design Confirmed / 正式地形实施待后续世界地理落位**。

高原是同一 Continuous Surface 上**可以站立与探索的高处地面**，不是不可达的整块 Mountain，也不是独立 Space。周缘陡崖阻止普通地面角色直接横穿；若干明确的坡道或山口把平地与高原顶面连起来，地面寻路只可由这些入口上、下高原。入口不必只有一处，首轮镇岳概念图示意三处。制作人随后确认魔兽山脉核心与西南火脉群峰也可按此原则设计为高原；它们的正式坡口数量和坐标尚未落位，妖域核心仍不布置人类城市。

金丹斗气化翼沿既有 [ADR-0054](ADR-0054-golden-core-flight.md) 的飞行权限越过周缘山崖，可直接飞抵高原上方，但落地仍必须找到合法的高原顶面格；不开启飞行时不能把高原边界当作可直穿的平地。既有同伴分离、灵力／失能、荒村开局边界和地形合法落点规则继续适用；本决定不赋予低境界或地面随从飞行资格。

正式落地时，以现有 `Plain / Mountain / Water` 基础地形和 Continuous Surface 导航表达：高原顶面是可走地面，周缘是不可地面通行的山崖带，入口形成连通的可走廊道；Host 只绘制高度与入口表现。概念图的三处入口、位置和地名尚非已发布坐标，须在完整地理作者数据中落位，并同时核对现有城镇、道路、河流与五级扩展范围。本 ADR 不单独授权修改 Snapshot 格式或 Core／Data 边界。
