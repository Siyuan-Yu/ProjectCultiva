# ADR-0001：Unity 版本与渲染管线选择

- 状态：**提议中**
- 日期：2026-07-29
- 决策者：`[待确认]`

## 背景

本机已安装的 Unity 版本：2018.3.9、2019.4.31、2019.4.40、2020.3.11、2021.2.13、2021.3.11、2022.3.6。

项目会长期开发（跨设备、跨时间、可能交接），版本选择需要兼顾：长期支持、生态与文档丰富度、AI 辅助编码时的知识匹配度、换机器时的可重现性。

## 选项

**A. 2022.3 LTS（本机已有）**
- 优点：本机已装，无需下载；LTS 长期修复；生态与教程覆盖充分；Cursor/AI 对该版本 API 的知识准确度高
- 缺点：不是最新，部分新特性缺失

**B. 更新的 LTS（如 6000 系 LTS）**
- 优点：更长的官方支持周期；新特性
- 缺点：需下载安装（数 GB）；AI 与社区资料相对少；部分插件兼容性未知

**C. 2021.3 LTS**
- 优点：极稳定，资料最多
- 缺点：偏旧，未来升级跨度更大

## 提议

选 **A（2022.3 LTS）**，渲染管线先用 **Built-in**（若确定要后处理/2D 光照再切 URP，切换成本在 2D 简单场景下可接受）。

理由：本机已有、可立刻开工；LTS 保证长期稳定；AI 辅助时 API 匹配度高，能显著减少排错时间。版本一旦确定就**锁定并写入文档**，禁止随 Hub 自动升级。

## 影响

- 工程创建后在本文件补充精确版本号（含 f 号）
- 换设备时必须安装完全相同的版本
- 若后续必须升级，需新开 ADR 记录原因与迁移步骤
