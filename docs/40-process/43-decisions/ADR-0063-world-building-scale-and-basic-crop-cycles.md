# ADR-0063：全世界建筑家具两倍与基础作物周期

状态：Design Confirmed / Implemented / Producer Acceptance Pending。

制作人对 1.5 倍实玩效果仍不满意，明确将所有城市的建筑、房间与家具实际长宽定为最初尺寸的两倍，并选择同步调整所有城市；农田明确指定 12×8 格，药田按当前 10×8 再放大 1.5 倍为 15×12。普通粮食从播种到成熟为五个游戏日，当前基础草药为十个游戏日。

## 采纳

- 全部 66 座既有城镇的主体建筑、房间、床、蒲团、棋盘、仓储／恢复家具和炉具使用原尺寸的 2 倍，不在当前 1.5 倍上再翻倍。既有物件稳定 ID、房间逻辑分格、住户与床位绑定、材料、工时及容量保留；动态新建和私人营地同步使用两倍物理矩形。
- 全部粮田地块 12×8，全部药田地块 15×12，实际耕作格同步扩大。重排城内房间／田块／家具，留主要道路、房门和床边净空；城址、城数、归属、外墙边界、行政范围及世界河山道路不整体放大。
- 已有正式外城墙保留，城内旧散落围墙随本轮重排清理；密集住宅并排布置，门前至少两格走道连接主路。自然树木矿石仅调整冲突位置，不减少资源数量。
- 荒村保留 12 间普通住宿（10 人需求＋2 间备用），粮田药田继续紧邻住宿；练功室、功法阁、斗技坊继续集中在主管／巡卫住房附近，占领前仅三名管理人员可用、解放后开放。
- WorldTick 仍唯一世界时间轴，每日 288 Tick。基础粮食 `crop_grain` 成熟耗时 1440 Tick，基础药草 `crop_spirit_herb` 耗时 2880 Tick；暂停不成长，游戏加速按世界时间推进。自然成长由 Core 执行，读档、离屏及重复照料不能额外催熟。
- 移除 Host 每次照料直接增加 34% 成长的捷径。播种从零开始，照料保留现有劳动动作，不引入未设计的浇水、肥力、枯死或照料惩罚；成熟之前不能收获。
- 沿用现有持久成长比例，不扩 Snapshot 形状；每次从比例还原本作物的整数成长 Tick，再推进世界 Tick，避免浮点累加使五／十天提前或拖后。未知作物不能猜一个成熟周期。

## 后续方向，尚未实施

天材地宝种子可具有一年、两年或更长成熟时间及苛刻栽培条件。具体种子、时长、灵气／土壤／环境等条件、失败与照料规则仍需单独确认；本轮不生成新种子、不添加条件字段、不把未设计品种接到普通粮草规则。
