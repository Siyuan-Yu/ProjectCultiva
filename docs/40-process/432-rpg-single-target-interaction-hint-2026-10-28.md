# RPG单目标交互提示与F直达菜单

日期：2026-10-28。状态：Design Confirmed / Implemented / Producer Acceptance Pending。制作人截图指出431的附近目标列表混入住宅／房门，要求直接按头上提示与指定目标交互，本轮覆写431的F目标列表设计。

## 单轮实施指令

RPG模式靠近有效人物／可使用物体时，只确定一个当前交互目标，在其头顶或物体上方显示“▼ F 交互”及对象名。按F直接打开这个目标的原交互／对话／战败处置菜单，不再出现找谁交互的列表。近处人物优先于物体，同类按距离选择并保留小范围稳定性；普通跟随队友不能始终抢占身旁NPC提示。按键时复验同一被提示目标的距离、可见性、视线和身份，不跳到未提示对象，不隔墙／远距离交互。

排除房门、房间地板、住宅、普通工区、仓库、交接点等纯建筑／管理对象，以及其重复逻辑热点。保留人物、床／恢复处、农田矿点、伐木、修炼／探索／拾取、真实动态机会等实际行动入口；非战斗左键建筑查看及原管理功能不删。核心／旗等显式宣战入口沿既有右键／管理面板保留，不列为日常F候选。墙仅在当前正式战斗允许破坏时作为可操作对象，不在日常与NPC争提示。普通清醒交战敌人由左键攻击，不用F攻击；倒地处置仍可F／右键原菜单。

提示是Host只读派生表现，按短周期重选、每帧复验当前目标，不每帧全世界查询，不写存档。菜单／剧情／大地图／设置等输入锁占用时隐藏，距离失效或切主控不保留旧提示。场景RTS和地图赶路开关、身体、宣战、照料与工作原权限不变。

只做基础编译及最少静态／diff检查，不启动Unity、不新增或运行自动测试、不提交推送；保留此前修改与本地地图备份。

## 实施结果

已删除目标选择界面及对应私有阶段／滚动状态。Host按0.2现实秒周期从加载登记表重选目标，每帧只复验当前目标；人物优先，同类距离差0.25以内保持旧目标，切主控／世界／输入锁立即失效。人物锚点用真实可见身体顶边，物体用其几何／使用点，显示具名“▼ F交互”，提示本身不截获鼠标。按F优先复验上一次实际显示的目标，不因当前重选到新邻居而无提示跳转。

收紧人物和物体候选、删除宽泛Work热点回落，普通跟随队友、清醒交战敌人、建筑管理对象与日常墙体不抢提示。RPG右键纯管理对象同样不弹菜单；房间左键检查、核心／旗原显式宣战入口保留。实际可用物体与囚犯／倒地人物仍走原动作权限，不改变世界、身体或存档。

Unity／Unity.Editor／Tests三程序集离线编译通过（仅编译，未运行测试）；旧列表入口引用无残留，diff检查通过。两处已有测试源码警告未改动。未启动Unity、未提交推送，现场提示位置／切换及实际交互待人工验收。

## 人工验收

走近截图中的NPC，其头上出现具名F提示，按F直接出现他的原菜单，无住宅／房门／重复目标列表。身旁跟随同伴不抢占提示；多人靠近只显示一处，走向另一人后切换。离开范围／隔墙／切主控／打开菜单提示消失或正确更新，按F不与旧目标交互。非战斗左键仍可查看房间，靠近床、田、矿点、树或物品有对应提示与原动作；战斗左键、倒地处置、牢房探视及地图赶路不回退。
