> 恢复后追加：补齐独立遭遇的同源WalkGrid攻击视线，墙后接敌点也需有视线；ReadyToEnd明确手动纱衣补刀允许合法失能者，自动弹体不补刀。命中复核射手／目标／场次；非建筑攻击规则变更。见329。

## 当前能够用于第一章的能力

- NPC 已有非凡人三档生活倾向、凡人职业日程、真实吃饭／休息／医疗、蒲团自主修炼至瓶颈与棋盘独立席位。318 已接全队主动休息、力竭卧倒、冷热移动与冷却存档、多轮停战；319 的新席位几何以 321 为准。以上属于已接线范围，人工状态仍按各原记录，不重新建立验收总表。
- 户外玩家交战使用 CharacterEncounter；洞府在当前 Separate Space 原地交战。现有近战、筑基纱衣远程、已装备主动斗技、默认不攻击重伤、伤势／死亡／返场、300 战术秒后撤退及和平资格足以支撑第一章战斗内容。
- 境界以现有基础吐纳、功法学习、瓶颈／突破、灵力资源与筑基纱衣表现推进。22 的高阶飞行、驭器、法宝、内丹、神魂和空间能力仍含未决规则，不能把“境界编号存在”解释为全部权限已实现。

### 第一章引导必须使用的实际成长门槛

- `CultivationService.CanAttemptBreakthrough` 与现行阶梯允许感应境无功法吐纳、手动突破；感应前／中／后期所需修为分别为 100／200／300，下一阶为炼气一层，基础成功率分别为 95%／95%／90%。第一次炼气给予 50 灵力。感应后期必须先得功法的旧叙事已被既有实现及 Devlog 2026-08-15 的“感应期不卡功法”记录替代，本轮不修改概率、修为或突破平衡。
- 炼气及以后冲击下一阶需已学功法，仍需 Alive、修为满瓶颈与已配置下一阶。自动生活只积累至瓶颈，不替玩家突破。
- 功法研读需背包有真实秘籍、`teachesManualId` 指向有效定义、人物 Alive 且有修炼／属性组件，并满足 RequiredRealm。当前 Mortal 门槛功法只允许感应境，炼气功法需已到炼气；学习会概率判定，不能把“拾到书”写成“已经学会”。
- 斗技研读需真实秘本、有效 `teachesArtId`、Alive／属性／CombatArts 组件，按神识与品阶判定学习概率。当前斗技没有独立境界门槛字段，不写成“必须筑基才能学习现有裂爪击／开山拳”。最多装备六栏，现有主动技分别为三连击／4 秒冷却与单击／5 秒冷却。
- 运行 RealmStage 目前只有感应、炼气、筑基。筑基纱衣固定消耗 60 灵力、需要至少 61 才能展开，远程普攻射程 7；飞行、法宝、神魂、金丹以上机制尚不能成为当前第一章任务的可完成条件。

### 第一章多物资委托追加核对

`QuestService.TryDeliverToTarget` 逐项扣除物资，公开服务独立调用时缺少整体回滚；`CanDeliverToTarget` 对重复 ItemId 没有合计，可能显示可交付但实际总量不足。反证是当前剧情调用的 `ContentOutcomeApplier.ApplyAll` 已有 OutcomeTransaction，因此不能断言现行所有剧情交付都会丢物。此次将任务交付复用同一事务，预先汇总相同物品并检查全部库存；直接 API 与剧情入口都只在全部成功后转 ReadyToClaim。只追加修改 `Core/Content/QuestService.cs`，不改变交付的公库／背包取用范围或任务奖励。

## 缺口分级与制作边界

1. **第一章可开始制作。** 使用现有修炼／功法／斗技和纱衣表现境界差距；没有理由先建设所有高阶能力或通用行为树。
2. **离屏战斗精度差异必须如实保留。** BackgroundNpcConflictService 每 8 WorldTick 只处理近敌接近、撤离与双方一次普攻；已保存主动斗技冷却，但冷区未释放主动斗技，也未使用纱衣远程。近场可施放已装备斗技并使用纱衣。因此当前不能承诺同一战斗离屏与手动必得相同结果；若第一章依赖长期远方修士战争，需要再明确离屏技能／弹体的抽象结算规则，不能用无弹体的即时远程扣血悄悄绕过 ADR-0047。
3. **玩家需决定的规则**：筑基驭器／法宝／短飞是否成为第一章必需机制；若需要，须明确距离、灵力、地形、对空与反制。金丹以上飞行／内丹／神魂／空间权限保持 22 的 Proposed，当前不自行实现。
4. **后续内容可逐步补**：更多 NPC 可用斗技、身份战术差分、战报文案与战前准备来源；不因缺少完整行为树／全人物独特美术而暂停首段内容。
