# 342｜现有世界聚落、功能建筑与公开传承扩充

状态：Design Confirmed（制作人本轮明确要求）／Implemented；Producer Acceptance Pending；未提交、未推送、未封板。

## 本轮唯一实施指令

在341荒村布局基础上，将当前正式世界既有的102个旗帜据点及其余固定据点补齐聚落内容。荒村保持低级木屋；青石镇及宗门主城采用石屋、石墙、更多住宅、书阁、修炼场、医舍、丹室、炼器室、坊市与拍卖行；附属据点按粮药、矿冶、驿站、关隘等用途形成较小街区。保留当前核心位置、领地范围、身份与占领规则。城市只是现阶段可游览和使用的建筑、交易与修行骨架，不冒充已实现高阶宗主、炼丹炼器生产链或动态城镇人口。

新增16套公开进阶功法与斗技及32本对应书册，沿用实际已有的属性Modifier、修炼增量、熟练突破、伤害倍率、段数和冷却；为每宗提供不同于入门篇的取舍。接入青石书市、宗门主城商人及拍卖供给。增加可建造的功能房等级和树木外观变体，复用现有共享贴图与分块加载，不增加每帧扫描或满世界实体表现。

## 必要接线与边界

- 旗帜据点仍由 `FactionFlagService.SiteIdForCoreFlag` 产生 runtime Site；不得将其写成静态 SiteRegion，不能另放第二颗 controlCore。
- 作者发布器只在当前 Surface 有 `createsWorldSite` 对应旗帜时允许关联该 Site；数据加载与内容引用采用同一确定身份。固定据点核心校验仍只接受静态 SiteRegion。
- 新开局须先创建已作者化旗帜据点，再接入NPC初始位置、建筑与仓储。Snapshot authority / wire ID 不变。
- 主城配置少量真实常驻交易NPC，沿用已存在的商店和拍卖系统；不会凭空产生元婴宗主或匿名修士人口。
- 木／石材质由建筑定义驱动表现；树木采用已有大小、轮廓与颜色变化，砍伐仍产原有木材。丹室、炼器室现阶段提供建筑空间，配方生产未开放。

## 实施结果

- 正式发布新增106份聚落蓝图，覆盖102个原有旗帜据点与4个原有固定据点；连同荒村、青石镇共108处。16宗门主城各21间房，其余新聚落12～13间；新增街区共1420间房、2790棵树。全体正式蓝图共12530个对象。荒村的位置与围墙保持341结果，树木只增加色调与名称变化；青石镇现14间房。
- 新增21项可建造功能房定义。功法阁、丹室、炼器室、坊市、拍卖行、医舍、客栈、修炼堂有低木／中石／高石规格；房屋和床位可沿用既有功能，医舍标为Medical。炼丹、炼器、旅店收费住宿与全城生产供应链未实现。
- 新增16功法、16斗技、32书册。青石书市能买全套；16宗门主城各有本宗公开书市与两件初始拍品。另4个固定据点补行商，共新增36名服务NPC，正式人口由20变56；不按1420间房虚构居民。
- 表现端按建筑材料区分石地面／石墙与木地板／木墙，复用已有石质地面素材作石墙顶面；树木复用既有三种轮廓并提供四种色调标签，不新增高清贴图。
- 旗帜据点身份仍为既有runtime Site，未添加伪静态SiteRegion或第二颗核心。新开局在NPC位置接线之前建立既有旗帜据点；发布器、schema引用、存储设施与加载区居民／地点接线补齐。
- 新增静态 `Site→Chunk` 缓存，替代每个据点查询时遍历整张地图物件；缓存与原有作者物件索引同生命周期，不在每帧重建。实际扩容后的帧率仍待现场确认。

## 一轮人工验收

1. 新开局，通过现有作弊工具或正常取得荒村后前往青石镇、玄衡城、赤铁坞、南稷庄：看石木差异、田地紧排、城门／房门通路、WASD顺滑度；荒村位置应保持341。
2. 在青石和玄衡城找到行商购买进阶书，主城拍卖行可查看／出价。功法支篇要求筑基；满足条件后学习、装备并检查属性与修炼增量；斗技检查段数和冷却。
3. 查看医舍医疗床、住宅床、公库、棋桌和蒲团；矿石仍区分铁铜银灵。丹室／炼器室目前不应出现声称已可生产的虚假配方。
