# 147 · 接战点无瞬移＋弥留残留战场（2026-08-21）

## 目标

大地图打完离开 LocalMap／确认自动结算后，参战者留在**接战点（BattleAnchor）**，禁止瞬移回家；场上仍有弥留则战场残留，可再进。

## 手操清单（LevelTester）

1. 路上接匪 → 手动清场 →「结束战斗」→ 大地图人仍在路上接战点（不回荒村）
2. 留敌弥留结束 → 大地图见敌「弥」头像／残留栈 → 右键「攻击（再入战场）」可进原图补刀
3. 我方弥留结束 → 右键弥留头像「查看」→ 存活角色再入战场
4. 补刀清光且无弥留 → 战场销毁
5. 自动战斗确认结算 → 路上参战者不瞬移回村
