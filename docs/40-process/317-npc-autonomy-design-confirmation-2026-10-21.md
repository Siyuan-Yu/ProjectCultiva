# NPC 自主行为：生活倾向与离屏结算确认

> 状态：Design Confirmed / Partial Implementation / Producer Acceptance Pending | 优先级：P0 | 最后更新：2026-10-21
> 来源：制作人本轮确认；实施前仍须遵循 23、27、2K、35 与现行 Freeze。本文不是人工验收记录。

## 范围和权威

- NPC 自主行为覆盖我方、敌方、中立的所有真实 Character，包括修士、凡人、主管与临时同行者；不同身份用不同候选行动、权限、职责和战斗策略。当前 ActiveControlledCharacter 的直接操作优先，不由普通自主决策接管。
- “生活倾向”三档**仅供玩家设置我方势力的非凡人角色**，包括未入队的开局同伴甲、乙和今后同类角色。它不是普遍适用于敌方／中立角色的玩家控制 UI，也不是队伍 Follow 关系。入队时队伍命令优先；离队后恢复持久的个人倾向。
- 我方受管凡人保留已验收的需求优先／日程／职业闭环，不能被三档非凡人倾向取代。敌方和中立 NPC 仍需按自身身份自主生活，但不由玩家配置其三档倾向。
- 角色是否在相机画面内不是行为权威。近场、洞府 Separate Space 和当前 CharacterEncounter 按现场精度处理；远方按 WorldTick 低频／事件驱动推进相同的真实 Character。LOD 切换保留 EntityId、真实位置、需求、伤势、关系、物品和行动结果，不凭空复位或复制行动。洞府是独立战场，敌对者在其中可直接交战，不再套一层 CharacterEncounter。

## 我方非凡人生活倾向

人物概览右侧、当前“斗气纱衣”行下方显示“生活倾向”下拉框，选项为：

| 选项 | 空闲时的行为方向 |
|---|---|
| 修炼为主 | 在安全、资源、精力、饱食及当前心境允许时优先修炼；否则先处理阻断条件。 |
| 平衡 | 在修炼、休息、生活／娱乐间交替，不用固定逐时日程。默认选项。 |
| 娱乐为主 | 满足基本需求后大部分可支配时间用于娱乐；仍保留一定修炼时间。 |

- 这三档是长期效用权重，不是玩家隔空指定坐标或每小时日程；危险、战斗、明确命令、伤病、饥饿与疲劳优先。修炼降低**当前心境**，娱乐恢复当前心境；休息恢复精力，进食消耗合法食物并恢复饱食。不能把 `AttributeId.MindState` 基础属性永久扣减来冒充当前心境；基础属性与当前状态分离，并在 HUD 清楚显示。
- 娱乐必须消耗真实世界时间。优先选择当前可访问的休闲地点；无合法专用地点时可以在安全住处休闲。不凭空生成资源或修炼收益；若无安全地点则不强制启动娱乐。
- 安全的自由活动地点不等于“由本人势力拥有的据点”：玩家势力同伴在青石荒村等与本人势力非交战的有效据点，也可就地修炼／休闲。仓储取用与进食须再经 [ADR-0050](43-decisions/ADR-0050-direct-vassal-overlord-storage-access.md) 的直接附庸资格；该资格不开放床位、建设或其他行政管理。遇正式战争、战斗或上级行动权威仍应停止自由活动。
- NPC 可以自主修炼至当前瓶颈，**不得自主突破**。到瓶颈后切换其他可行行为；我方角色向玩家给出可读提示，由玩家决定突破及其资源／风险。
- **2026-10-21 现场返修确认：** 非凡人自主修炼须先找到同一据点内有效的打坐位（现有 `cushion` 蒲团），实际走到位后才启动修炼、增加修为；不能在住宅门口或原地挂“修炼中”。打坐位不可达时报告受阻，不结算修为。疲劳达到阈值时中断自主修炼，优先回已分配住宅床睡觉；床边路径失败后有限重试并以就地休息保底，不能精力归零后仍持续站立修炼。可见角色按真实移动；离屏仍不得无地点凭空修炼。
- 三档具体评分、阈值、时间长度和心境数值留给实施调参，但必须满足上述可观察行为，不能让“修炼为主”饿死、困死或无限修炼到不可突破瓶颈，也不能让“娱乐为主”完全停止修炼。

## 离屏冲突

- 制作人确认：NPC 与 NPC 的离屏冲突允许产生真实伤亡等结果，不能仅产生一条虚构消息。交战资格仍须依真实敌对／战争／现场关系判定，低好感或同屏本身不授权攻击。
- 结果须写回相同 Character 的生命、伤势、位置及既有可用的关系／战斗结算真源；不能匿名生成或删除修士，不得使普通人物交战自动宣战或接管 Site。近场／离屏转换不得双算伤害、奖励、时间或资源。
- 洞府内敌对双方直接在 Separate Space 战斗；普通户外玩家实战仍使用现行同源 CharacterEncounter。离屏 NPC 战斗的具体目标选择、战术、胜负与撤退数值，以及对战争增援和交战通知的影响，需在战斗 AI 实施设计中明确，不能用旧 FormalArmy／Hex runtime 代替。

## 自动交战、同伴职责与撤退（2026-10-21 追加确认）

- 自动先手只由正式战争、明确私人敌对或内容标记敌对等合法敌对依据触发；单纯低好感只可警戒，不自动攻击。
- 我方同伴默认保护当前主控，并协同选择目标；不以“各自追最近敌人”作为默认策略。明确玩家命令与现场可达性仍优先。
- 普通 NPC 劣势时允许逃跑或投降；死战身份可例外。我方同伴默认向主控撤靠，不自行投降。洞府 Separate Space 暂不提供逃跑功能，不能借户外 CharacterEncounter 逃跑入口绕过洞府空间规则。
- 普通户外独立战场从“开始战斗”后、实际交战累计约 300 战术秒才开放玩家“逃跑”按钮；准备、暂停、战后结算不计时。战术加速下按现有战术时间累计，非墙上实秒。一次尝试是否成功先参考当前双方仍能战斗者的神识总和；今后可加入距离、速度、控制等因素。成功必须是与胜／败不同的撤退结果，保留已发生的伤势、死亡和物资变化，按既有战场 Return／SuppressedContact 机制安全离场，不自动宣战或接管 Site。失败仍在原场交战，不能通过点击重置战场。
- **2026-10-21 制作人追加确认：** 神识总和转概率，双方相等时约 50%，下限 10%、上限 90%；失败后仍在原战场交战，60 战术秒后才可再试。成功仅撤离仍能行动的我方成员，失能者留在战场并承担后续被俘／死亡风险；尝试前明确警告。具体概率曲线与可调整数值可在实施中选择，但不得与这些边界相反。不能免费带走失能者，也不能把他们悄悄计为战胜或瞬时死亡。

## 统一决策与结算契约（2026-10-21 制作人要求完整落地）

以下是本轮代码实施的规则真源；未能接线的条目仍须在本文末尾逐项保留为缺口，不能因为设计已定而记作完成。

1. **决策优先级**：死亡／失能／囚禁和战场权威先阻断生活；当前玩家直接命令、编队命令、职业与凡人日程随后优先；现场合法敌对和自保优先于自由生活；饥饿、疲劳、伤病优先于偏好；最后才由个人生活倾向选修炼、休息或娱乐。已有行动仅在更高优先级条件出现时中断，避免每 Tick 抖动。人物仅有一个 Action 和一个位置权威。
2. **类别**：开局主角及永久同伴均是真实 Character；直接主控不由生活 AI 接管。受管凡人以 `MortalCivilianService` 的需求／日程／职业为准。玩家势力非凡人（即非受管凡人的常驻角色，包含尚未入队同伴）可改三档。其他修士和中立人物采用平衡缺省，但不展示玩家编辑入口；敌对标签只是战斗资格，不剥夺吃饭、休息等生活需求。临时同伴服从同行／战斗 authority，不因可见而变为永久可管理者。
3. **自由生活数值**：饱食、精力、当前心境均为 0–100 的独立当前量，基础 `MindState` 仍为属性。安全空闲且未满瓶颈时修炼可取得现有 `CultivateAction` 真实进度、耗精力并降当前心境；疲劳先睡，饥饿先寻找合法食物，低心境先娱乐。娱乐每次占用真实 WorldTick，恢复当前心境，不产生修为／物品。平衡不得长期偏向一个选项；修炼为主只有需求许可才优先，娱乐为主仍安排非零修炼。若粮食、床位或安全地点不存在，保留可读受阻状态，不免费填满需求。
4. **精度**：当前加载战场／洞府按实时碰撞、目标和实际移动结算；远处 Character 仍是同一个 EntityId，以 WorldTick 低频／事件驱动推进持续状态及冲突。LOD 转换不可复写位置、瞬间补满需求、重新抽取随机结果、给同一次行动重复伤害或把弥留当作死亡。随机顺序和目标选择以稳定 EntityId 排序。
5. **自动敌对**：`WarGateService` 的正式战争、明确的角色间私人敌对事实、或内容标记敌对三者之一才允许自动先手。私人敌对须是显式事实，不以 Affection／Grudge 阈值推断。同势力不自动相杀；无证据则警戒／避让。发现需要同一空间及合理距离，普通户外不得仅凭同地图全知开战。玩家队伍遇敌走现行 CharacterEncounter，洞府直接原地作战，NPC–NPC 离屏冲突写回真实生命／伤势及必要战报，不自动触发战争、征服或奖励。
6. **战术**：同伴默认护主，按主控指定目标、正在威胁主控的目标、最近可达敌人的顺序选择；玩家明确 Stop／目标指令优先。普通 NPC 选附近合法目标，可用已装备斗技与现有冷却，无技能则用普攻／纱衣。劣势判断应基于当前仍可战斗力量，不根据阵营标签预设胜负；普通 NPC 可撤离或投降，死战标签例外；我方同伴优先撤向主控、不自行投降。投降不能凭空改变所属势力或直接变成被俘，必须经过既有俘虏 authority；无法合法结算时只撤离。
7. **战场结果**：人物死亡／弥留走 `CombatLifeStateService`；普通战斗不自动占点。玩家独立战场撤退保留 300 秒开放、神识概率 10%–90%、失败 60 秒冷却、失能者留下、撤退与胜败分离。洞府没有该按钮或计时逃跑，不得从其他入口绕过。

### 人工验收重点

- 把同伴甲／乙留在队伍外、切换三档并存读档，观察合法取食、休息、修炼至瓶颈与娱乐时心境、精力、饱食的真实变化；主控与凡人仍分别服从原权限和日程。
- 本次返修重点：把同伴甲／乙设为“修炼为主”，确认先走至荒村现有蒲团，途中修为不增，到位才修炼；将精力耗到 30 以下后确认停止修炼、走到各自住宅床边并恢复精力。故意堵住一处床边路径时应改选合法床边格或就地休息，不能无限显示“修炼中”。
- 对同一对 NPC 检查同屏／远处切换：无合法敌对不打、合法敌对可以战斗，位置与伤势不复位，不双算；洞府内多名敌人可自主换目标且不弹第二层战场。
- 独立战场观察同伴护主、NPC 劣势反应、斗技冷却和玩家撤退；人工确认旧档、新档、加速与暂停结果。

## 实施边界和当前差距

### 本轮已接线（静态编译通过；不等于全部 NPC AI 完成）

- 普通独立 `CharacterEncounter` 在累计 300 战术秒、至少一名 PlayerParty 参战者仍可行动后开放玩家撤退按钮；等神识为 50%，以双方可战斗者神识总和差相对较大一方的比例线性调整（上下限 10%／90%）。一次失败要再等 60 战术秒，冷却与撤退标记随战场状态保存。确认框暂停战术时间并警示失能者留场，成功立刻走现有返场及独立“已撤离战场”战报；洞府不显示入口。
- 普通独立战场中，同伴没有有效目标时优先援助当前主控的有效目标，其次应对指向主控的敌人，最后才取最近敌人。现有明确目标／停止命令不被覆盖。
- 普通独立战场中，非当前主控参战者可按已装备的主动斗技、战场持久冷却与近距离目标合法性自动释放；没有可用主动技时沿用既有纱衣／普攻。技能仍遵循现有 `MeleeCombatService.CastEquippedArt` 的伤害和熟练权威，不给 NPC 凭空生成未学习／未装备技能。
- `PersonalLifeComponent` 分离当前心境、饱食、精力与三档倾向；我方常驻非受管角色的人物概览下拉框可改，个人状态随 Snapshot v17 optional 字段保存，旧档缺省平衡／75。`PersonalLifeService` 在 WorldTick 推进，非受管角色不被 `NpcActivityDriver` 的 Npc-only 日程假装覆盖。修炼沿用原 Action 至瓶颈并耗精力／当前心境；休息恢复精力，娱乐占用 WorldTick 恢复心境；有合法休闲 WorkArea 时寻路，暂无则仅在安全 Site 原地娱乐。饥饿需从己方或直接宗主 Site 公库真实取食（[ADR-0050](43-decisions/ADR-0050-direct-vassal-overlord-storage-access.md)）；加载人物到储藏室后扣粮，离屏角色限本 Site 抽象扣粮。床铺与储藏室路由失败留状态及有界重试。
- 现场返修已把现有 `cushion` 放入可复原的静态打坐位目录：自主修炼前找本 Site 可达蒲团，热区通过 MovementIntent 走到位、冷区沿真实 Surface 路径逐段更新持久位置，到位才发 Cultivate Action；旧档中离开蒲团的 AI 修炼会被中断。床边与储藏室访问半径改按真实 CellSize，不再使用远大于一格的 0.5 世界单位；个人返床可重选合法床边点，到位假阳性与路径失败时短暂就地休息并重试。此为离线编译后的代码状态，仍待制作人现场验收。
- `NpcHostilityService` 将正式战争、RelationshipLedger 显式私人敌对和内容 `hostile` tag 归一；五维态度低分不触发自动先手。被袭击者收到显式私人敌对事实，仍不自动宣战。热区由 `HostNpcAutonomousCombat` 发现同空间近敌、多目标选择、移动与普攻／既有装备斗技；玩家户外接战仍走 CharacterEncounter，洞府原地打，不套第二层。冷区由 `BackgroundNpcConflictService` 每 8 WorldTick 仅对双方都非物化的真实人物按距离配对，复用生命／伤害服务，不与热区双算，不占点。
- 独立战场非 PlayerParty 的普通 NPC 在低血且本方力量劣势时可按身份撤离／战术投降，死战 tag 例外；`Withdrawn` 随战场保存，退出目标选择与胜负统计。投降只意味着停止交战、返场后仍需既有捕获 authority，不自动归属玩家。离屏／加载户外的普通 NPC 低血劣势可沿合法地表路线脱离，接触抑制避免原地反复开战。洞府暂不做逃跑。
- 受管凡人不会因势力战争或被袭后的私人敌对事实自动变成攻击单位；遭遇合法敌对接触时依现有忠诚／Disposition 进入逃离或待降，洞府无法逃离时只待降，不凭空变成已俘。离屏逃离按分桶 WorldTick 沿合法 Surface 路线推进同一人物的真实位置，越过据点边界后接原有 Displaced／避难流程；仍需人工核查不同身份在近场与离屏交接的状态。
- 运行代码已离线编译；未启动 Unity、未运行自动测试、未完成人工验收。撤退后失能者依现有 Return authority 留在原交战地点，不随仍能行动的 PlayerParty 成员投影移动；当前实现不瞬间判定他们被俘或死亡。

### 未闭环，不能宣称完整接入

- 队内非凡人的个人需求仍会变化，饥饿时可从共享背包扣真实 food，但自由生活让位于队伍命令；当前没有完整的队伍统一睡眠时间／床位安排，长时间随队后需人工观察。临时同行者的专属生活／战斗职责仍主要依现有同行 authority，不是独立完整日程。
- 非凡人生活行为现为以状态阈值与 6 Tick 会话驱动；不是基于全部场景内容的广义行为树。无安全 Site／合法食物时保留受阻状态，未实现流浪寻粮或跨 Site 自动采购；当前内容没有专用 `leisure` WorkArea，实际休闲会走安全 Site 后备。
- 现场自动发现目前以同空间／显示距离判定，尚未接遮挡视线判断；多方阵营目标选择以合法敌对和距离为基础，非完整的掩体／威胁／战术编组。热区斗技冷却为 Host 会话态，读档回到非独立现场时不保存该冷却；独立战场斗技冷却已在 Encounter state 保存。
- NPC 战术投降只退出本场，不自动押送／俘虏；离屏战斗没有正式 NPC-NPC 战报页、资源掠取、增援／战争战略响应。冷热转换、防重复伤害及多人性能仍待 Unity 现场人工验收。故本轮状态仍为 **Partial Implementation / Producer Acceptance Pending**，不是“NPC AI 已全部实现”。
