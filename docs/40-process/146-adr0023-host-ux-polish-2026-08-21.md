## 2. 相对 145 的打磨对照

| 主题 | 145 初版／问题 | 本轮规则 |
|------|----------------|----------|
| **支援范围** | 先 TravelCost≤24，后 hop≤1，仍偏大 | **大地图世界坐标半径默认 1.0**（约 2～3 人头像宽）；邻村（如荒村↔林间距 3）不可支援 |
| **手动战后** | 曾出强制中央弹窗 → 软锁／挡操作 | 清场→PostBattle：**右下角非强制条**；可继续补刀／交互；点「结束战斗」才 `ResolveAndEnd` |
| **自动战** | 点完只 Toast，瞬间解冻 | `ResolveAuto`→**结算弹窗**（胜／负＋摘要）→「确认结算」才出队／解冻；不额外推进 Tick |
| **出队** | Modal 未解冻时 `TryPromote` 被挡 | `FinishOfferResolution` **先 EndFreeze 再出队** |
| **编译** | `HostWorldTravelDeparture` 重复 `var world` | 已合并 |
| **山匪可见性** | 栈画在节点下，叠在荒村 128px 标签后 | 栈**后画置顶**；贴节点时挪到标签右侧；演示栈改荒村→青石关路上、**4 人「荒村山匪」** |

## 4. 手操再验（LevelTester）

1. 同节点可选支援出现；邻村角色**不**出现在可选列表  
2. 手动战：敌军全弥留→右下角「结束战斗」→可先补刀再点结束→时间恢复  
3. 自动战：点自动→**结算弹窗**→确认→大地图恢复；串行第二场需确认后才弹  
4. 大地图：荒村旁可见「4人 · 荒村山匪」，不被地名挡住

## 5. 与 ADR-0023 的关系

- **不变：** Offer／Manual／PostBattle 冻结 WorldTick；Modal 禁远方战略令／禁切其他节点场景  
- **澄清：** PostBattle **≠** 强制 UI 打断；仅自动战结算弹窗计入 `HasBlockingInterrupt`  
- **澄清：** 支援距离真源＝世界坐标近距，不是 hops／TravelCost 主闸
