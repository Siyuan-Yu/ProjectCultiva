# 351｜世界图远距离旅行与主控小队标志

> 2026-10-25；制作人要求修复远处右键卡顿、路线短暂出现后无法出发，并让当前主控小队标志醒目且不随缩放变化。本轮沿用既有 Continuous Surface + exact WorldPosition、村界解锁和 WorldMap planning overlay 契约；不改 Snapshot、地图 authority 或开局剧情规则。状态：**Implemented / Producer Acceptance Pending / 未提交推送**。

## 定位与实施范围

- 世界扩展到 15200×6800 格后，远程目标若直线被阻挡，当前右键在 IMGUI 主线程同步进行稀疏 A*；路径简化从同一锚点反复做越来越长的射线检查，直线路段成本可随长度平方增长。地图帧会被整段规划占住。已改为与主线程隔离的纯 Core 地面读查询，规划完成后仅在原会话、Surface、主控与起点仍有效时提交；连续点选以最后目标为准，旧查询可取消并在搜索中定期退出。稀疏搜索使用 1.5 倍八向启发式偏向目标，并限制逐段简化前瞻到 48 格；这可能生成略长于最短路的路线，但仍逐格验证通行与禁止穿角。直线可走／飞行继续即时响应。
- 现有 Editor 日志出现过 `SurfaceTravelPlanRejected`（村界封锁）及 `SurfaceAutoTravelStalled`（局部 `NeedsRouteData`）。村界是已确认规则，不能靠路线规划绕开；拒绝现在留在地图上方显眼的提示条。预期的村界／目标范围／NPC 选择拒绝不再逐次写入带栈 Console 警告，其他诊断按原因去重。对于已接受的远路线，局部执行在目标尚未加载时只选择距人物至少 0.75 格的可达前沿，避免将当前脚下格当作下一段路而静默等待。仍被实际障碍围死的目标会报告原因，不虚构通路。
- 主控玩家小队改为唯一以屏幕像素绘制的 26px 高对比定位标记与定宽标签；Site、NPC Squad 继续随世界图投影缩放。地图坐标仍从 exact WorldPosition 取得。
