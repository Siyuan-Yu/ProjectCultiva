# 功法、斗技与装备

> 状态：设计方向已定，数值未展开 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`2H-manual-system-rules.md`、`22-realms-and-abilities.md`、`25-cultivation-and-breakthrough.md`、`2B-attributes-and-affinity.md`、`23-combat.md`
> 当前只记设计方向，**不进入具体数值与平衡设计**。示例数字仅用于说明规则形态。

## 1. 这个系统解决什么问题

把修士成长的主轴放在**功法与斗技**上，降低装备复杂度，避免"强化武器跨境界碾压"的装备驱动。

## 2. 战斗影响排序

战力与成长影响的优先级（设计目标）：

1. **境界**
2. **功法**
3. **斗技**
4. **灵根与角色属性**（神识、悟性、心境等，见 `2B`）
5. **装备**

装备不能让低境界靠堆强化跨越大境界击败高境界。

同一件功法／斗技在不同角色手中效果不同，取决于灵根适配、神识控制上限、悟性与**掌握程度**，规则见 `2B-attributes-and-affinity.md`。

## 3. 功法体系

功法是修士成长核心。提高功法重要性，降低装备影响。完整规则见 `2H-manual-system-rules.md`；本节只保留与斗技、装备的边界摘要。

### 3.0 功法的主要作用

- 提升修为获取速度
- 影响最大灵力、灵力恢复与灵力质量
- 提供成长方向
- 影响技能学习和使用

**功法不是单纯的技能列表**，不同功法决定修士的发展路线。

### 3.1 品阶

| 品阶 | 设计意图 |
|---|---|
| 黄阶 | 入门 |
| 玄阶 | 进阶 |
| 地阶 | 高阶 |
| 天阶 | 顶尖 |

品阶代表功法的完整程度和成长潜力，影响：

- 修为获取效率
- 最大灵力、灵力恢复与灵力质量
- 战斗续航
- 长期成长上限

### 3.2 低境界可获得高级功法

角色没有职业或灵根禁学限制，原则上可以学习任何功法；灵根只影响效率。功法仍可存在境界、身体、前置知识或传承等客观学习条件。

低境界可以提前获得甚至尝试学习高级功法，但不一定能完整发挥；强行运转可能有风险。风险形态**待确定**（走火、伤身、心魔、修为停滞等）。

### 3.3 第一份功法

不是固定赠送。来源包括：NPC 传承、秘境探索、宗门获得、商人交易、特殊事件。不同来源功法不同，影响属性方向、效率、技能与战斗风格。详见 `25-cultivation-and-breakthrough.md`。

### 3.4 与境界门槛

- 感应境：可获得、持有，但不能正式学习与运转。
- 炼气：可正式学习并运行功法，进入修炼体系。
- 更高境界：逐步发挥高阶功法的完整潜力（是否存在硬门槛**待确定**）。

### 3.5 功法成长

大部分功法不可升级品阶。角色通过寻找和更换更适合的新功法成长；把一部功法练到更高掌握程度，不代表其品阶提高。

仅少数特殊机缘功法可以成长、补全或升阶，数量需严格控制。详见 `2H-manual-system-rules.md`。

## 4. 斗技／技能体系

技能品阶同样采用：黄阶、玄阶、地阶、天阶。

设计原则：

- 技能数量可以学很多，但战斗中最多装备 **6** 个。
- 每个修士重点培养**少量核心技能**。
- 技能决定战斗方式。

炼气即可使用基础灵力技能；更高品阶斗技、与法宝配合的复杂技巧，随境界与功法推进解锁。**炼气技能与筑基斗技的命名／切分边界待确定**（避免"神通／斗技／技能"同义词混用）。

### 4.1 掌握程度

技能与功法有**独立于角色等级的掌握程度**：初学 → 入门 → 小成 → 大成 → 圆满 → 化境（名称待调整）。

掌握程度受使用频率、修炼时间、悟性、灵根适配度影响。品阶决定技能的上限与体系归属，掌握程度决定当前实际发挥到几成。完整规则见 `2B-attributes-and-affinity.md` 第 7 节。

### 4.2 战斗装备与自动释放

战斗中装备技能对应快捷键 1–6。技能支持手动／半自动／自动释放，细则见 `23-combat.md`。

## 5. 装备与法宝定位

降低装备系统复杂度。

**不要**让武器强化、装备等级成为主要战力来源。

装备和法宝主要提供：

- 特殊效果
- 战斗方式变化
- 辅助能力

例如：

- 飞剑：提升御器能力
- 护甲：提供防御

筑基后才能稳定驭使法宝、短距离御器飞行（见 `22`）。法器与法宝是否分两级**待确定**。

## 6. 与其他系统的接口

- 输入：境界、灵根、神识、悟性、心境、功法品阶、掌握程度、环境、因果状态。
- 输出：修为获取效率、最大灵力、灵力恢复、灵力质量、可学习技能、同时可控制的法宝／法术数量、战斗风格、探索与御器权限。
- 战斗层消费这些结果，但不单独靠装备碾压境界。
