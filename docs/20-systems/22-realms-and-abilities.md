# 境界与机制能力

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> **这是本项目最重要的差异化系统。**

## 1. 这个系统解决什么问题

竞品的境界主要是任务门槛和属性倍率，导致后期变成数值对撞。我们要让境界成为**规则权限**：每次大境界突破都改变玩家实际能做的操作，也就是"斗气化翼"那种质变感。

## 2. 核心原则

- 每个**大境界**至少解锁一种由玩家亲手使用的超凡能力。
- 能力应尽量横跨战斗与跑图两个场景，避免为每个场景各造一套系统。
- 不要求每个小阶段都有新机制；小阶段负责数值与稳定性，大境界负责质变。
- 高阶修士形成规则优势，但仍受克制、资源、因果和战略条件约束。
- 判定标准：**玩家不看属性面板，仅凭可执行的操作就能判断自己是否跨入了新境界。**

## 3. 候选能力矩阵

名称与境界的对应关系尚未定案，此表用于确定能力的形态。

| 超凡能力 | 战斗影响 | 跑图与世界影响 |
|---|---|---|
| 灵力／斗气外放 | 从近身扩展到远程攻击、范围压制 | 隔空触发机关、采集危险资源 |
| 护体铠甲 | 抵挡凡兵、环境伤害与低阶围攻 | 进入毒瘴、烈火、极寒等危险区域 |
| 御物／化形 | 改变技能形态、制造临时武器或掩体 | 搭桥、破障、搬运大型物体 |
| 飞行 | 形成空地分层，对地面单位产生压制 | 越过山河城墙、缩短行军、进入浮空区域 |
| 神识 | 扩大侦察、识破隐匿、预判敌人 | 探查资源、识别伏兵、远程管理与通信 |

## 4. 每个大境界的设计清单

正式设计每个境界时，必须回答下面五格，缺一格不算定稿：

| 维度 | 必须回答的问题 |
|---|---|
| 战斗 | 玩家多了什么新操作？旧敌人的应对方式如何改变？ |
| 跑图 | 哪些以前不能到达或代价极高的地方现在可以进入？ |
| 探索 | 新能力能发现、采集或处理什么？ |
| 领地 | 能建什么、保护什么，或提高什么管理能力？ |
| 世界反应 | 凡人、低阶修士与高阶势力如何重新评价该角色？ |

## 5. 未决问题

- [ ] 境界命名走传统体系（练气／筑基／金丹／元婴…），还是偏"斗气"表达的自定义层级？
- [ ] 大境界总共几层？第一阶段只做"凡人 → 练气"这一次质变。
- [ ] 能力是突破后自动获得，还是在突破时从若干分支中选择？
- [ ] 同一境界的不同功法路线是否给出不同能力变体？
- [ ] 飞行这类能力如何避免让地面据点战失去意义？（需要制约手段，例如禁空阵法）
