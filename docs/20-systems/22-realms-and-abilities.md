# 境界与机制能力

> 状态：炼气四能力方向已冻结于 `33`；飞行／踏空等仍待定 | 优先级：P0 | 最后更新：2026-07-31
> 上级：`docs/00-project/00-overview.md`
> 关联：`../30-tech/33-architecture-core-rules-freeze-v0.1.md`
> **这是本项目最重要的差异化系统。**
> **本阶段不写实现代码。** 炼气解锁：灵力池、功法修炼、基础术法、灵气感知（见 `33` §4）。

## 1. 这个系统解决什么问题

竞品的境界主要是任务门槛和属性倍率，导致后期变成数值对撞。我们要让境界成为**规则权限**：每次大境界突破都改变玩家实际能做的操作，也就是"斗气化翼"那种质变感。

## 2. 核心原则

- 每个**大境界**都必须带来**机制层面的新能力**，而不是单纯提高攻击、防御与生命数值。
- 每个境界应尽量同时改变三类体验：**移动方式、战斗方式、世界交互方式**。
- 能力应尽量横跨战斗与跑图两个场景，避免为每个场景各造一套系统。
- 不要求每个小阶段都有新机制；小阶段负责数值与稳定性，大境界负责质变。
- 高阶修士形成规则优势，但仍受克制、资源、因果和战略条件约束。
- 判定标准：**玩家不看属性面板，仅凭可执行的操作就能判断自己是否跨入了新境界。**

成长闭环：

```
境界改变能力 → 能力改变玩法 → 势力改变资源 → 资源推动修炼 → 修炼推动更高境界
```

## 3. 境界名称与规则权限骨架

名称沿用《鬼谷八荒》式传统体系，实际效果参考《斗破苍穹》式"每个境界改变能量形态与操作权限"。

| 境界 | 能量／生命形态变化 | 讨论中的核心规则权限 | 当前状态 |
|---|---|---|---|
| **感应境**（初始状态） | 能感受到天地灵气并进行基础吸收 | 可基础吸收灵气、进入正式修炼准备阶段；**不能学正式功法、不能真正运转灵力、不能使用修士能力** | 核心规则已定 |
| 炼气 | 正式进入修仙体系，能够使用灵气 | 获得灵气池；战斗优先耗灵气；可学习运行功法；身体基础强化；基础灵力技能 | 方向已定，细则待定 |
| 筑基 | 灵气可附着到物体上 | 使用法宝、学习斗技、驭器，并可驭器短距离飞行 | 讨论中 |
| 结晶 | 离体灵力凝结并稳定塑形 | 护体强化、术法塑形、多法宝协同 | 待确定 |
| 金丹 | 形成内丹，力量外放改变战场 | 内丹体系、灵气外放／斗气铠甲式护体、不同属性内丹风格；真正飞行（讨论中） | 讨论中 |
| 具灵 | 灵力造物开始具备"灵" | 器灵、灵体召唤、自动护主 | 待确定 |
| 元婴 | 生命形式改变：灵魂可离体 | 灵魂出窍、神魂战斗、第二生命机会、神识压制低阶；出窍有风险 | 讨论中 |
| 化神 | 神魂可分化并远程作用 | 神识领域（对范围内敌我产生影响）；分神／化身方向仍保留讨论 | 待确定 |
| 悟道 | 开始理解并干涉天地规则 | 规则力量／道域；空间虫洞方向此前已讨论 | 空间／规则边界待整理 |
| 羽化 | 肉身与天地规则融合 | 可能涉及空间通道／跨区域移动；与悟道空间权限的边界**待确定** | 待确定 |
| 登仙 | 从使用规则变成规则参与者 | 世界级能力与最终胜利权限；可能包含踏空一类更高层移动规则 | 待确定 |

**待确定｜肉身飞行归属：** 本次补充方向倾向**金丹解锁真正飞行**；筑基的驭器短距离飞行仍是过渡形态。最终是否锁定于金丹，仍待确认。

**待确定｜空间能力归属：** 早前把战略空间虫洞放在悟道；本次补充把空间通道写为羽化可能能力。两者边界未定，不擅自迁移。

**说明：** 感应境不是通过游戏事件触发解锁的阶段。三名核心角色开局默认已处于感应境；世界中的大多数普通人则是真正凡人，无法感知灵气。感应境不是与筑基、金丹并列的大境界，也不算真正修士，更**不是一种特殊视觉能力**（见第 4 节）。

## 4. 感应境：修炼的起点，不是特殊视觉

三名核心角色从游戏开始就处于感应境。玩家不需要等待某个事件来证明角色"可以修仙"。

### 4.1 定位

感应境**只是一个修炼境界**，不是正式修士，也**不是一种特殊视觉能力**。

### 4.2 能力

感应境的能力仅限三项：

- 可以感受到天地灵气。
- 可以进行基础吸收（效率极低，无法形成完整修炼循环）。
- 可以进入正式修炼准备阶段。

### 4.3 隐藏信息感知不属于感应境

玩家能发现灵物、灵气异常、妖气痕迹、隐藏修士身份等普通人察觉不到的信息，**来源是神识、天赋与经历，不是感应境这个境界本身**。详见 `2B-attributes-and-affinity.md`。

因此：一个神识高的凡人也可能察觉异常；一个刚入感应境但神识平平的角色不会自动获得"透视"。开局三人之所以比周围劳役者更敏锐，是属性与背景的结果。

### 4.4 关键限制

感应境：

- **不能学习正式功法**
- **不能真正运转灵力**
- **不能使用修士能力**

玩家需要通过探索、NPC 互动、宗门、商人或特殊事件获得第一份功法。感应境角色可以持有功法，但只有在成功按照功法正式运转灵气后，才进入炼气期。

### 4.5 设计目标与待设计项

设计目标：让玩家从游戏开始就感觉自己正在逐渐发现一个隐藏的修仙世界，而不是突然被系统告知"你可以修仙"。这个"逐渐发现"由神识与经历驱动。

待设计：

- 神识带来的感知范围与精度如何表达和提升。
- 感知是常驻的，还是需要主动集中注意力。
- 感应境的缓慢吸收能带来什么有限收益。
- 如何让玩家在画面上确实"看见"普通凡人看不见的东西。

## 5. 炼气：正式进入修仙体系

**炼气不是巨大的能力跃迁。** 它代表角色正式进入修仙体系。

| | 感应境 | 炼气 |
|---|---|---|
| 本质 | 能够感知灵气 | 能够使用灵气 |
| 体验 | 看见修仙世界 | 真正进入修仙世界 |

进入炼气的关键条件：获得第一份功法，并首次成功按照功法正式运转灵气。

### 5.1 主要变化

- 获得**灵力资源／灵气池**（战斗与施法消耗的资源）。
- 获得基础的灵力恢复能力与**灵力护体**。
- 战斗中伤害**优先消耗灵力护盾／灵力防护；耗尽后才直接损伤生命**。
- 可以正式学习和运行功法。
- 身体获得基础强化。
- 可以开始使用**基础法术／灵力技能**。
- 普通攻击开始可变为灵力强化攻击或基础灵力攻击（见 `23-combat.md`）。

具体技能清单与数值强度**待确定**；本阶段只锁定"从看见到使用"的定位，不写平衡表。

### 5.2 与更高境界的关系

炼气解决的是"入门"。真正改变战场与地图规则的大权限（驭器飞行、内丹领域、自主飞行等）留给后续大境界。炼气相对感应境的质变是**体系准入**，相对筑基以后则仍是低阶修士。

### 5.3 与第一个卡点的关系

筑基初期的管事弟子拥有玩家在炼气阶段尚未获得的规则权限（灵气附物、法宝、驭器飞行等）。三名炼气角色不应靠纯数值正面碾过他。

玩家可通过战前准备削弱其规则优势，例如：破坏或封住其飞行用法宝、布置陷阱、消耗其灵力、切断守卫支援、三人分工协同。

目标是"准备充分的三名炼气击败孤立且被削弱的筑基"，不是越级属性奇迹。

## 6. 筑基：开始控制外物与灵气

核心体验：从近战凡人方式，进入真正的修士战斗方式。

讨论中的解锁方向：

- 可以将灵气附着到物体与武器上。
- 开始稳定使用**法器／法宝**（是否分两级**待确定**）。
- 解锁**驭器**：远程操控、隔空交互、短距离御器飞行。
- 远距离灵力攻击成为常规手段。
- 斗技与器物配合的要求提高；边界细节见 `2D-manuals-arts-and-equipment.md`。

**待确定：** 法器与法宝是否分两级、驭器飞行的距离与消耗、筑基普通攻击如何从近战切到附灵／远程。

## 7. 金丹：力量外放，改变战场

### 7.1 内丹与灵气外放

金丹阶段形成**内丹**，战斗能力发生质变，并逐渐拥有**灵气外放**（类似斗气铠甲）的能力。核心不是单纯加血加伤，而是开始用外放力量改变战场形态。

### 7.2 真正飞行（讨论中）

本次补充方向：金丹可能解锁**真正飞行能力**。筑基驭器短飞仍只是过渡。飞行必须在战斗与探索中有实际作用，见第 9 节。

### 7.3 属性内丹形成不同战斗风格

不同属性的内丹应当带来**完全不同的战斗风格**，而不是同一套技能换个颜色。属性是能力倾向，**不做传统五行相克**（见 `2B-attributes-and-affinity.md`）。讨论中的方向：

| 属性 | 讨论中的效果方向 |
|---|---|
| 火 | 灼烧 |
| 木 | 恢复 |
| 水 | 治疗 |
| 雷 | 麻痹 |
| 金 | 反伤 |
| 土 | 护盾 |
| 风 | **待设计**（暂定属性之一） |
| 冰 | **待设计**（暂定属性之一） |
| 毒 | **待设计**（暂定属性之一） |

> **待确定：** 上表中的「水」沿用本轮补充示例。最新灵根名单为火、金、土、木、雷、风、冰、毒，不含水。水是否并入冰，见 `2B-attributes-and-affinity.md`；定案后需回来同步本表。木的"恢复"与水的"治疗"如何区分，也待确定。

玩家可以用天材地宝增强自身内丹，且这条养成线在后期仍然有效。

**待确定：**
- 具体数值与触发方式。
- 天材地宝增强内丹是否设上限，如何避免无限堆叠。
- 内丹在战斗中是常驻领域，还是战前／战中主动开启。

## 8. 元婴：生命形式改变

讨论中的方向：

- **灵魂出窍**与神魂层面战斗。
- **第二生命机会**：肉身受损或毁灭后仍有存续手段。
- 可寻找合适的傀儡或替代躯体。
- **神识压制**：对低境界、低神识目标产生压制，例如降低技能效果、灵力恢复或整体战斗能力。
- 神魂离体存在风险，不能做成无代价无敌形态。

**待确定：** 出窍时原肉身的状态、压制的具体规则、替代躯体能继承多少能力、是否与化神的分神／化身区分开。

## 9. 飞行与踏空：两层移动规则

飞行是本作最重要的境界能力之一，**必须在战斗与地图探索中产生实际作用，不能只是动画效果**。

### 9.1 飞行

讨论中的定义：依靠能力在空中移动。本次补充方向倾向由**金丹**解锁真正飞行；筑基驭器短飞不算完整飞行权限。

战斗中对地面单位的战略优势方向：

- 更高的闪避。
- 更高的伤害。
- 无视大量地形限制。

**具体数值本阶段不确定。** 需要平衡：面对无对空能力的凡人军队时应体现碾压；面对同阶修士或具备对空手段的敌人时不应无条件生效。

地图探索中的作用：越过地形障碍、缩短远距离移动、进入地面无法抵达的区域。

### 9.2 踏空

更高境界可能解锁**踏空**，它区别于普通飞行：

| | 飞行 | 踏空 |
|---|---|---|
| 本质 | 依靠能力在空中移动 | 改变移动规则本身 |
| 讨论中的能力 | 空中位移、越过地形 | 空中停留、自由转向、不依赖普通飞行能力 |

踏空归属哪一境界、与飞行如何并存，**待确定**。

### 9.3 待确定

- 真正飞行是否最终锁定于金丹。
- 是否存在禁空手段（例如阵法、对空法宝）。
- 飞行的持续消耗与载重限制。
- 踏空的解锁境界与对飞行的替代关系。

## 10. 更高境界补充方向

### 10.1 化神：神识领域

讨论中的方向：形成神识领域，对范围内敌我产生影响。此前"分神、化身、同时操纵第二躯体"的方向仍保留，不互相覆盖；最终如何切分**待确定**。

### 10.2 悟道：规则力量与空间网络

悟道开始从使用能量转为理解并操作规则。

此前已讨论的战术／战略空间方向仍保留：

- 短距离挪移、空间锁、空间裂隙。
- 构建空间虫洞，使两地极快往来；需空间锚点、维护成本、通行容量，且可被破坏。

判定标准：玩家突破悟道前把远方视为"数月路程"，突破后开始把世界看作"可建设的空间网络"。

### 10.3 羽化：可能的空间能力

本次补充方向：羽化可能涉及空间能力，例如空间通道、跨区域移动、突破大型阵法与空间限制。

> **待确定：** 战略空间网络归悟道还是羽化，或两者分层（悟道建规则网络，羽化做更自由的空间通行）。在定案前，不删除悟道已有空间虫洞讨论，也不把羽化写成已定稿。

### 10.4 登仙

从使用规则变成规则参与者，拥有世界级能力与最终胜利权限。细则**待确定**。

## 11. 每个大境界的设计清单

正式设计每个境界时，必须回答下面五格，缺一格不算定稿：

| 维度 | 必须回答的问题 |
|---|---|
| 战斗 | 玩家多了什么新操作？旧敌人的应对方式如何改变？ |
| 跑图 | 哪些以前不能到达或代价极高的地方现在可以进入？ |
| 探索 | 新能力能发现、采集或处理什么？ |
| 领地 | 能建什么、保护什么，或提高什么管理能力？ |
| 世界反应 | 凡人、低阶修士与高阶势力如何重新评价该角色？ |
