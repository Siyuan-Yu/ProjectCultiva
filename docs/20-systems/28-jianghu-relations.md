## 0. 与架构冻结的对齐

- `Relationship` 与 `FactionMembership`／`FactionRole`／`ControlAuthority` **分离**。  
- 离开势力后关系**不清零**；可保留仇恨／友好／师徒等。  
- 角色死亡可使强绑定关系与剧情永久结束（允许错过内容）。  
- 延迟报复等用 `ScheduledEvent` + Ledger，禁止系统私有倒计时。  

## 1. 这个系统解决什么问题

《鬼谷八荒》最好的部分：你在客栈遇到一个人，能查出他跟世上谁有关系；要杀他之前，他会告诉你"我死了，某人不会放过你"。我们要保留并深化这一点，让关系成为**规则**而不是背景资料。

## 2. 关系网络

- NPC 拥有亲属、师徒、好友、仇敌、宗门与利益关系。
- 对话、酒馆、客栈、传闻与情报能逐步揭示这些关系。
- 开战或处决前明确提示潜在后果，例如："此人的师父是金丹修士，杀死他可能招致报复。"

## 3. 关系驱动什么

关系不是查看用的资料，而是影响：招募成功率、外交态度、复仇事件、战争借口、事件触发条件、据点归顺意愿。

## 4. 玩家要能利用关系，而非只被惩罚

联姻、结拜、拜师、离间、赎人、担保都应成为可用的策略手段。玩家应该可以：

- 通过关系网招募到本来不会加入的修士。
- 用某人的亲属关系换取和平，而不是必须一战。
- 故意制造两个敌对势力之间的仇怨。

## 5. NPC 的隐藏经历与机缘

**NPC 不只是任务发布器。** 每个 NPC 都可能藏着自己的经历、秘密与机缘，这些内容不会主动推送给玩家。

### 5.1 典型例子

一个普通的砍柴人，年轻时其实是低资质修士。修炼失败后落回凡人，在这里砍了半辈子柴。他没有传人，希望能把自己的功法传承出去。

如果玩家只把他当成一个交任务的 NPC，就永远拿不到这份功法。

这个例子说明了本系统在前期的价值：**营地里最不起眼的人，可能是玩家进入炼气的唯一路径。**

### 5.2 玩家如何发现

| 手段 | 说明 |
|---|---|
| 聊天 | 反复交谈，在合适的时机问到合适的话题 |
| 观察 | 注意其行为习惯、住处陈设、随身物件中的异常 |
| 神识 | 感知到其身上残留的灵气痕迹、情绪波动与说谎迹象，看出他动作里的修炼底子 |

第三条是神识在开局的直接价值：**同一个 NPC，迟钝者眼中和神识敏锐者眼中不是同一个人。**

### 5.2.1 神识与关系系统的边界

神识远高于对方时可获得交流优势：更容易提升好感、更容易看穿真实想法，某些情况下直接发现隐藏信息。

但**神识不能完全替代关系系统**。它提供的是信息与判断优势，不是自动通关：

- 知道对方想要什么，不等于拿得出来。
- 看穿谎言可以避免被骗，但不会自动产生信任。
- 关键传承、庇护与人情仍需时间、代价与选择来换。

神识的社交优势上限**待确定**，见 `2B-attributes-and-affinity.md`。

### 5.3 设计要求

- 隐藏信息必须**可被玩家主动挖出来**，不能只靠随机事件推送。
- 挖掘要有成本：时间、怀疑度，或者需要先帮对方做点什么。
- 秘密的类型要有区分：有的是功法传承，有的是仇怨，有的是藏起来的物件，有的只是一段过去。
- 前期至少有一个 NPC 的隐藏线索通向**功法**，作为进入炼气的可行路径之一。

**待设计：** 前期需要几个有隐藏内容的 NPC、各自的秘密类型与挖掘方式、这些秘密之间是否互相勾连。

## 6. 第一阶段验证事件：宗门使者审查

这个事件承载本作的一条核心特色：**江湖关系会影响宏观势力发展。**

背景：世界中正在发生规模远大于玩家的正魔大战。玩家此时只是偏僻地区的小势力，不会立刻成为天下大战的核心，因此大宗门暂时无暇顾及。玩家可以选择暂时寄人篱下，借助大宗门发展。

玩家推翻筑基管事弟子后，宗门随后派使者前来检查当前情况。玩家可以通过了解使者喜好、送礼与建立关系等江湖手段，影响使者回报的内容，从而改变上级宗门对玩家势力的判断。

这不是一次单独的“贿赂按钮”，而是关系与利益共同决定结果：

```
使者报告倾向
= 据点产出变化
+ 地方稳定程度
+ 旧管事的负面证据
+ 使者对玩家的私人关系
+ 宗门正魔大战的事务优先级
```

玩家可通过对话、观察和他人关系打听使者偏好，准备其真正喜欢的礼物。礼物的作用是提高私人关系、让使者愿意采用对玩家有利的解释，不是凭空洗掉所有罪责。

成功结果：使者回宗报告“旧管事治理恶劣，玩家虽越矩但接管有功”，宗门暂时默许玩家管理据点，并附加观察期或贡赋条件。

这个事件是第一阶段关系系统的验收标准：

- 玩家能提前发现一个 NPC 偏好。
- 玩家能为此准备对应物品或完成人情。
- 这段关系能改变一个原本可能招致高阶报复的政治后果。
- 结算界面能解释每项因素为什么推动了结果。

## 7. 与世界状态的关系

关系变化写入世界状态记账（`WorldLedger`），后续事件读取它，从而实现"世界记得玩家做过什么"。

需要记录的第一批状态包括：旧管事如何倒台、据点接管后的产出、玩家掌握的证据、使者收到的礼物、使者最终提交的报告。
