# 义务、配额与隐匿

> 状态：前期节奏与敛息方向已定 | 优先级：P0 | 最后更新：2026-07-31
> 上级：`docs/00-project/00-overview.md`
> 关联：`20-opening-experience.md`、`21-core-loop-and-time.md`（时间表与优先级）、`28-jianghu-relations.md`、`2G-first-chapter-flow.md`

## 1. 这个系统解决什么问题

前期需要一个持续的压力来源，让玩家真切感到时间和资源都不属于自己。没有这层压迫，"修炼需要挑时间挑地点"就只是一句设定。

核心体验定位：

> **玩家不是一开始没有力量，而是没有自由。**

感应境角色已有感知灵气的潜质，但劳役身份、时间表与主管规则剥夺了使用这些潜质的权利。本系统的目标是压迫，也是让玩家亲手把自由一点点偷回来，最终从被管理者变成管理者。

## 2. 核心结构：明面与暗面

| | 明面（义务） | 暗面（隐匿） |
|---|---|---|
| 玩家在做什么 | 完成主管下达的每日任务，遵守时间表 | 私下狩猎、采药、炼制、修炼、探索 |
| 时间来源 | 白天被时间表强制占用 | 夜间，或提前完工挤出的空档 |
| 收益 | 口粮、免于惩罚、维持现状 | 修为、私藏物资、真正的成长 |
| 风险 | 未完成任务、违反时间表推高主管愤怒 | 被发现会被没收甚至清算 |
| 长期意义 | 不会让你变强 | 唯一能让你脱离这个处境的路径 |

**关键设计点：官发的口粮能让人活着，对修炼毫无益处。** 老实干活这条消极解法被堵死，玩家必须冒险。

## 3. 明面：每日任务与主管机制

前期玩家处于劳役者身份。主管每天发布任务，例如：

```
今日任务（酉时前完成）
├── 收集木材      20
├── 击杀低级妖兽   3
├── 制作工具       3
└── 搬运资源       …
```

任务由若干条目组成，有明确数量与验收时限。三名角色可以分头去做。任务完成情况影响主管态度与愤怒。

### 完成与未完成

| 结果 | 后果 |
|---|---|
| 按时完成 | 发放口粮，主管愤怒小幅下降 |
| 超额完成 | 额外口粮或少量杂物，愤怒明显下降，态度改善 |
| 部分完成 | 愤怒上升，可能减少资源或口头警告 |
| 未完成 | 扣发口粮，次日任务加重，愤怒上升 |
| 连续未完成 | 进入更高愤怒阶段的惩戒 |

### 提前完工是核心奖励

任务有工时成本，角色能力越强完成越快。**省下来的时间归玩家自由支配**——这是前期最重要的正反馈，也是玩家第一次意识到"变强等于获得时间／自由"。

省下的时间可以用来：休息、私下修炼、探索周边、结识他人、准备暗面行动。

任务的具体生成规则**待设计**，不要在本期自行定稿。

## 4. 主管愤怒值

主管愤怒衡量管理者对玩家小队的不满与警惕。它是前期玩家面对的主要风险反馈。

具体数值后续设计；本阶段只定方向与阶段。

### 4.1 增加来源

- 没有按照时间表工作
- 没完成当天任务
- 任务只完成一部分
- 私自离开工作区域
- 偷偷修炼被发现
- 偷藏资源被发现

### 4.2 愤怒阶段（暂定）

| 阶段 | 后果方向 |
|---|---|
| 低 | 关注、口头警告 |
| 中 | 增加工作、减少资源、没收物品 |
| 高 | 鞭打、扣除食物、限制行动 |
| 极高 | 禁闭、更严重处罚 |

任何一级都不是游戏结束。最高级应设计成改变故事走向的出路（例如驱逐转入流亡），而不是强制读档。

### 4.3 与怀疑度的关系

既有设计中的**怀疑度**用于表达"暗面行动有多容易被察觉"。本期新增的**主管愤怒**是管理者的态度与惩罚阶段。

两者如何合并或分工：

- 方案 A：前期只向玩家展示愤怒一条风险条；怀疑度作为内部判定，发现后直接推高愤怒。
- 方案 B：怀疑度管"被发现的风险"，愤怒管"被发现或违规后的态度"。

**当前倾向方案 A（减轻心智负担），但标为待确定。** 无论哪条，前期都只让玩家盯一条主要风险反馈。

## 5. 玩家成长与主管系统的关系

主管系统的目的**不是单纯惩罚玩家**，而是体现玩家逐渐获得自由。

| 阶段 | 玩家与规则的关系 |
|---|---|
| 前期 | 必须遵守时间表与任务规则，违规代价高 |
| 中期 | 可通过药物、修炼、灵气护体、关系、贿赂等降低违反规则的风险 |
| 后期 | 获得领地与势力后，身份转换：从被管理者变成管理者 |

后期玩家将制定凡人生产时间、弟子修炼时间、巡逻与研究安排——时间表权限本身就是成长回报。详见 `21-core-loop-and-time.md`。

## 6. 劳役阶段核心循环

```
接受任务
→ 完成任务获得生存资源
→ 与 NPC 交流
→ 获取信息和机会
→ 寻找修炼资源
→ 偷偷修炼
→ 承担被发现风险
→ 逐渐获得力量
```

重点体现：玩家缺的是自由，不是感应灵气的潜质。第一章体验节奏见 `2G-first-chapter-flow.md`。

## 7. 暗面：隐匿行动

| 行动 | 产出 | 主要风险 |
|---|---|---|
| 私下狩猎 | 肉食，恢复体力，少量滋养 | 离开辖区、携带猎物返回时被撞见 |
| 采集药材 | 灵药，可服用或炼制 | 采集点可能在禁入区域 |
| 采集敛息资源 | 敛息草等，用于隐藏修为气息 | 采集点暴露、库存被搜 |
| 炼制丹药 | 修炼增益 | 炼制有烟火气味，容易被察觉 |
| 秘密修炼 | 修为／感应积累 | 耗时长、中途难中断、气息外泄 |
| 打听消息 | 情报、NPC 偏好、巡逻规律 | 问得太多本身就可疑 |

### 7.1 秘密灵地

前期关键转折：发现一处灵气显著更高的地方（例如废弃山洞，地点待确定）。灵地不能搬走，必须反复前往并承担暴露风险，自然产生"谁去修炼、谁去掩护"的分工。

### 7.2 敛息资源系统

进入炼气后，玩家需要隐藏修为，避免被筑基主管与其他修士察觉。

新增**敛息资源**（示例：敛息草）：

| 项 | 规则方向 |
|---|---|
| 作用 | 短时间隐藏自身修为气息 |
| 限制 | **不是永久效果**；时效结束后气息重新外泄 |
| 获取 | 需要持续采集／准备，不能一次采完管一辈子 |
| 用途 | 秘密修炼、夜间行动、接近主管或高阶修士时降低暴露风险 |

三人可分工：一人修炼、一人采集敛息与隐藏资源、一人探索与收集情报。

敛息失败或断药期间被感知到的后果，与主管愤怒／怀疑度挂钩；具体感知判定与资源刷新**待确定**。

### 7.3 离开辖区：高风险选项

玩家可以尝试离开起始荒村／资源点，但风险很高，不是默认推荐路线：

- 劳役身份仍受宗门管理
- 炼气实力不足
- 筑基主管可追捕
- 外界可能举报

因此前期主线仍是隐藏成长、就地积累。离开作为高风险分支保留。

## 8. 掩护（Cover）

- 角色可被指派为**掩护**，指定一名正在进行隐匿行动的同伴。
- 掩护者拦截、搭话、引开靠近的 NPC。
- 效果：显著降低被保护者被发现的风险，并延迟判定。
- 代价：掩护者不产出，长时间反常逗留也会积累风险。

典型抉择：

```
三人都去干活           → 任务轻松，愤怒低，但无修炼进度
一人修炼，两人掩护     → 修炼安全但产出锐减，当日任务可能完不成
一人修炼，无人掩护     → 进度快，但暴露风险陡增
一人修炼／一人采敛息／一人探情报 → 隐藏修士阶段的标准分工
```

## 9. 藏匿点（Stash）

私有物资不能随身携带，必须存放在藏匿点。

- 属性：**容量**与**隐蔽度**。
- 搜查时按隐蔽度判定；超出容量的部分更易暴露。
- 前期一到两个藏匿点即可。

被搜出：物资没收、主管愤怒大幅上升、可能连带惩戒。

## 10. 贿赂与人情

- 关键 NPC（主管、监工、守卫、伙房、账房）有可被发现的偏好。
- 满足偏好后解锁便利：夜间放行、验收放水、提前通报搜查、无视少量私藏。
- 风险对等：被上层发现则双方同罪；关系不牢可能反噬。

这条线通到后期：前期贿赂守卫，后期收买敌对势力执事，应是同一套机制。

## 11. 明确不做：实时潜行

**不做视野锥、噪音条、蹲伏躲避这类实时潜行操作。**

玩家的决策应是：派谁去、什么时候去、藏在哪里、什么时候收手、要不要买通谁——而不是贴墙走位。

## 12. 后期演化

| 前期 | 中期 | 后期 |
|---|---|---|
| 主管的每日任务 | 宗门的贡献指标 | 对上级势力的岁贡与义务 |
| 被时间表支配 | 开始有自己的修炼时段 | 为他人制定时间表 |
| 偷偷修炼与私藏 | 私下培养亲信、藏匿资源 | 暗中扩军、秘密洞府 |
| 主管愤怒 | 执事与同门的猜忌 | 敌对势力的情报与戒备 |
| 贿赂守卫 | 打点执事 | 收买敌方要员 |

## 13. 节奏与心智负担

- **凡人觉醒阶段**目标：约 **40 分钟～1 小时**内进入炼气（见 `20-opening-experience.md`）。这不是长期凡人经营。
- **隐藏修士阶段**可更长：继续劳役外表，用敛息与分工积累，直到具备掀桌条件。
- 期间必须有可见进展：发现灵地、取得功法、第一次炼气、学会敛息、买通第一个守卫、察觉管事把柄。
- 任务内容要随天数变化。
- 结束由玩家推动（掀桌）或被动触发（暴露流亡）。

> **说明：** 早前“劳役阶段约 15–30 游戏天／1–1.5 小时”的写法已由“40 分钟～1 小时入炼气 + 随后隐藏修士阶段”取代；具体游戏天数随时间流速校准。

### 分层解锁

| 阶段 | 玩家主动管理的事 | 系统默默跑的事 |
|---|---|---|
| 凡人觉醒前段 | 领任务、三人分工、完成交差 | 寻路、采集、战斗基础、验收 |
| 凡人觉醒后段 | 省下的时间干什么；找灵地／功法；准备第一次突破 | 同上 |
| 隐藏修士前段 | 今晚去不去偷练；敛息是否够用；东西藏哪 | 愤怒／发现风险自动升降；默认藏匿点 |
| 隐藏修士后段 | 掩护与三人分工、打听偏好、贿赂 | 偏好打听可做成事件 |
| 掀桌前 | 攒战力／攒把柄，选时机摊牌 | 管事日常巡逻与任务规则 |

**前期只让玩家盯一条主要风险反馈（倾向为主管愤怒）。** 体力、伤势、饥饿用颜色或短提示表达。

提供默认预案：「三人全力赶任务」「一人去灵地、两人掩护」「一人修炼、一人采敛息、一人探情报」。

## 14. 与其他系统的接口

- 输入：角色能力、时间表与时间系统、灵地属性、战斗结果。
- 输出：修为、私藏物资、主管愤怒、NPC 关系、剧情分支、第一个据点归属、时间表制定权。
- 第一卡点：管事弟子（筑基初期），见 `20-opening-experience.md`。
