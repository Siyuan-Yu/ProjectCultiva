# 义务、配额与隐匿

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`20-opening-experience.md`（前期形态）、`21-core-loop-and-time.md`（时间来源）、`28-jianghu-relations.md`（贿赂与人情）

## 1. 这个系统解决什么问题

前期需要一个持续的压力来源，让玩家真切感到"时间和资源都不属于自己"。没有这层压迫，"修炼需要挑时间挑地点"就只是一句设定；有了它，玩家挤出来的每一刻钟都有分量。

它同时给了玩家第一个可以主动破局的目标：从被支配，到偷偷积累，到有能力掀桌。

## 2. 核心结构：明面与暗面

整个系统建立在一组对立上。

| | 明面（义务） | 暗面（隐匿） |
|---|---|---|
| 玩家在做什么 | 完成监工下达的每日配额 | 私下狩猎、采药、炼制、修炼 |
| 时间来源 | 白天，被强制占用 | 夜间，或提前完工挤出的空档 |
| 收益 | 口粮、免于惩罚、维持现状 | 修为、私藏物资、真正的成长 |
| 风险 | 完不成会被惩罚 | 被发现会被没收甚至清算 |
| 长期意义 | 不会让你变强 | 唯一能让你脱离这个处境的路径 |

**关键设计点：官发的口粮能让人活着，但对修炼毫无益处。** 这一条把"老实干活就好"这个消极解法直接堵死，玩家必须冒险。

## 3. 明面：每日配额

### 形态

每天清晨，监工下达当日配额，例如：

```
今日配额（酉时前完成）
├── 采伐木材      20
├── 剿灭妖兽       3
└── 打造武器       3
```

配额由若干条目组成，每条有明确数量与验收时限。三名角色可以分头去做不同条目。

### 完成与未完成

| 结果 | 后果 |
|---|---|
| 按时完成 | 发放口粮，怀疑度小幅下降 |
| 超额完成 | 额外口粮或少量杂物，怀疑度明显下降，监工态度改善 |
| 未完成 | 扣发口粮，次日配额加重，怀疑度上升 |
| 连续未完成 | 触发惩戒事件（体罚、禁闭、调往更苦的岗位） |

### 提前完工是核心奖励

配额有工时成本，角色能力越强完成越快。**省下来的时间归玩家自由支配**，这是前期最重要的正反馈，也是玩家第一次意识到"变强等于获得时间"。

省下的时间可以用来：休息恢复体力、私下修炼、探索周边、结识他人、准备暗面行动。

## 4. 暗面：隐匿行动

### 可做的事

| 行动 | 产出 | 主要风险 |
|---|---|---|
| 私下狩猎 | 肉食，恢复体力，少量滋养 | 离开辖区、携带猎物返回时被撞见 |
| 采集药材 | 灵药，可服用或炼制 | 采集点可能在禁入区域 |
| 炼制丹药 | 修炼增益 | 炼制有烟火气味，容易被察觉 |
| 秘密修炼 | 修为 | 耗时长、中途难以中断、气息外泄 |
| 打听消息 | 情报、NPC 偏好、巡逻规律 | 问得太多本身就可疑 |

### 秘密灵地

前期的关键转折物：三人在某次外出中发现一处灵气浓度远高于营地的地方。它让秘密修炼从"效率极低"变成"值得冒险"。

灵地的价值在于**它不能被搬走**。玩家必须反复前往、反复承担暴露风险，这就自然产生了"谁去修炼、谁去掩护"的分工决策。

## 5. 怀疑度（Suspicion）

### 定义

衡量"管理者对这几个人有多在意"的数值。它是暗面行动的统一代价，也是本系统的核心资源。

范围建议 0–100，按角色和小队分别记录（个人行为算个人的，连带影响小队整体）。

### 上升来源

- 夜间离开住处、出现在不该出现的位置
- 携带或藏匿私有物资时被目击
- 配额未完成、验收时数目对不上
- 频繁打听、与守卫过分熟络、行为模式突变
- 修炼时气息外泄（修为越高越难掩盖）

### 下降来源

- 按时或超额完成配额
- 一段时间内没有可疑行为（自然衰减）
- 贿赂或人情
- 主动做出讨好举动（帮监工办私事、上交部分收获）

### 阈值与后果

分级触发，**任何一级都不是游戏结束**。

| 区间 | 状态 | 后果 |
|---|---|---|
| 0–25 | 无人在意 | 夜间巡逻稀疏，暗面行动风险低 |
| 26–50 | 被留意 | 巡逻加密，夜间外出更易被撞见 |
| 51–75 | 被盯上 | 触发搜身与搜查，私藏物可能被没收 |
| 76–99 | 被清算 | 加重配额、扣粮、体罚致伤、关禁闭数日 |
| 100 | 摊牌 | 驱逐或武力处置，**进入剧情分支而非失败结算** |

最高级要设计成出路：被赶出去意味着失去庇护，但也摆脱了配额，可以转入流亡路线。玩家的失败应该改变故事走向，而不是回读档。

## 6. 掩护（Cover）

三人分头行动的策略价值主要由这个机制提供。

- 角色可被指派为**掩护**，指定一名正在进行隐匿行动的同伴作为保护对象。
- 掩护者会主动拦截、搭话、引开靠近保护对象的 NPC。
- 效果：显著降低被保护者的怀疑度积累速度，并延迟"被发现"判定。
- 代价：掩护者本身不产出任何东西，且长时间反常逗留也会积累自己的怀疑度。

典型抉择因此成立：

```
三人都去干活      → 配额轻松完成，怀疑度低，但没有任何修炼进度
一人修炼，两人掩护 → 修炼安全但产出锐减，当日配额可能完不成
一人修炼，无人掩护 → 产出勉强够，修炼进度快，但暴露风险陡增
```

这就是前期每天要做的核心决定。

## 7. 藏匿点（Stash）

私有物资不能随身携带，必须存放在藏匿点。

- 属性：**容量**与**隐蔽度**。
- 搜查时按隐蔽度判定是否被翻出；超出容量的部分显著更易暴露。
- 可以更换位置或改良（挖深、伪装、设在无人去的地方）。
- 前期只需要一到两个藏匿点，属性保持简单。

被搜出的后果：物资没收、怀疑度大幅上升、可能连带惩戒。这让玩家有动机分散存放而不是全堆一处。

## 8. 贿赂与人情

这是江湖关系系统在前期的具体形态，也是玩家第一次学会"关系可以当作工具"。

- 每个关键 NPC（监工、守卫、伙房、账房）有**可被发现的偏好**：某种酒、某味药材、某个心事、某个仇人。
- 偏好通过观察、闲聊、打听或情报获得，不直接显示。
- 满足偏好后关系改善，解锁具体便利：夜间放行、验收放水、提前通报搜查、无视少量私藏。
- 风险对等：被上层发现则双方同罪；关系不牢的守卫可能反过来长期勒索，或在关键时刻反咬。

这条线要一直通到后期。前期贿赂一个守卫和后期收买敌对势力的执事，走的应该是同一套机制。

## 9. 明确不做：实时潜行

**不做视野锥、噪音条、蹲伏躲避这类实时潜行操作。**

理由有三条：

1. 实时潜行是另一个游戏类型，操作精度要求与本作"暂停即时策略"的定位冲突。
2. 它的实现与调优成本极高，而且只服务前期一小段流程。
3. 抽象化的怀疑度可以平滑演化成后期的势力猜忌、情报与外交，实时潜行则完全无法复用。

玩家的决策应该是**派谁去、什么时候去、藏在哪里、什么时候收手、要不要花代价买通谁**，而不是操作角色贴墙走位。

## 10. 后期演化

这个系统不是一次性的开场关卡，它的结构会一路沿用，只是换层皮。

| 前期 | 中期 | 后期 |
|---|---|---|
| 监工的每日配额 | 宗门的贡献指标 | 对上级势力的岁贡与义务 |
| 偷偷修炼与私藏 | 私下培养亲信、藏匿资源 | 暗中扩军、秘密洞府、隐藏真实实力 |
| 监工的怀疑 | 执事与同门的猜忌 | 敌对势力的情报与戒备 |
| 贿赂守卫 | 打点执事 | 收买敌方要员 |
| 藏匿点 | 密室 | 暗桩与秘密据点 |

玩家在开局学会的心智模型，后期可以直接复用，这正是把它放在开局的价值。

## 11. 节奏与心智负担约束

这段玩法的双重风险是：变成"打工模拟器"，以及**同一天塞太多系统导致过载**。

### 时长

- 劳役阶段控制在**游戏内 15–30 天**，实际游玩约 1–1.5 小时。
- 期间必须有可见进展：发现灵地、第一次成功偷练、买通第一个守卫、察觉管事弟子的把柄。
- 配额内容要随天数变化，不能同一组任务重复二十遍。
- 结束由玩家推动（掀桌）或被动触发（暴露流亡），不靠熬天数过关。

### 分层解锁（防过载）

| 阶段 | 玩家主动管理的事 | 系统默默跑的事 |
|---|---|---|
| 第 1–2 天 | 三人怎么分配额 | 寻路、采集、战斗基础、交差结算 |
| 第 3–5 天 | 省下的时间干什么；发现灵地 | 同上 |
| 第 6–12 天 | 今晚去不去偷练；东西藏哪 | 怀疑度自动升降；一个默认藏匿点 |
| 第 12 天以后 | 谁掩护、要不要买通守卫 | 偏好打听可做成事件，不强迫玩家查遍地图 |
| 掀桌前 | 攒战力／攒把柄，选时机摊牌 | 管事弟子的日常巡逻与配额规则 |

**同时只让玩家盯一条风险条：怀疑度。** 体力、伤势、饥饿用颜色或短提示表达，不要各开一张管理面板。

提供默认预案：「三人全力赶配额」「一人去灵地、两人掩护」一键下达，减少每天重做相同决策。

## 12. 与其他系统的接口

- 输入：角色能力（决定配额完成速度）、时间系统（白天与夜间时段）、灵地属性（决定偷练收益）。
- 输出：修为、私藏物资、怀疑度、NPC 关系、剧情分支、第一个据点的归属。
- 第一卡点：管事弟子（筑基初期），见 `20-opening-experience.md`。
