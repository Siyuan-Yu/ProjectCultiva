## 0. 文档定位与使用方式

### 0.1 这是什么

描述玩家处于**荒村杂役时期**时，**可能**经历的叙事内容、人物反馈与关系变化。

它是：

- 叙事**状态**、**触发条件**、人物**反馈表**、可重复／可错失事件的设计稿  
- 与义务／时间表／隐匿／关系账本等玩法系统对接的内容层说明  

它不是：

- 固定章节制或「第一章／第二章」推进  
- 必须按日完成的线性剧情 RPG 脚本  
- 游戏内会显示的章节标题或强制过场清单  

### 0.2 核心命题（阶段主题，非任务目标）

> 当一个人连自己的时间都无法拥有，他还能不能决定自己的命运？

体验锚点（对齐 `20`／`2F`）：**玩家不是一开始没有力量，而是没有自由。**

### 0.3 强制遵守的修正原则

| # | 原则 |
|---|---|
| 1 | **不**规定必须在第几天触发偷修 |
| 2 | **不**规定必须在固定时刻完成某段剧情 |
| 3 | **不**设计明确的「本阶段结束点／通关过场」 |
| 4 | 玩家与初始三人姓名、性别、外貌均**不固定** |
| 5 | **不**写死「现实型伙伴／理想型伙伴」等固定主角团人设 |
| 6 | 角色行为尽量由**属性、性格、关系、经历**驱动 |
| 7 | 偷修发现取决于探索、悟性、NPC 提示、修炼知识与玩家行为 |
| 8 | 主管**不会**在本阶段某个固定结尾失去权力 |
| 9 | 主管持续掌控荒村，直至玩家达到**筑基**并击败／赶走／杀死／迫使其交权（见 §11 冲突） |
| 10 | 主管是**长期人物关系与压迫来源**，不是固定阶段 Boss |
| 11 | 文档重点＝状态／触发／反馈／可重复事件，而非起承转合剧本 |

### 0.4 阶段范围（空间与身份，非日程表）

**在场：** 荒村／宗门外围资源点尺度；三名感应境劳役核心角色；一名主管；若干杂役／村民与可重复互动者。  

**玩法身份（Freeze）：** 三人隶属压迫宗门，职位为杂役／劳役弟子；玩家可 DirectControl。  

**离开本叙事文档覆盖的信号（开放，非强制剧情句号）：** 例如已稳定掌握偷修／藏修、已入炼气并转入「隐藏修士」内容密度、或关系／风险状态使荒村日常不再是主矛盾——由 `20`／`2G`／后续内容文档承接，**不在此写死过场**。

### 0.5 明确不做

- 天命之子／隐藏血脉／仙帝转世  
- 大陆阴谋、飞升真相、正魔大战正文  
- 新增独立善恶值、复杂好感数值系统或巨型分支树  
- 把「第一天」写成不可偏离的强制脚本  
- 在本阶段设定主管倒台的固定剧情结局

## 1. 荒村开局五分钟的初始呈现

### 1.1 目标状态（开场结束时应成立）

玩家应立刻理解：

1. 这是修仙世界。  
2. 自己处于最底层。  
3. 世界不围绕自己运转。

### 1.2 呈现结构（演出方向，可裁剪）

| 块 | 内容方向 | 建立的认知 |
|---|---|---|
| 远景 | 山门、御剑、仙家轮廓、灵光／鹤影 | 仙路存在且宏大 |
| 下移 | 灵气变淡、土路、边缘聚落 | 世界分层 |
| 荒村晨景 | 破屋、集合、搬运、带伤出工、口粮抱怨 | 底层日常；无人「迎接主角」 |
| 主管分配 | 清点、当日配额、未完成→扣粮／惩罚／态度恶化 | 时间与食物被制度拿走 |

旁白仅作方向草案，例如：「世人皆知仙人可移山填海／少有人知仙山之下有无数凡人供养。」可改为更短字幕或纯环境叙事。

### 1.3 情绪落点（非「必须恨主管」）

优先念头：

> 为什么我连今天怎么度过都不能自己决定？

开场**不**强制仇恨高潮；恐惧、麻木的从众与轻微不甘即可。

### 1.4 与玩法的接口

开场结束后进入可游玩状态：Schedule／DailyQuota／三人可控——对齐 Demo／VS 骨架。之后内容全部由玩家行为与世界规则驱动。

## 2. 初始三名角色的生成与关系原则

### 2.1 不固定清单

| 项 | 规则 |
|---|---|
| 姓名／性别／外貌 | 玩家自定义或生成；剧情对白用关系称呼／职位，避免锁死专名 |
| 主角团标签 | **禁止**文档级写死「现实型／理想型／勇敢型」固定席位 |
| 开局关系 | 可为同乡、路上结伴、互不相识等——由生成结果与经历标签决定，**非唯一真结局** |
| 禁止人设 | 隐藏血脉、天命、仙人转世 |

### 2.2 半固定要素池（对齐 `20`，行为驱动源）

每名角色从要素池抽取／由玩家调整，且须能在世界上**真正被引用**（地点、NPC、事件）：

| 要素 | 影响叙事的方式 |
|---|---|
| 家乡 | 可回访、旧识、方言／习惯差异 |
| 身世标签 | 对话选项、对压迫的态度倾向 |
| 性格标签（TraitTag） | 自动行为、对话语气、对风险的默认反应 |
| 天赋倾向／灵根占位 | 劳役分工效率、对某类异常更敏感 |
| 悟性／神识等属性 | 发现灵地、读懂残卷、察觉他人异常的速度 |
| 经历碎片 | 「见过反抗失败」「初来乍到」「欠过人情」等，改变反馈 |

### 2.3 行为应由状态推导（示例，非剧本）

叙事反馈查表时，优先问：

1. 该角色当前 TraitTag／属性如何？  
2. 与玩家／同伴的 RelationshipLedger（或缓存态度）如何？  
3. 近期经历（受罚、被帮、见证偷修）如何？  

而不是：「因为他是队伍里的理想位，所以必须劝善。」

**示例映射（可扩展，非三人定装）：**

| 倾向来源 | 发现偷修机会时可能反应 |
|---|---|
| 高谨慎／曾见惩罚 | 反对立即尝试；要求先摸清巡逻 |
| 高好奇／高悟性 | 更早指出异常；愿试探 |
| 高忠诚于同伴 | 参与掩护或坚持共享秘密 |
| 高利己／恐惧主管 | 旁观、疏远，极端时埋下告密风险（见 §5） |
| 高同情弱者 | 更易在配额冲突中偏向帮助他人 |

同一角色可随关系与经历**改变倾向**（例如被连坐惩罚后更谨慎）。

### 2.4 三人关系的阶段状态（开放）

关系用状态描述，不用「第几天升到生死之交」：

| 状态 | 含义 | 典型进入条件（示例） |
|---|---|---|
| 共事 | 同一配额体系下的协作 | 开局默认 |
| 互利 | 分工／掩护已发生过 | 共同提前完工、互相补任务 |
| 共谋 | 共享偷修或私藏秘密 | 共同进入秘密灵地或约定隐瞒 |
| 裂隙 | 信任受损 | 独吞机会、告密边缘、连累对方 |
| 疏离 | 减少夜间共同行动 | 长期忽视互动或对立选择 |

可进可退；无强制顺序。

### 2.5 开局硬约束（玩法）

- 境界：感应境（可感灵气、低效基础吸收；不能正式功法／真灵力）  
- 「看见异常」主归因：**神识／悟性／经历**，非感应境透视（`22`）

## 3. 荒村第一天可观察到的生活内容

> **本节只描述进入游戏后最初一天「可能看到」的基础生活节奏与环境信息。**  
> **不是**固定剧情脚本：玩家可跳过对话、提前探索、只干活、或在允许时 Override 日程。错过某条观察**不阻断**后续可能性。

### 3.1 一日节奏（环境默认，非任务清单）

| 时段（表现层示意） | 可能观察到的生活内容 | 信息类型 |
|---|---|---|
| 清晨 | 集合、清点、带伤／迟到者、配额公布、口粮与惩罚被提及 | 制度压迫 |
| 上午 | 多工种劳作；他人争执／互助／抱怨；时间表限制「该在岗」 | 世界自转 |
| 中午 | 口粮差异；未完成者少领；偶发上层过客（短、远） | 阶级差（食物／站位／药） |
| 下午 | 边缘区域劳作；植物、温度、虫鸟异常等**可选线索** | 可错失的暗示 |
| 傍晚 | 验收、评价、未完成者受罚风险；主管提及「上面的数」 | 压力来源有上层 |
| 夜晚 | 宵禁／休息默认；有限私人时间窗口 | 首次「时间可自决」的体感 |

逻辑时间仍以 WorldTick／Schedule 为准（`21`）。

### 3.2 可重复／可错失的观察事件（非一次性主线）

| ID（工作） | 内容方向 | 重复性 | 错过后果 |
|---|---|---|---|
| OBS-伤员出工 | 带伤仍被催上工 | 可换人换日再出现 | 无；仅少一条共情锚 |
| OBS-口粮克扣 | 某人因差额少饭 | 与 Quota 完成度联动 | 无 |
| OBS-老人旧梦 | 年老杂役提及「也曾想御剑」 | 低频率可再聊深 | 延迟该 NPC 线，不锁死偷修 |
| OBS-上层一瞥 | 传令／弟子短暂过村 | 稀有 | 无 |
| OBS-边缘异常 | 药园／林凹／干涸泉等微异常 | 依赖地点与神识检定 | 延迟发现路径 A（§4） |

### 3.3 叙事要求

- 用生活细节表达制度，少用说明演讲。  
- NPC 有自己的事做；大量内容与玩家无关。  
- 「第一天」结束后，同类事件可按权重继续刷新，形成杂役生活的**常态感**。

## 4. 偷修可能性的多种发现路径（第一次偷修状态）

### 4.1 「第一次偷修状态」定义

指角色从「模糊感到灵气／听说修炼」进入「**主动、持续地在不宜被发现的条件下引导／确认可修行**」的状态变迁。

- **不是**固定日期的剧情事件名  
- **不是**必须完成的大境界突破（入炼气仍按 `22`／`25`／`2G` 条件，可远晚于首次偷修）  
- 可被推迟很多天；也可因高悟性＋主动探索较早发生  

### 4.2 地点气质（内容约束）

秘密灵地／机会点应显得：潮湿、荒废、狭小、无人关注；灵气仅略高；对真修士无价值。  
候选包装：废弃药园深处、林中凹地、干涸灵泉、废弃劳作角、与 `2F` 兼容的狭小洞穴等——**工作名待确认**，禁止华丽仙境。

### 4.3 发现路径（多选一或叠加，均可延迟）

| 路径 | 触发方向 | 帮助条件 | 延迟／阻碍条件 |
|---|---|---|---|
| A 探索观察 | 在边缘 Repeated Observe／停留 | 神识、悟性、相关天赋 | 只蹲工位、从不 Override 夜间 |
| B NPC 提示 | 老人、前偷修者痕迹、醉话、仇怨透露 | 关系、帮助过对方、多次交谈 | 无互动、高怀疑下 NPC 闭嘴 |
| C 知识残片 | 残卷、磨平石面、旧刻痕、破损器具 | 悟性、识字／经历标签 | 未调查痕迹、毁坏现场 |
| D 行为连带 | 为躲巡逻／采药误入；护送伤员抄近路 | 勇敢／好奇特质、任务路线随机 | 从不离开主路 |
| E 同伴感知 | 某同伴属性检定先成功，再告知玩家 | 该同伴高神识／好奇；关系非裂隙 | 同伴低感知或关系疏离不分享 |

发现时间＝玩家节奏；**无「第 N 天必出」**。

### 4.4 进入「第一次偷修状态」的软条件（叙事层）

满足越多越容易发生，**非**全或无主线锁：

- 已知或怀疑存在更高灵气角落  
- 拥有一小段不被 Schedule 完全占满的时间（夜间／提前完工）  
- 至少一名可控角色愿意尝试或可被说服（见同伴反应）  
- 玩家未处于极高暴露／禁闭等无法行动状态  

### 4.5 角色首次清晰感知灵气时的反应池

由属性／性格抽取 1～2 条，避免三人同一句：

| 反应类型 | 可能表现 |
|---|---|
| 震撼—希望 | 沉默、手抖、低声确认「真的有」 |
| 恐惧—后果 | 先看巡逻方向；要求立刻离开 |
| 分析—经验 | 判断「有人来过」；估计风险 |
| 兴奋—冲动 | 想多待一会；需他人按住 |
| 麻木—后知 | 起初不信，事后才反复回想 |
| 功利—盘算 | 先问「能换口粮吗／能变强吗」 |

感应境角色本就可感灵气（`22`）：文案强调「第一次**抓住／确认可主动用**」，避免「开局前完全不知天地有灵」。

### 4.6 同伴立场（参与／旁观／反对／告密）

对「是否今晚试」等决策，每人独立结算态度：

| 立场 | 含义 | 常见驱动 |
|---|---|---|
| 参与 | 同入或护法／放风 | 高信任、好奇、共情玩家目标 |
| 旁观 | 不阻止也不深入 | 中风险偏好、关系一般 |
| 反对 | 劝阻、拖延、要求更多准备 | 高谨慎、刚受罚、见过失败 |
| 告密倾向 | **极端**；通常需高压或裂隙＋利己 | 被威胁、仇恨玩家、换取免罚——应罕见且有前兆 |

告密**不**设计成「选错就永久删除修炼可能」的陷阱；若发生，应转为风险剧情（搜查、怀疑上升、转移灵地），仍保留其他发现／再尝试路径。

### 4.7 主管怀疑接口（长期，非脚本杀）

异常行为可推高主管相关 **Suspicion**／关注（对接 `2F` 三层隐匿，不合并成单一「剧情怒气条」）：

| 异常信号（示例） | 可能反馈 |
|---|---|
| 工时内频繁失踪 | 盘问、加派脏活 |
| 夜间离铺被撞见 | 警告→搜查 |
| 神情恍惚、效率骤变 | 盯梢加重 |
| 多人同时异常一致 | 怀疑「串通」 |

主管怀疑是**持续压力**，不是「第一次偷修后的必爆事件」。

### 4.8 偷修经历如何改变关系（状态迁移示例）

| 共同经历 | 可能关系变化 |
|---|---|
| 三人共谋成功且无人出卖 | 共事→共谋；后续掩护默认更顺 |
| 仅二人知情 | 知情者更密；第三者易生裂隙（可修补） |
| 强行拉反对者参与且出事 | 裂隙或恐惧绑定 |
| 独吞信息不分享却被发现 | 信任下降；对白长期带刺 |
| 有人反对但仍帮你放风 | 关系深化（「我不认同，但保你」） |

## 5. 玩家行为产生的选择与关系反馈

### 5.1 设计原则

- 选择表达「你是什么样的人」，**不**立刻改写能否修炼的主可能。  
- 反馈落在：同伴态度、杂役群体看法、主管关注、对白分支、小事件权重。  
- **不**标善恶；**不**新建独立道德点数系统（可用已有关系／怀疑等）。  
- 同类两难可在杂役阶段**重复变体出现**（换人、换日、换配额）。

### 5.2 行为族 A：配额与弱者

| 玩家行为方向 | 可能反馈 |
|---|---|
| 出让成果帮未完成者 | 部分杂役印象↑；己方压力↑；谨慎同伴可能反对 |
| 向主管求情 | 主管关注↑；或无效／加码 |
| 沉默旁观 | 安全；同情倾向同伴可能冷淡 |
| 揭发隐瞒 | 主管满意倾向；群体戒备↑ |

### 5.3 行为族 B：资源与规则边界

藏粮、藏药、截留边角料、拒绝私藏等：

- 影响私藏风险、能否支撑夜间外出／敛息材料筹备（对接 `2F` 语言）  
- 同伴依特质：有人视为聪明，有人视为脏，有人只问「别连累我」

### 5.4 行为族 C：秘密与信任

分享灵地、独探、暂缓、只告诉一人：

- 改变共谋／裂隙状态（§2.4）  
- 影响日后掩护、告密抗性、共同修炼意愿  
- **禁止**「告诉主管＝永久删机缘」的单次死刑分支；最多转为高风险线

### 5.5 可重复日常互动（举例）

夜间探望伤员、听传闻、赌博式闲聊、帮工换人情、练习「看起来更听话」——用于刷关系与情报，无章节进度条。

## 6. 主管的长期人物塑造与态度变化

### 6.1 定位

| 项 | 说明 |
|---|---|
| 工作名 | 赵管事／赵主管等（**待确认**；游戏内可用职位称呼） |
| 玩法身份 | 管事弟子／主管；约筑基层级（对齐 `20` 管事战力） |
| 叙事功能 | 长期压迫来源＋「接受规则后的人」镜像；**非**定时击杀的阶段 Boss |
| 权力 | 本阶段与其后很长一段时间**持续掌权** |

### 6.2 人物层次（始终可并存）

1. 玩家会怕他  
2. 玩家会恨他的一部分行为  
3. 玩家能理解他何以至此（不＝原谅）

自我解释方向（草案）：「上面先拿我问罪。」——不洗白其转嫁行为。

### 6.3 态度状态机（示例，可调参）

主管对玩家小队的态度是**长期变量**，随行为漂移，而非剧情日切换：

| 态度状态 | 表现方向 | 常见进入 |
|---|---|---|
| 漠视 | 视作可替换劳力 | 开局／表现普通 |
| 可用 | 少骂、派关键活 | 稳定超额、告密有功 |
| 盯梢 | 盘问、突击检查 | 失踪、夜间异常、效率诡异 |
| 憎恶 | 加罚、克扣、当众折辱 | 顶撞、连续差额、私藏败露 |
| 利用 | 威胁利诱做脏事 | 抓住把柄或看中「聪明」 |
| 戒备 | 减少单独机会、换工种隔离 | 怀疑修炼／串通 |

可逆：老实一段时间可从盯梢回到漠视；大事件可跳级。

### 6.4 细节埋伏笔（可分散在多日观察）

旧伤、懂一点低级行内知识、对偷懒者的复杂神色、旧物、老人似曾识、对无力劳动者偶尔松一点却不许被看穿——**无集中「身世揭秘过场」要求**。

### 6.5 权力结束条件（跨阶段，本文件只声明）

主管失去荒村控制，仅当玩家侧达成：**境界达到筑基**，并成功击败／赶走／杀死／迫使其交权。  

此前一切偷修、入炼气、藏修、关系经营，都是在其阴影下的长期博弈。  
（与部分既有「炼气阶段掀桌」表述的冲突见 §11。）

## 7. 荒村杂役阶段的整体情绪目标

### 7.1 情绪是状态，不是幕次

| 情绪状态 | 玩家可能想法 | 常见支撑体验 |
|---|---|---|
| 落差 | 「仙山之下竟是这样。」 | 开场呈现 |
| 受控 | 「时间不是我的。」 | 日程、配额、验收 |
| 不适的习惯化 | 「他们怎么都认了。」 | 路人麻木、重复日常 |
| 微自主 | 「只有这一点是我选的。」 | 夜间／提前完工 |
| 危险的希望 | 「也许真有一条缝。」 | 接近或进入偷修状态 |
| 共谋感 | 「有人知道我的秘密。」 | 共享灵地／掩护 |
| 复杂压迫 | 「他也可恶，也可怜，仍该死在我头上。」 | 与主管多日互动 |

无强制「第几天必须从 A 情绪进到 B」；可长期停在受控感，也可较早尝到希望。

### 7.2 阶段体验成功标准（设计验收，非玩家任务）

若抽样不同节奏的玩家：

- 慢节奏：多日只干活＋听闻，仍感到世界在转、压迫真实  
- 快节奏：早发现灵地，仍感到风险与关系重量，而非「领主线奖励」  
- 皆应在意**身边具体的人**，而非天下大势  

本阶段**不**以占领荒村或主管倒台为情绪高潮必选项。

## 8. 后续人物、地点和势力伏笔

伏笔以**可发现内容**存在，无揭示日程。

| 伏笔 | 本阶段可露出 | 后续可能走向 |

| 荒村连着上层 | 指标令、短暂巡查 | 贡赋、人口、妖兽压力；完整势力后置 |

禁止本阶段展开：飞升、天道终极、大宗门战争正文。
