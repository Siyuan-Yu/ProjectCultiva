# 世界与据点

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`

## 1. 这个系统解决什么问题

世界是所有内容的容器，同时也是扩张玩法的棋盘。它要能承载"从一个荒村打到数十座城镇"的尺度跃迁，又不能带来无缝开放世界的美术与内容成本。

## 2. 结构：大战略地图 + 分层据点

- 世界包含数十个主要城镇或区域。
- 主要城镇下属若干次级据点：村庄、农田、森林、矿区、渔村、荒地、秘境、灵地。
- 据点可以探索、占领、建设、劫掠、保护，或交给部属管理。
- 道路、山脉、河流与危险区域影响行军；飞行等境界能力会改变通行规则。

不做无缝 3D 开放世界。

## 3. 势力生态

- 宗门、家族、城镇政权、妖族与散修势力争夺人口、资源与灵地。
- 每个据点都有归属、守护力量、产出、人口、灵气浓度与关系网络。
- 占领不是换个颜色：新领主要面对民心、旧势力关系、资源恢复与高阶报复。

## 4. 据点的数据维度

每个据点至少需要：归属势力、守护战力、人口规模、产出类型、灵气浓度与五行属性、与周边据点的连接关系。
