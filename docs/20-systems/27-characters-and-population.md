# 角色、修士与凡人人口

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`

## 1. 这个系统解决什么问题

要同时满足两个看似矛盾的需求：每个修士都有独特故事和培养价值；势力规模扩大到数千人时玩家不会被操作量压死。解法是**两套粒度**。

## 2. 核心修士（逐个养成）

- 拥有完整的境界、属性、灵根、功法、技能、装备、关系与经历。
- 可组成若干小队，执行探索、驻守、外交与战争任务。
- 长期目标上限约 **30–50 人**；常用出征小队应远少于这个数量。
- 上限由势力影响力、设施与制度决定，可随发展提升。

### 招募来源

酒馆结识、任务同行、宗门关系、历练救援、主动邀请、凡人灵根筛选。

## 3. 凡人人口（群体管理）

- 不逐个模拟完整角色面板，以人口组和岗位管理。
- 定期进行灵根检测，少数人才可转化为可培养修士。
- 负责农业、生产、运输、基础军事与建设。
- 修士为凡人提供庇护，凡人为修士提供组织与资源基础。

## 4. 判定标准

领地人口翻倍不应让玩家的逐个操作量翻倍，但新招募的每名修士仍要有明确个性与培养价值。

## 5. 未决问题

- [ ] 修士是否会因不满、理念冲突而叛离？（与 `28-jianghu-relations.md` 耦合）
- [ ] 凡人是否需要个体化的少数"名人"（村长、工匠头目）作为叙事锚点？
- [ ] 修士死亡后是否有传承机制，还是纯粹损失？
