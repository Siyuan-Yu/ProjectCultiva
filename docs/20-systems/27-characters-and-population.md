## 1. 这个系统解决什么问题

要同时满足两个看似矛盾的需求：每个修士都有独特故事和培养价值；势力规模扩大到数千人时玩家不会被操作量压死。

## 2. 三名初始角色

开局的 3 名角色采用**半固定背景 + 玩家自定义**：每人带有家乡、身世标签、性格标签、天赋倾向与外貌，这些要素会在后续剧情中被真正引用（回故乡、遇旧人、牵出家族关系），同时保留玩家的修改空间。

完整说明见 `20-opening-experience.md` 第三节。三人之间的关系**待设计**。

## 3. 世界模拟四层（已冻结）

完整冻结条文见 `33` §3。本表为展开入口：

| 层 | 对象 | 模拟方式 | 要点 |
|---|---|---|---|
| 第一层 | **当前 PlayerParty／镜头内关键修士** | 完全模拟 | 玩家同一时刻只直接控制一个 Active；其余 Party 成员 AI |
| 第二层 | **关键 NPC** | 完全模拟 | 主管、商人、宗门人物、重要敌人；属性、日程、关系、成长、事件记录 |
| 第三层 | **修士（非玩家焦点）** | **真实 Character + LOD 模拟** | 所有修士都是持久 Character；离屏用 Cold／Strategic 数据模拟，**不是**匿名计数；见 ADR-0024 |
| 第四层 | **普通凡人** | **持久 Character + LOD** | 个体需求、职业、势力、忠诚与位置是真源；人口／劳动力只作派生统计 |

## 3.1 同行、归属与当前所在

- 玩家普通 Party 与 NPC 普通同行 Party 均按最多六人（含队长）设计；这是同行组织上限，不是战场人数上限。
- 真实同行者在遭遇中按现场关系纳入；朋友临时助战只建立本场阵营，不自动加入 Party／Faction，也不给玩家其背包或控制权。
- `HomeSite`、`Faction`、当前物理所在 Site 和玩家控制权相互独立。Site 易主或范围变化不移动人物，也不自动改变忠诚、个人关系、日程或出生点。

## 3.2 生命状态、队内接替与势力继承

- Dead 与 Removed 保持分离；弥留／暂时失能但仍存活也不等于死亡。
- 当前 Active 失能时，按 Party 固定顺序从第二位开始自动选择下一名可控成员；不按战力排队，也不弹选择窗口。
- 当前 Party 无任何可控成员时，从玩家势力中自动选择存活、可担任主控且按现有口径战力最高的外部人物。并列须稳定处理；旧“必须在己方 Site／未出征”限制不再适用。
- 仍有生者时是 Emergency Takeover：旧生者留在原地 Recovery Squad；全员 Dead／Removed 时是 Succession。先结算真实伤亡与消耗，再于接管者自己的实际位置取得控制；不传送、不复活、不自动补队。
- 全员失能但没有外部候选时保留原 PlayerParty 等待恢复。玩家势力无人时的最终结局明确延期。
- Recovery Squad 是玩家势力普通、非主控 Squad：保留旧成员的真实位置、伤势和生命周期，`CommandKind=None`，不自动移动、跟随、治疗、回队或抢回 Active。Dead／Removed 不进入可移动 Recovery Squad，继续使用 corpse／singleton／retired membership。恢复后的旧成员只能通过正常 Party transfer／add／management 重新组织。

正式控制契约见 [2K §4](2K-rpg-first-character-control-playerparty-and-continuous-hex-world.md) 与 [ADR-0034](../40-process/43-decisions/ADR-0034-conflict-control-succession-and-airship-role.md)。

> **2026-09-27 修订（ADR-0044）：** ADR-0024 已确立修士真实个体；CIVILIAN-LIFE-01 继续确立凡人真实个体。二者都保留 Character identity，区别体现在生活方式、能力和 LOD，不再以是否实体化区分。

**势力外交／战争战略**建立在真实 Character／Squad roster 之上；旧 FormalArmy 只允许作为旧输入迁移边界（见 [2A](2A-factions-armies-diplomacy-and-capture.md)）。不得用匿名 `QiRefiningCount` 代表不存在的修士，也不得把离屏修士偷偷做成全员 LocalMap Actor。

凡人获得修炼能力时仍是同一 Character，只增加相应能力组件；不会更换 EntityId。关键 NPC 的职能接替须由真实人物承担，规则仍待后续设计。

## 4. 核心修士（第一层）

- 拥有完整的境界、属性、灵根、功法、技能、装备、关系与经历。
- 可组成若干小队，执行探索、驻守、外交与战争任务。
- 长期约 **30–50 人**指可管理、培养和进入 LOD 的核心修士规模方向；普通同行小队最多六人，且同一时刻只直接控制一个 Active。
- 上限由势力影响力、设施与制度决定，可随发展提升。
- **默认可永久死亡**；不被 `IsStoryImportant` 自动保护。
- **可离开势力**（退出／叛逃／自立等），须有前兆与可解释原因；离开不清空 Relationship。
- 玩家控制权来自 `PlayerAgency`／`ControlAuthority`，不是“核心修士=永远可点选”。

### 招募来源

酒馆结识、任务同行、宗门关系、历练救援、主动邀请、**学校人才候选**、凡人灵根筛选。

## 5. 关键 NPC（第二层）

关键 NPC **实体化**，例如：

- 商人
- 村长
- 铁匠
- 重要人物／剧情人物

可拥有：姓名、性格、关系、任务、库存等。

玩家可以与他们互动：接任务、帮助、交易、结怨、击杀。被杀或离开后，其社会功能可能由其他人接替（接替规则**待确定**）。

隐藏经历（如“砍柴人曾是失败修士”）仍挂在这一层或可转化为修士层，见 `28-jianghu-relations.md`。

## 6. 势力与修士名册

势力层做战略模拟：扩张、外交、战争、资源。

玩家自己的宗门／领地是可操作的势力；世界上的大宗门、妖族、城镇政权等也在这一层运转。正魔大战等宏观事件主要在此层推进，详见 [2A](2A-factions-armies-diplomacy-and-capture.md)、`24-world-and-settlements.md` 与 `28-jianghu-relations.md`。

**炼气 30、筑基 5** 等势力面板数字 = 从真实 Character Roster **统计**，不维护独立的匿名计数器（ADR-0024）。

## 7. 普通凡人（第四层）：真实 Character 与生活 V1

每个凡人拥有稳定 EntityId、位置、生命状态、FactionMembership（或 None）、Satiety、Energy、Profession 与必要历史。人口、职业和劳动力数字可汇总展示，但不得反向拥有、生成、删除或归并人物。

有归属凡人接受所属势力工作；无归属凡人仍进行基本生活，但不接受势力排程。玩家势力凡人进入可管理名册方向，不等于自动加入 PlayerParty 或成为 ActiveCharacter。

V1 专业职业单选为 Unassigned、Farmer、HerbFarmer、Logger、Medic。所有有行动能力的凡人均可执行搬运／救援与建设；Medic 才执行专业治疗。需要优先于普通工作，食物必须来自可访问库存，Energy 极低时允许原地紧急睡眠。

附近人物使用高细节行为，离屏未来可降频；LOD 只能降低模拟成本，不能消除 Character identity。住房继续显示真实人物并使用真实容量。

## 8. 学校与人才系统

凡人不做单人全模拟，但建筑／据点内会生成**少量关键人才**。

### 8.1 学校系统

占领据点并建设／启用学校（或学塾）后：

- 每隔一段时间刷新人才候选，暂定约每 **2～3 个月**游戏时间。
- 生成有潜力的凡人候选。

候选包含：

| 字段 | 作用 |
|---|---|
| 灵根 | 修炼潜力与属性方向 |
| 悟性 | 学习与领悟速度 |
| 神识 | 感知与控制潜力 |
| 性格 | 行为与关系倾向 |
| 天赋 Tag | 额外特长或背景 |

治理质量（时间表、幸福度、资源）应影响候选质量：管理越好，越容易刷出优秀人才。

### 8.2 玩家对候选的两种任命

| 选择 | 要求 | 作用 |
|---|---|---|
| **收为弟子** | 需要修炼潜力 | 进入修士培养线，成为可养成核心／候补修士 |
| **任命管事** | **不需要**修炼天赋 | 负责人口管理、生产、建设等凡人治理 |

管事解决“势力扩大后谁来管凡人日常”的问题，避免所有事务都压在玩家小队上。

### 8.3 与势力成长的关系

```
治理凡人 → 发现人才 → 培养弟子／任命管事 → 增强势力 → 占领更多土地 → 继续发展
```

详见 `26-territory-management.md` 势力成长循环。

刷新频率、每批人数、弟子容量与管事上限**待确定**；避免把凡人人口做成纯抽卡池。

## 9. 凡人军事边界

凡人 V1 主要是居民与劳动者，不建立数百／数千人的 RTS 凡人大军。未来可讨论真实 Character 的 guard／militia duty；大型战争如何摘要结算另行设计，不能以匿名军队倒推删除凡人身份。

## 10. 修士与凡人的力量差距

- 高境界修士与凡人之间应存在**明显的力量差距**。
- 同时通过天道因果体系，限制高阶修士随意屠杀凡人。
- 凡人与修士的关系不是单纯善恶压迫，而是阶层、资源供养与保护交换的结构性结果；详见 `29-karma-and-consequence.md`。

这两条必须同时成立：修士要有压倒性的力量感，但不能变成随意清场。

## 11. 判定标准

- 领地人口增长不应让玩家的逐个操作量等比增长。
- 新招募的每名修士仍要有明确个性与培养价值。
- 玩家走进自己的村庄时，应该感到这里住着人（群体表现 + 关键 NPC），而不是只看到一个人口数字。
- 学校人才应来自治理结果，而不是与治理无关的纯抽卡。
