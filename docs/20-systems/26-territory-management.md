# 领地经营

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`

## 1. 这个系统解决什么问题

领地是修炼的供养来源，也是"从个人成长为势力"的载体。它必须在规模扩大时不增加等比例的微操负担。

**取得第一个据点后才解锁**，之前不显示任何经营界面。

## 2. 玩家在领地里做什么

- 分配凡人人口从事耕种、畜牧、伐木、采矿、练兵、探索、建设与情报。
- 修建洞府、聚灵设施、防御设施、仓储与生产建筑。
- 委任修士坐镇、修行、探索、处理事务或带队出征。
- 与周围村镇、宗门和势力进行外交、贸易、结盟、威慑或战争。
- 在多个据点之间调配人员、物资与核心修士。

## 3. 人口的管理粒度

凡人不是可逐个控制的 RTS 单位，而是**人口组 + 岗位**。例如：

```
荒村（人口 2300）
├── 耕种农田    500
├── 养殖牲畜    200
├── 外出历练    500
├── 操练兵勇   1000
└── 待分配      100
```

修士才是逐个养成和战术控制的角色，详见 `27-characters-and-population.md`。

## 4. 修士驻留的价值

角色留在领地可提升治理效率（例如政务助手让各项产出效率提升），外出则能探索、招募与作战。玩家必须在两者之间取舍时间——这是本系统与 `21-core-loop-and-time.md` 的主要耦合点。

## 5. 未决问题（**影响原型形态**）

- [ ] 建设采用自由空间布局（类修仙模拟器），还是据点建筑槽位 + 政策面板？后者实现成本低得多，建议第一阶段用后者。
- [ ] 灵气是否像修仙模拟器那样有流动与风水，还是简化为据点属性值？
- [ ] 人口是否有满意度／民心，反抗与逃亡如何表现？
- [ ] 岗位调整是否有过渡期，还是即时生效？
- [ ] 多据点时是否需要"总览面板"，避免逐个据点点进去管理？
