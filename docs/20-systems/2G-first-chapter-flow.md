# 第一章流程设计（草案）：从凡人到炼气

> 状态：体验流程草案；开局 Membership 已冻结于 v0.2 | 优先级：P0 | 最后更新：2026-08-01
> 关联：`2F`、`22`、`25`、`29`、`../30-tech/33-architecture-core-rules-freeze-v0.2.md`、`34`
> **荒村杂役阶段叙事框架（非线性）：** 见 [`2I-huangcun-labor-phase-narrative-v0.1.md`](2I-huangcun-labor-phase-narrative-v0.1.md)（Draft）。本页若用语含「第一章」，仅作内部体验弧参考；**游戏内无章节 UI**。

## 1. 第一章核心目标

玩家从没有选择权的底层感应境角色开始，在约 **40 分钟～1 小时**内进入炼气，然后转入隐藏修士阶段。经历：

```
生存压力
→ 发现隐藏修仙世界
→ 获得修炼机会
→ 偷偷积累
→ 获得第一份功法
→ 第一次进入炼气
→ 隐藏修为继续成长
→ 获得改变命运的力量
```

核心主题：

> 从被压迫的凡人，成为隐藏的修士。

凡人阶段不是长期玩法；前期重点不是经营凡人生活。这里的“普通人”指社会身份与处境普通。三名核心角色开局已处于感应境，拥有修仙潜质，但尚非正式修士。

## 2. 开局背景

玩家控制 3 名初始角色。

### 2.1 势力与控制（Freeze v0.2 已冻结）

| 对象 | FactionMembership | FactionRole | ControlAuthority |
|---|---|---|---|
| 三名初始角色 | **当前压迫他们的宗门** | 杂役弟子／劳役弟子 | 玩家**直接控制** |
| 主管 | **同一宗门** | 管理者 | 监督与处罚（非玩家 DirectControl） |

目的：支撑荒村生活 → 秘密修炼 → 隐藏 → 击败主管 → 夺取据点。详见 `33` v0.2 §15、`34`。

### 2.2 人物设定

三人：

- 来自不同凡人城市。
- 拥有不同背景标签。
- 具备修仙潜质。
- 开局处于感应境。
- 不是正式修士，只能感知灵气，不能真正运转灵力或使用修士能力。
- 因家境普通、没有背景，且资质不足以直接成为正式弟子，被送往某个中小型宗门的外围资源区域劳役。

角色采用“半固定背景 + 玩家自定义”，详见 `20-opening-experience.md`。

## 3. 初始地点（暂定）

**青云宗外围资源点**（名称待确定）。

该区域负责：

- 开采资源
- 采集灵材
- 种植灵药
- 维护宗门外围产业

青云宗不是单纯邪恶势力。它保护区域安全、对抗妖兽并提供进入修仙体系的机会；但底层资源体系也使普通凡人与感应境劳役者受到压迫。

玩家面对的是修仙社会结构，不是单纯的坏人，详见 `29-karma-and-consequence.md`。

## 4. 第一阶段：凡人觉醒

目标：约 40 分钟～1 小时内完成第一次炼气。

### 白天

完成宗门安排的任务，例如：

- 收集木材
- 搬运矿石
- 采集资源
- 清理妖兽痕迹

### 晚上

玩家可以：

- 休息
- 探索
- 与 NPC 交流
- 寻找修炼机会与功法

重点体现：

> 玩家不是一开始没有力量，而是没有自由。

配额、时间表、主管愤怒、掩护与藏匿规则见 `2F-obligation-and-concealment.md` 与 `21-core-loop-and-time.md`。

离开辖区风险很高（劳役身份、实力不足、筑基追捕、外界举报），不是不能走，而是默认应隐藏成长。

## 5. 神识体验：看见普通人看不见的世界

普通劳役者只能看到普通世界；三名核心角色因**神识与天赋高于常人**，能够隐约感知：

- 灵气异常与浓度差异
- 隐藏资源和灵物
- 妖气痕迹与特殊环境
- 部分隐藏修士身份或修炼痕迹

体验示例：

> 普通人看到一块普通石头；神识敏锐的角色察觉其中存在微弱灵气。

注意：这层信息优势来自**神识**，不是"感应境"这个境界本身。感应境只代表能感受并基础吸收灵气、可以准备正式修炼。详见 `2B-attributes-and-affinity.md` 与 `22-realms-and-abilities.md`。

设计目标不是一次性弹出“发现修仙世界”，而是让玩家在劳役、交流和探索中逐步理解这些异常。

## 6. NPC 与机缘

前期的重要玩法是通过交流获得机会。NPC 不是任务发布器，而是拥有过去经历、个人目标与隐藏故事的人。

### 示例 NPC：砍柴老人

表面上，他只是普通凡人。

实际上，他年轻时曾是低资质修士，修炼多年也只达到炼气低阶，最终回归凡人生活。

如果玩家发现他的异常、建立关系并帮助他完成愿望，就可能获得第一份功法。

这只是流程样例，人物身份、愿望与奖励均可调整。

## 7. 第一份功法

第一份功法不是固定赠送，存在多种路线：

- NPC 传承
- 秘境探索
- 商人交易
- 宗门获得
- 特殊事件

不同来源提供不同属性方向与功能的功法，影响修炼效率、技能类型与战斗风格。

玩家可以自由选择路线；第一章至少要保证存在一条稳定可发现的主路径，同时允许其他路线作为替代。

## 8. 感应境到炼气的准备

玩家获得功法后仍不能立即进入炼气，需要：

- 感应境阶段的基础积累
- 一份可以尝试运转的功法
- 合适的修炼环境
- 足够且不被打断的时间

玩家因此需要寻找灵气较高的区域，例如**废弃山洞**（地点待确定）。

这个过程要与白天劳役、夜间门禁、怀疑度和同伴掩护形成冲突：突破准备本身就是一次风险决策。

## 9. 环境修炼

修炼地点影响修炼效率和突破结果，不采用复杂摆放系统，主要通过自然环境体现。

### 基础灵气浓度

不同地区不同：凡人城市低，灵山高。

### 属性环境

| 属性 | 环境示例 |
|---|---|
| 水 | 河流、湖泊、瀑布、雨季 |
| 木 | 森林、古树 |
| 火 | 火山、岩浆 |
| 金 | 矿山、金属资源 |
| 土 | 山脉、大地 |
| 雷 | 雷暴天气 |
| 风 | 待确定 |
| 冰 | 待确定 |
| 毒 | 待确定 |

> **待确定：** 最新灵根名单为火、金、土、木、雷、风、冰、毒，不含水。上表「水」沿用早前草稿，是否并入冰见 `2B-attributes-and-affinity.md`。

环境影响：

- 修炼效率
- 突破成功率
- 属性修炼倾向

具体数值不在本章确定，详见 `25-cultivation-and-breakthrough.md`。

## 10. 第一次炼气突破

进入炼气不是简单升级。修为与准备达到要求后，角色只获得突破资格；玩家需要主动选择地点、状态与时机，安排同伴护法，再尝试**引气入体、按照功法正式运转灵气**。

影响因素：

- 灵气环境
- 功法品质与匹配度
- 身体状态
- 心境状态
- 灵根与悟性
- 辅助资源
- 同伴护法与地点安全

可能结果：

- 普通突破
- 完美突破
- 瑕疵突破
- 失败并受到反噬

第一次突破事件的具体流程、事件内容、结果差异与失败后果仍待确定；但结果必须可解释，不能只显示随机成功或失败。通用规则见 `25-cultivation-and-breakthrough.md`。

## 11. 炼气后的第一次变化

进入炼气后，角色获得：

- 灵气池
- 灵力恢复能力
- 基础灵气防御
- 学习、运行功法与使用基础灵力技能的资格

战斗中优先消耗灵气；灵气耗尽后，普通生命伤害才会直接作用于角色。

这一变化不代表炼气拥有压倒性战力。它的核心体验是：

> 我已经不再只是看见修仙世界，而是真正进入了它。

## 11.1 隐藏修士阶段

进入炼气后**不能立刻公开身份**。主管是筑基期，暴露会被轻易抓捕。

玩家需要：

- 使用敛息资源（如敛息草）短时间隐藏修为气息
- 三人分工：修炼／采集隐藏资源／探索情报
- 继续完成明面劳役，隐藏成长

离开辖区风险很高，不是绝对禁止。详见 `2F-obligation-and-concealment.md`。

## 12. 第一场修仙战斗

突破后，附近出现普通凡人难以处理的低级妖兽。

玩家使用：

- 灵气强化
- 基础灵力技能
- 初级斗技

第一次体验修士与凡人的区别，同时学习灵气池、灵气防御与技能消耗。

这不是第一次 Boss 战。妖兽种类、战场位置、是否有凡人需要保护以及具体教学顺序均待设计。

## 13. 第一章后续方向（暂定）

玩家逐渐发现当前资源点管理者存在问题。

管理者不是纯粹恶人，而是受到宗门体系、资源指标与自身利益共同驱动。

玩家未来可能：

- 加入体系
- 改善制度
- 挑战管理者
- 建立自己的势力

第一阶段长期目标仍是：获得第一块属于自己的领地。

## 14. 节奏骨架

| 段落 | 主要体验 | 玩家获得的认知／能力 |
|---|---|---|
| 劳役入场 | 无选择权、生存压力、三人分工 | 时间与资源不属于自己 |
| 感应探索 | 在普通环境中发现异常 | 世界存在隐藏的信息层 |
| NPC 机缘 | 交流、观察、建立关系 | 人不是任务牌，关系能带来修炼机会 |
| 功法路线 | 在多种获取路径间选择 | 功法决定成长方向 |
| 秘密准备 | 找环境、挤时间、承担暴露风险 | 修炼需要条件，不是点按钮 |
| 首次突破 | 约 40 分～1 小时内进入炼气 | 从感知灵气到使用灵气 |
| 隐藏修士 | 敛息、分工、继续藏修 | 炼气也不能立刻公开 |
| 修仙战斗 | 灵气池、基础技能、灵气防御 | 自己第一次拥有改变命运的力量 |
| 权力伏笔 | 看见管理者与制度问题 | 未来可以加入、改变或挑战体系 |
