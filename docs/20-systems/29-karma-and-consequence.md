# 世界观哲学：天道、因果与修仙社会结构

> 状态：设计方向已定，数值与细则未展开 | 优先级：P1 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`27-characters-and-population.md`、`28-jianghu-relations.md`、`25-cultivation-and-breakthrough.md`、`26-territory-management.md`
> 当前只记录设计方向，**不进入具体数值与平衡设计**。

## 1. 这个系统解决什么问题

修仙世界如果只做成"正道善良、魔道邪恶"，玩家面对的所有冲突都会退化成打坏人。本作需要一套伦理与因果框架，让力量、资源、寿命与阶层压迫成为世界运行的真实逻辑，也让玩家在变强之后面对一个真正的长期主题：

**当一个曾经被压迫的人获得力量后，他会改变体系，还是成为新的体系维护者？**

这套体系同时承担玩法约束：高境界不能毫无代价地滥用力量。

## 2. 修仙世界不是简单善恶世界

这个世界**不是**：

- 正道 = 绝对正义
- 魔道 = 绝对邪恶

而是一个围绕以下要素运转的复杂体系：

| 核心要素 | 为什么重要 |
|---|---|
| 修炼资源 | 灵石、灵药、法宝材料、粮食，决定谁能持续修炼 |
| 寿命 | 境界不够则寿尽；争抢资源往往是为了活得更久 |
| 境界突破机会 | 功法、洞天、指点与突破窗口，是阶层跃迁的关键门槛 |
| 灵气分布 | 不同地区灵气浓度与属性环境不同，决定哪里值得驻扎与争夺 |
| 社会阶层 | 凡人、感应境潜质者、正式修士、宗门势力形成天然分层 |

不同势力拥有不同理念和选择。正魔标签更多是立场、手段与资源观的分野，而不是道德评分板上的黑白两端。

## 3. 修仙社会结构

### 3.1 凡人

- 数量最多。
- 负责生产与社会运行。
- 大多数无法修炼，也看不见灵气。

### 3.2 拥有灵根、进入修仙体系的人

- 获得更高资源。
- 拥有更长寿命。
- 掌握更强力量。

其中，开局三名核心角色属于**感应境**：已有修仙潜质，但尚非正式修士；真正进入体系的标志是炼气（见 `22-realms-and-abilities.md`）。

### 3.3 宗门

宗门需要凡人社会提供资源，同时保护凡人免受妖兽、其他势力侵害。

因此宗门与凡人的关系**不是简单的善恶关系**，而是资源交换与阶层关系：

| 宗门提供 | 凡人提供 |
|---|---|
| 保护一方免受妖兽与外部势力侵扰 | 资源、劳役、粮草与基础生产 |
| 维持区域秩序 | 人口与组织基础 |

宗门对凡人的压迫并不一定完全来自恶意，而常常是整个修仙资源体系导致的结构性结果。宗门**不要**做成脸谱化反派：它可能压迫底层，同时也保护一方、维持秩序并对抗外部威胁。普通弟子也可能只是执行体系规则。

详细人口与力量差距见 `27-characters-and-population.md`。

## 4. 主角的核心矛盾

### 4.1 开局

主角是修仙体系底层：

- 被迫接受资源生产体系（外门劳役）
- 希望摆脱自己的命运
- 对压迫有切身感受

### 4.2 成长之后

主角建立自己的宗门，拥有：

- 弟子
- 领地
- 凡人居民
- 资源需求

最终也会成为体系的一部分：要养活修士、要收贡赋、要在秩序与压榨之间做选择。

### 4.3 游戏核心问题

> 当一个曾经被压迫的人获得力量后，他会改变体系，还是成为新的体系维护者？

这是长期成长的重要主题。前期劳役、配额与隐匿体验要为后期留下可回望的对照：玩家曾经痛恨的结构，日后可能亲手重建。

## 5. 因果、功德与业障

**不要**设计成简单善恶值。行为需要结合背景判断。

### 5.1 通常不会产生明显负面影响

- 战争中击杀敌对修士
- 保护领地击杀妖兽
- 对抗邪修

这些行为可能仍有江湖关系后果（仇家报复、势力记恨），但不一定形成严重业障。

### 5.2 会产生明显负面后果

- 为资源屠杀无辜凡人
- 杀害已经投降的人
- 随意毁灭弱小势力

可能产生：

- 业障
- 道心影响
- 气运下降
- 突破困难
- 渡劫风险增加

判定原则：**看对象、看情境、看动机与手段，不做固定扣分表。**

## 6. 高阶修士限制

高境界修士拥有巨大力量，但不能随意使用。

**境界越高，力量越强，同时因果影响越大。**

例如：元婴、化神修士理论上可以轻易毁灭大量凡人，但这样做会影响自身未来修行——道心、气运、突破与渡劫都会承压。

一句话概括：**力量越强，限制越多。** 天道允许强者存在，但不允许强者把世界当成没有代价的猎场。

## 7. 后续可扩展的影响面

当前只记录方向，本阶段不做数值与平衡：

| 方向 | 说明 |
|---|---|
| 功德 / 业障 | 行为长期积累的两面状态，细则待定 |
| 道心 | 信念稳定程度，影响心魔与突破 |
| 心魔 | 滥用力量或执念过重时的内在反噬 |
| 突破成功率 | 业障与道心损伤会压低突破质量或成功率 |
| 渡劫难度 | 高境界滥用力量后，天劫可能更重 |
| 宗门理念 | 玩家宗门的治理取向与对外标签 |
| NPC 评价 | 旁人对玩家手段与统治方式的观感 |
| 江湖关系 | 仇怨、恩义、信誉与可被利用的人情 |
| 正魔选择 | 立场与手段分野，不是绝对善恶开关 |

## 8. 与其他系统的接口

- 输入：战斗结果、领地政策、对待凡人的手段、对投降者与弱小势力的处置。
- 输出到：`25` 突破与渡劫、`28` 江湖关系与 NPC 评价、`26` 领地与宗门治理、`27` 凡人处境、未来的势力与正魔选择。
- 前期验证点：玩家在劳役阶段感受到的压迫，应能在后期经营中被玩家自己复现或拒绝复现。

## 9. 未决问题

- [x] 世界不是正善魔恶的简单二分，而是围绕资源、寿命、突破机会、灵气分布与阶层形成的复杂社会。
- [x] 力量越强，因果限制越多；影响道心、气运、突破、渡劫与修行道路。
- [x] 杀戮按情境判定，不做简单善恶值。
- [x] 凡人与修士／宗门存在阶层与利益交换；宗门不做脸谱化反派。
- [x] 玩家长期主题：改变体系，还是成为新的体系维护者。
- [ ] 功德与业障是单一轴，还是多维度？（杀凡人／杀同阶／背信／护民等）
- [ ] 玩家能否直接看到因果数值，还是主要通过世界反应、道心异动与渡劫反馈间接感知？
- [ ] 是否存在可行的"魔道／极端效率"路线：高业障换取短期优势，但长期代价更重？
- [ ] 行善、护民、赎罪能否削减业障？（数值阶段再定）
- [ ] 正魔大战中的"正／魔"如何与本伦理体系对齐，避免叙事又退回绝对善恶。
