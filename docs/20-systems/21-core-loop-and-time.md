# 核心循环与统一时间

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> **这是下一份要优先完善的文档。** 其他系统都挂在它定义的时间轴上。

## 1. 这个系统解决什么问题

角色行动、修炼、领地生产、事件推进和战斗必须共用**同一条时间轴**，否则会出现"战斗时领地停摆""修炼与探索各算一套时间"这类结构性矛盾。这个系统定义"一天怎么过"。

## 2. 三层循环

### 分钟级：角色行动

```
暂停规划 → 分配角色行动 → 恢复时间流逝
→ 探索 / 对话 / 采集 / 修炼 / 战斗
→ 获得资源、情报、关系或伤势 → 再次规划
```

### 小时级：修炼与扩张

```
完成任务与经营产出 → 获得修炼时间、功法和资源
→ 准备突破或强化小队 → 挑战据点守护者或完成外交夺取
→ 获得新领地与更优修炼条件
```

### 长期：个人能力与势力规模互相供养

```
领地供养修士 → 修士突破获得新机制能力
→ 新能力允许探索、战斗或统治更高层级区域
→ 占领更高价值领地 → 支撑更多修士与更高质量突破
```

## 3. 循环必须成立的三个约束

- **不修炼**：打不过更强守护者，也无法进入危险区域。
- **不扩张**：缺乏灵地、资源和人口，修炼质量与势力上限受限。
- **只堆人口**：凡人无法替代高阶修士，但可支撑经济、防务与低阶战争。

## 4. 时间模型的当前设想

- 时间持续流逝，玩家可**随时暂停**下达指令，也可倍速跳过无事阶段。
- 逻辑层只认 Tick（例如 1 Tick = 一个时辰），不认真实秒数。
- 角色行动、领地生产、修炼进度、事件判定都由同一个 Tick 驱动。
- 角色不在领地时，领地按已分配的岗位与政策自动运转，产出照常结算。
