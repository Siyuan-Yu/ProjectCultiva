# 功法系统设计（规则层）

> 状态：核心规则已定方向，数值与具体功法内容未展开 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`2B-attributes-and-affinity.md`、`2D-manuals-arts-and-equipment.md`、`25-cultivation-and-breakthrough.md`、`22-realms-and-abilities.md`
> 本章只确定功法作为修仙成长核心系统的规则，**不设计具体功法、具体倍率或数值平衡**。

## 1. 这个系统解决什么问题

功法决定角色如何积累修为、形成怎样的灵力，以及长期沿哪条道路成长。它是修仙成长的核心，不是职业选择、装备附属品或简单技能列表。

## 2. 功法定位

### 2.1 功法不是职业限制

角色原则上可以学习任何功法，不因职业、流派或灵根属性被永久禁止。

同一部功法由不同角色学习时，效率与最终发挥会不同，主要受以下因素影响：

- 灵根适配程度
- 悟性
- 神识（仅对部分需要复杂感知或精神控制的特殊功法）
- 功法自身品阶与完整程度

### 2.2 “可以学习”不等于“可以完整发挥”

功法可以设置客观学习条件，例如境界、身体状态、前置知识或特殊传承要求；这些条件不是职业锁，也不是灵根禁学。

低境界角色可以提前获得甚至尝试学习高阶功法，但可能因为灵力容量、境界或控制能力不足，只能发挥部分效果，强行运转还可能产生反噬。具体门槛与风险待确定。

### 2.3 灵根只影响效率

灵根不限制功法学习，只影响：

- 学习与掌握速度
- 修炼效率
- 对应属性力量的发挥

角色可以跨属性学习功法，只是通常需要更多时间，且最终效果可能较低。

## 3. 功法品阶

暂定四个品阶：

| 品阶 | 定位 |
|---|---|
| 黄阶 | 入门 |
| 玄阶 | 进阶 |
| 地阶 | 高阶 |
| 天阶 | 顶尖 |

品阶代表功法的**完整程度与成长潜力**，影响：

- 修为获取效率
- 灵力恢复速度
- 最大灵力
- 灵力质量
- 战斗续航能力
- 长期成长上限

品阶不是单纯的即时数值差。高阶功法的价值可以随境界提高而逐渐放大。

## 4. 功法如何影响修为

**修为是长期成长资源**，用于境界提升与突破。

在相同环境和相同修炼时间下，不同功法获得的修为不同。

规则方向：

- 玄阶功法在低境界阶段可提供较稳定的修为积累。
- 天阶功法在前期的优势可以有限，不要求从炼气起就形成悬殊差距。
- 随境界提高、突破所需修为大量增加，高阶功法的长期优势会越来越明显。

设计目标是让高阶功法体现更好的成长曲线，而不是让低阶角色仅凭一本天阶功法立刻产生不合理的战力跃迁。

具体曲线、倍率与各境界差距不在本阶段确定。

## 5. 功法如何影响灵力

**灵力是可消耗、可恢复的战斗资源**，用于：

- 释放技能
- 灵力护体
- 使用法宝
- 发动特殊能力

修为与灵力是两个独立系统：修为决定长期成长，灵力决定当前战斗与行动续航。

功法可以影响：

- 最大灵力
- 灵力恢复速度
- 灵力质量

例如同为筑基期：

- 修炼玄阶功法者，灵力恢复速度可能较低。
- 修炼天阶功法者，灵力恢复速度可能更高。

这只是规则形态示例，不锁定具体差距。

### 5.1 灵力质量

“灵力质量”暂定表示同等数量灵力的凝练程度与实际效能，可影响护体、技能、法宝驱动与续航。

它与最大灵力、恢复速度不是同一个指标。具体表现、是否需要独立显示，以及如何避免形成难以理解的重复数值，均待确定。

## 6. 功法成长与更换

### 6.1 大部分功法不可升级品阶

大部分功法自身不会从黄阶升级为玄阶、地阶或天阶。

角色的常规成长路径是：

- 炼气阶段使用基础功法。
- 筑基后寻找更适合或更高阶的功法。
- 金丹及以后继续寻找更完整、更契合自身道路的功法。

因此，获得、选择与更换功法本身就是长期成长内容。

### 6.2 掌握程度不等于功法升级

角色可以提高某部功法的掌握程度，但这不会改变功法本身的品阶。

例如，一部黄阶功法可以被练到圆满，但仍然是黄阶功法；角色只是把它现有的内容发挥得更完整。

### 6.3 少数特殊成长功法

少数特殊机缘功法可以通过特定条件成长、补全或提高品阶，例如类似《焚诀》的成长路线。

这类功法必须严格控制数量，作为稀有机缘与特殊成长线，不能成为所有功法的通用升级模式。

具体成长条件、数量与上限待确定。

## 7. 功法与技能／斗技的关系

- 功法决定：**如何修炼**。
- 技能／斗技决定：**如何战斗**。

功法不是简单的技能列表，但可以影响技能的学习、消耗、威力、变化方向或使用方式。

同一个技能，在不同功法、灵根、神识与掌握程度组合下，可以产生不同效果。具体组合规则由战斗与技能系统后续展开。

“技能／斗技／神通”的最终统一用词仍待确定。

## 8. 功法规则字段

以下字段只记录未来需要表达的规则信息，不代表已经进入数据库或技术实现：

| 字段 | 含义 |
|---|---|
| 名称 | 功法名称 |
| 品阶 | 黄／玄／地／天 |
| 属性倾向 | 功法偏向的天地能量；影响适配效率，不构成学习限制 |
| 境界阶段效率 | 功法在不同境界阶段的修炼表现 |
| 修为获取倍率 | 对修为积累速度的影响 |
| 最大灵力 | 对灵力容量的影响 |
| 灵力恢复速度 | 对灵力恢复的影响 |
| 灵力质量 | 对灵力凝练程度与效能的影响 |
| 特殊效果 | 不属于通用字段的独特规则 |
| 学习条件 | 境界、身体、前置知识、传承等客观条件；不能写成职业或灵根禁学 |
| 来源 | NPC 传承、宗门、秘境、商人、事件等 |
| 是否特殊成长 | 是否属于少数可成长、补全或升阶的特殊功法 |

字段名称仅用于策划层表达，最终数据结构与技术命名不在本阶段确定。

## 9. 与其他系统的关系

| 系统 | 关系 |
|---|---|
| 角色属性 | 灵根影响适配，悟性影响学习，部分特殊功法受神识影响 |
| 修炼与突破 | 功法影响修为积累、灵力系统、成长上限与突破准备 |
| 境界 | 境界影响功法能发挥到何种程度，但不构成职业锁 |
| 技能／斗技 | 功法决定修炼道路，并影响技能学习与实际表现 |
| 江湖与探索 | 功法来源本身是传承、关系、交易与机缘内容 |

## 10. 已确认规则

- [x] 功法是修仙成长核心，不是职业限制。
- [x] 角色原则上可以学习任何功法；灵根只影响效率，不构成禁学。
- [x] 不采用属性克制体系。
- [x] 功法品阶暂定黄、玄、地、天，代表完整程度与成长潜力。
- [x] 修为与灵力分离：修为用于成长，灵力用于战斗与能力消耗。

- [x] 大部分功法不可升级品阶，角色通过寻找和更换功法成长。
