> 上级：`docs/00-project/00-overview.md`

## 1. 这个系统解决什么问题

要做出"修炼需要挑地方、挑准备、挑功法"的修行真实感，而不是经验条满了点一下按钮。灵地、属性环境、功法与因果都应对修炼结果产生可读影响。

**明确不做：** 《了不起的修仙模拟器》式复杂建筑摆放与无限叠放灵物玩法。环境以自然地理与少量灵物／阵法表达。

## 2. 前期是生存，后期才是养成

- 前期存在食物、伤病、安全、住所与时间压力，先是生存，再谈修仙。
- 中期开始有稳定修炼条件与多角色培养。
- 后期才是完整的多角色养成与势力经营。

## 3. 开局状态与入门：感应境 → 炼气

三名核心角色开局默认处于感应境，不需要在游戏过程中触发。世界中的大多数普通人仍是真正凡人。

| 阶段 | 角色能做什么 | 关键限制 |
|---|---|---|
| 普通凡人 | 只能靠食物、药物与休息 | 感受不到天地灵气 |
| **感应境** | 感受天地灵气、进行基础吸收、进入正式修炼准备阶段 | 不能学正式功法；不能真正运转灵力；不能使用修士能力 |
| **炼气** | 正式进入修仙体系：灵气池、学功法、基础灵力技能 | 仍是低阶，大权限留给后续境界 |

**感应境：能够感知灵气。炼气：能够使用灵气。** 区别主要是从"看见修仙世界"到"真正进入修仙世界"。炼气不是巨大能力跃迁。详见 `22-realms-and-abilities.md`。

**注意：** 发现灵物、妖气痕迹、隐藏修士等隐藏信息的能力**不属于感应境**，而来自神识、天赋与经历（见 `2B-attributes-and-affinity.md`）。感应境只是修炼的起点，不是特殊视觉。

## 4. 第一份功法

第一份功法**不是固定赠送**。玩家可通过多种路线获得，例如：

- NPC 传承
- 秘境探索
- 宗门获得
- 商人交易
- 特殊事件

不同来源获得的功法不同。不同功法影响：属性方向、修为获取效率、最大灵力、灵力恢复、灵力质量、技能表现与长期成长上限。

功法规则见 `2H-manual-system-rules.md`；功法与斗技、装备的边界见 `2D-manuals-arts-and-equipment.md`。

灵根不限制功法学习，只影响效率；功法也不是职业限制。大部分功法不可升级品阶，角色会随境界成长寻找和更换更适合的功法；少数特殊机缘功法可以成长。

### 4.1 第一次进入炼气的流程方向

获得功法后仍不能立即进入炼气。至少需要：

- 感应境阶段的基础积累
- 一份可以尝试运转的功法
- 合适的修炼环境
- 足够且不被打断的时间

玩家准备环境后，进行**引气入体、按照功法正式运转灵气**。影响因素包括灵气环境、功法品质与匹配度、身体状态、灵根与悟性和辅助资源。

修为与准备达标后，角色只获得突破资格；玩家需要主动选择时机并开始突破。结果沿用统一四类：

- 普通突破
- 完美突破
- 瑕疵突破
- 失败并受到反噬

第一次炼气的具体事件、判定与后果仍待设计，但结果必须可解释。体验草案见 `2G-first-chapter-flow.md`。

## 5. 灵气环境

修炼环境影响突破与修炼效率。采用**自然环境**，不做复杂摆放。

### 5.1 基础灵气浓度

不同地区不同。例如：凡人城市灵气低，灵山灵气高；荒村低，灵泉高。具体数值**待确定**。

据点被占领后，其灵气可作为领地资源；玩家可将多据点灵气汇聚到主洞府，以提升主修炼点浓度。详见 `26-territory-management.md`。这是占领地盘的核心动力之一，不是单纯扩图。

### 5.2 属性环境

属性与 `2B` 一致，是能力倾向，不是相克表。环境示例：

| 属性 | 自然环境示例 |
|---|---|
| 水 | 河流、湖泊、瀑布、雨季 |
| 木 | 森林、古树 |
| 火 | 火山、岩浆 |
| 金 | 矿山、金属资源 |
| 土 | 山脉、大地 |
| 雷 | 雷暴天气 |
| 风 | **待设计**（如峡谷、高空、季风地带） |
| 冰 | **待设计**（如雪山、极寒之地） |
| 毒 | **待设计**（如瘴气沼泽） |

> **待确定：** 最新灵根名单为火、金、土、木、雷、风、冰、毒，不含水。上表「水」沿用早前草稿，是否并入冰见 `2B-attributes-and-affinity.md`。

环境影响：

- 对应属性修炼效率
- 突破成功率
- 灵气恢复速度

幅度**待确定**。

## 6. 灵物与阵法

### 6.1 灵物

可以提高某区域灵气或属性倾向。

约束：

- 同类灵物**不要无限叠加**
- **不设计疯狂摆放玩法**

### 6.2 阵法

阵法作为独立高级系统，由阵法师掌握。例如聚灵阵。

主要用于宗门阶段建设，不是开局核心。细则**待设计**。

## 7. 突破基本原则

突破不是“达到经验值后自动升级”。

角色修为达到当前阶段要求后，只获得**突破资格**。玩家必须主动选择突破，并为此寻找合适地点、调整角色状态、选择时机，然后进入突破事件。

基础流程：

```
修为达到要求
  → 获得突破资格
  → 玩家选择地点、状态与时机
  → 安排护法与资源（大境界更重要）
  → 主动开始突破
  → 处理突破事件
  → 结算突破结果与世界反馈
```

突破期间角色无法正常行动。突破是角色改变修行阶段乃至生命层次的过程，不是普通升级按钮。

## 8. 小境界突破

例如：炼气一层 → 炼气二层。

小境界突破属于小幅提升，流程复杂度低于大境界，但仍需玩家主动开始。

### 8.1 基础条件

| 类别 | 影响因素 |
|---|---|
| 地点 | 需要一定灵气；普通地点可以尝试，高灵气地点提高成功率或突破质量 |
| 状态 | 当前伤势、肉身状态、灵力状态、心境状态 |
| 环境 | 天气、时间、季节、属性环境 |

### 8.2 风险

小境界突破风险较低，失败不会造成巨大惩罚。可能结果包括：

- 突破耗时增加
- 短暂修为停滞
- 肉身、灵力或心境状态下降

具体持续时间与数值**待确定**。

## 9. 大境界突破

例如：感应境 → 炼气、炼气 → 筑基，以及后续跨越大境界的突破。

> **境界顺序说明：** 本作仍沿用感应境、炼气、筑基、结晶、金丹、具灵、元婴、化神、悟道、羽化、登仙。讨论中“筑基 → 金丹”“金丹 → 元婴”只用于说明大境界突破的机制感，不表示删除结晶与具灵。

大境界突破代表生命层次与玩法权限变化，需要更复杂的准备。

### 9.1 主要输入

| 类别 | 因素 |
|---|---|
| 灵气环境 | 灵气浓度、灵脉、灵泉、特殊地形、属性环境 |
| 身体状态 | 肉身强度、伤势、经脉状态、寿命 |
| 修炼基础 | 修为、灵根、悟性、神识、功法匹配度与掌握程度 |
| 心境与因果 | 经历、杀戮、道心、性格、心魔、业障 |
| 时间 | 时辰、季节、天象 |
| 资源 | 丹药、天材地宝、特殊材料、灵物、阵法 |
| 人际与势力 | 护法者、师父指点、宗门设施、势力关系 |

准备越充分，成功率、突破质量与长期根基越好。各因素权重**待确定**。

## 10. 突破事件

突破不是单纯等待计时结束。过程中可能出现事件，例如：

- 灵气不足
- 心魔侵扰
- 妖兽靠近
- 敌人发现并干扰
- 特殊机缘

事件需要玩家或护法者处理。不同境界应拥有不同事件池；不能让所有突破只是同一组随机弹窗换数值。

事件是否允许暂停突破、改换策略或消耗额外资源，**待确定**。

## 11. 突破结果

结果不是简单成功／失败：

| 结果 | 含义 |
|---|---|
| 普通突破 | 正常进入新阶段／境界 |
| 完美突破 | 条件极佳，获得额外优势或更稳固根基 |
| 瑕疵突破 | 突破成功，但留下隐患 |
| 失败 | 未进入新阶段，并承受相应后果 |

失败或瑕疵可能造成：

- 修为下降
- 身体／经脉受损
- 心境受影响或留下心魔
- 形成后续突破障碍
- 在高境界付出寿命、因果等代价

结果还应记录：

- 是否获得新境界的机制能力，或能力分支
- 根基质量与对未来上限的影响
- 伤势、隐患、心魔、寿命损失或因果
- 对下一次突破条件的影响

“完美突破”的额外优势不能膨胀为强迫玩家反复读档的唯一正确答案；其具体价值与是否可补救，**待确定**。

## 12. 突破异象

突破会引发天地反馈，强度随境界提高。

### 12.1 小境界异象

- 灵气波动
- 周围环境轻微变化
- 附近修士可能感知

### 12.2 大境界异象

- 天地灵气聚集
- 天象变化
- 雷云
- 妖兽靠近
- 敌人或其他势力察觉

异象不仅是视觉表现，还会产生情报、危险与关系后果。异象范围、是否可隐藏或伪装，**待确定**。

## 13. 护法系统

突破期间角色无法正常行动，需要外部保护。

### 13.1 同伴护法

开局三人中，一人突破时，其他人可以：

- 放哨
- 防御
- 引开敌人
- 处理突发事件
- 补充资源或维持环境

这与前期“一人修炼、两人掩护”的核心体验直接衔接。

### 13.2 宗门护法

加入势力后，可获得：

- 护法弟子
- 安全洞府
- 突破资源
- 阵法与师长指点

这些是加入宗门／依附势力的实际价值，但也可能伴随义务、人情与控制。

### 13.3 地点保护

不同地点危险程度不同。秘密山洞可能隐蔽但灵气有限，宗门洞府安全且资源充足，但突破会被宗门知晓。

## 14. 宗门关系影响突破

突破异象与资源需求可能暴露玩家。势力关系会改变事件：

| 关系 | 可能行为 |
|---|---|
| 友好势力 | 提供保护、洞府、资源或情报 |
| 中立势力 | 观察、交易、索取人情 |
| 敌对势力 | 干扰、偷袭、抢夺突破资源 |

是否帮助不只由“友好度”决定，还应受人物关系、利益、宗门理念与当前战争状态影响；详见 `28-jianghu-relations.md`。

## 15. 渡劫系统方向

渡劫不是所有突破都有。

- 低境界：没有天劫，或只有较弱的天地反馈。
- 随境界提高：逐渐出现雷劫等天地考验。

渡劫开始出现的具体境界、劫难种类、是否受业障／功德／道心影响，均**待确定**。

## 16. 修炼时间尺度（体验目标）

本节给出**游玩节奏目标**，不是最终平衡表。数值阶段可整体缩放，但方向应保持“低境界差距较小，高境界差距扩大”。

### 16.1 总目标

玩家从开局到**元婴**：约 **60–100 小时**真实游玩时间（含探索、劳役、经营与战斗，不只是挂机修炼）。

### 16.2 基准样本（暂定）

以**正常资质**为基准：

- 灵根约 **15–20**（满分 30）
- 使用**黄阶高级**功法

在此条件下：**炼气 → 筑基**约 **100 游戏天**。

### 16.3 功法品阶对修炼速度的影响（方向）

同一境界、相近资质下，功法品阶主要拉开修炼速度。以“炼气到筑基”为示意：

| 功法 | 示意用时（炼气→筑基） |
|---|---|
| 黄阶高级 | 约 100 游戏天 |
| 玄阶 | 约 70 游戏天 |
| 地阶 | 约 20 游戏天 |

说明：

- **低境界差距较小**；进入更高境界后，高阶功法优势应**明显扩大**（与 `2H-manual-system-rules.md` 一致）。
- 天阶与特殊成长功法的具体倍率**待确定**。
- 灵根、悟性、环境、灵气汇聚、辅助资源都会修正实际用时；上表只表达功法品阶这一轴。

### 16.4 与真实时间的关系

游戏天与真实小时的换算依赖时间流速（暂停／2x／5x 等，见 `21-core-loop-and-time.md`）。60–100 小时是**玩家体验目标**，需在数值阶段与 Tick、日程压迫一起校准。
