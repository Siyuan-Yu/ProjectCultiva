# 修炼与突破

> 状态：草稿 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`

## 1. 这个系统解决什么问题

要做出《了不起的修仙模拟器》那种"结一枚金丹真的需要挑时间、挑地方、挑准备"的修行真实感，而不是经验条满了点一下按钮。这个系统同时也是让灵地、洞府、资源点具备战略价值的原因。

## 2. 前期是生存，后期才是养成

- 前期存在食物、伤病、安全、住所与时间压力，先是生存，再谈修仙。
- 中期开始有稳定修炼条件与多角色培养。
- 后期才是完整的多角色养成与势力经营。

## 3. 突破的输入

重大突破至少考虑以下若干项：

| 类别 | 因素 |
|---|---|
| 角色 | 灵根、资质、功法匹配度、心境、伤势、寿命 |
| 时间 | 时辰、季节、天象 |
| 地点 | 灵气浓度、五行属性、风水、是否安全 |
| 物资 | 丹药、法器、阵法、灵材 |
| 人际 | 护法者、师父指点、宗门设施 |

准备越充分，突破质量与后续潜力越好。

## 4. 突破的输出

结果不能只有"成功／失败"，而应包含：

- 是否进入新境界。
- 境界品质或根基质量（影响长期上限）。
- 获得哪一种机制能力，或该能力的哪个分支。
- 留下的伤势、心魔、寿命损失或因果。
- 对未来上限与下一次突破条件的影响。

## 5. 与其他系统的接口

- 依赖：`22-realms-and-abilities.md`（能力解锁）、`26-territory-management.md`（灵地与设施）、`21-core-loop-and-time.md`（修炼占用时间）。
- 影响：战斗能力、跑图权限、世界对角色的态度。
