# 开局体验

> 状态：主线已确定，细节待定 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`2F-obligation-and-concealment.md`（前期主玩法）、`21-core-loop-and-time.md`（一天怎么过）

## 1. 这个系统解决什么问题

开局要在最短时间内让玩家理解三件事：我是谁、我为什么必须变强、变强之后世界会怎样重新对待我。它同时是第一阶段原型的验证载体——能把这条线连续玩通，第一阶段就算成立。

## 2. 定调：先给枷锁，再给钥匙

前期不是"新手教程"，而是一段有明确压迫感的处境。玩家一开始就该感到时间和资源都不属于自己，然后亲手一点点偷回来。

三名角色出身同一荒村，因战乱、灾荒或被强征而沦为某处的劳役者。管理他们的是一名代理修士及其手下的监工。角色此时没有修为、没有居所、没有自由，每天要完成配额才有饭吃。

**官发的口粮只能让人活着，对修炼毫无益处。** 这一条从第一天就要让玩家明白，因为它是整个前期驱动力的来源。

## 3. 四个阶段

### 阶段一：配额之下（约游戏内 1–5 天）

- 玩家控制一至三名凡人，三人战斗定位互补（承伤 / 远程 / 辅助）。
- 每天清晨领取配额（采伐、剿妖、打造之类），黄昏验收，完成才有口粮。
- 三人可分头行动，玩家开始体会"能力越强，省下的时间越多"。
- 此时**不显示任何领地管理界面**，玩家只能移动、对话、采集、制作、战斗。
- 本阶段的教学目标：指令怎么下、时间怎么流逝、提前完工能换来什么。

### 阶段二：偷来的时间（约游戏内 5–20 天）

转折点是某次外出时**发现一处秘密灵地**，那里灵气浓度远高于营地，秘密修炼第一次变得划算。

玩家开始经营明暗两条线：

- 白天照常完成配额，维持表面正常。
- 夜间或利用提前完工的空档，潜出去修炼、狩猎、采药、炼制。
- 私藏的食物和药材必须藏好，被搜出就会没收。
- 一人修炼时，另两人可以承担掩护，把靠近的守卫引开。
- 打听到守卫的偏好后可以行贿，换取夜间放行或验收放水。

怀疑度在这一阶段成为玩家最关心的数值。完整规则见 `2F-obligation-and-concealment.md`。

阶段成果：三人中至少一人踏入练气，获得第一个改变实际操作的能力。

### 阶段三：掀桌（第一次权力转移）

积累到一定程度后，矛盾必须爆发。触发方式有两类：

- **主动**：玩家掌握了代理修士压榨村民或背叛宗门的把柄，凭借新获得的实力与人脉将其击败或取代。
- **被动**：暗面行动暴露，被清算或驱逐，被迫提前摊牌或流亡。

无论哪条路，结果都是玩家取得第一处破旧村庄或小型洞府的控制权，**首次解锁人口分配、建设与领地资源界面**。

### 阶段四：第一轮完整闭环

- 分配凡人恢复农业与基础生产。
- 一名角色留守修炼或辅助治理，其余外出探索、招募、获取资源。
- 用领地产出准备第一次重要突破。
- 通过突破获得明确改变玩法的机制能力。
- 用这个新能力击败或绕过此前无法处理的威胁，夺取第二个据点。

到这里玩家完整体验了一遍"领地供养修炼、修炼推动扩张"的双向闭环。

## 4. 前后呼应

前期的每一样东西，后期都有对应物。这不是丢掉不用的开场关卡。

| 前期 | 后期 |
|---|---|
| 监工的每日配额 | 宗门贡献指标、对上级势力的岁贡 |
| 偷偷修炼与私藏 | 秘密洞府、暗中扩军、隐藏实力 |
| 贿赂守卫 | 收买敌方要员、外交交易 |
| 藏匿点 | 暗桩与秘密据点 |
| 三人分工掩护 | 多小队协同、佯攻与调虎离山 |

玩家在开局学会的心智模型，后期直接复用。

## 5. 设计要求

- 阶段三之前不要暴露完整经营 UI，避免开局信息过载。
- 阶段四必须让玩家**亲手用上**新解锁的能力，而不是只看到属性提升。
- 前期总时长控制在实际游玩 1–1.5 小时，配额内容要随天数变化，不能同一组任务重复二十遍。
- 阶段一到阶段四应当能在原型里连续玩通，这是第一阶段的验收标准。

## 6. 未决问题

- [ ] 三人沦为劳役的具体原因是固定剧本，还是可选的多个开局？
- [ ] 三人是否有身份差异（例如一人做过账房学徒，更容易接触情报）？
- [ ] 是否需要一小段无战斗的纯生活引导，还是直接以一场遭遇战开场？
- [ ] 代理修士是本地豪强、宗门派驻还是妖族附庸？这决定推翻他之后玩家面对的是谁。
- [ ] 被驱逐的流亡分支第一阶段是否实现，还是先只做主动掀桌这一条？
- [ ] 秘密灵地是固定位置还是随机生成？固定更容易做叙事，随机更耐玩。
