## 1. 这个系统解决什么问题

开局要在最短时间内让玩家理解三件事：我是谁、我为什么必须变强、变强之后世界会怎样重新对待我。它同时是第一阶段原型的验证载体——能把这条线连续玩通，第一阶段就算成立。

本文件定义开局系统与长期结构；具体的第一章体验节奏草案见 `2G-first-chapter-flow.md`。草案中的人物、地点、名称与事件均可修改。

## 2. 定调：先给枷锁，再给钥匙

前期不是"新手教程"，而是一段有明确压迫感的处境。玩家一开始就该感到时间和资源都不属于自己，然后亲手一点点偷回来。

**玩家不是一开始没有力量，而是没有自由。** 感应境已给了感知灵气的潜质，但时间表、每日任务与主管规则剥夺了使用这些潜质的权利。

### 2.1 前期节奏：凡人阶段不是长期玩法

**凡人／感应境劳役不是长期经营玩法。** 玩家应在约 **40 分钟～1 小时**真实游玩时间内，从感应境进入炼气期。

前期重点不是经营凡人生活，而是：

> 从被压迫的凡人，成为隐藏的修士。

| 前期分段 | 目标体验 | 节奏目标 |
|---|---|---|
| 第一阶段：凡人觉醒 | 感知世界、找功法、完成第一次炼气 | 约 40 分钟～1 小时内进入炼气 |
| 第二阶段：隐藏修士 | 敛息藏修、分工成长、准备掀桌 | 进入炼气后仍需隐藏，不可立刻公开 |

> **说明：** 早前草稿曾把劳役阶段写成约 15–30 游戏天／1–1.5 小时。本次明确：**入炼气节奏压缩到约 40 分钟～1 小时**；之后的隐藏修士阶段可以更长，直到具备对抗筑基管事的条件。

### 已确认的身份

- 三人因家贫被迫前来接受**宗门外门劳役**，开局默认都处于**感应境**：拥有修仙潜质，已经能隐约感知天地灵气，但尚未成为真正修士。
- 世界中的大多数普通人仍是真正的凡人，不能感知灵气；三名核心角色与他们存在本质区别。
- 直接管他们干活与产出的，是宗门派来的弟子（约**筑基初期**），手下有凡人监工与守卫。
- 这名管事弟子是玩家要打的**第一个卡点**：前期积累的目标是具备击败或取代他的条件。
- 管事弟子与所属宗门**不是脸谱化反派**：宗门可能压迫底层劳役，同时也保护一方、维持秩序并对抗外部威胁。玩家面对的是修仙社会结构，而不是单纯的坏人。详见 `29-karma-and-consequence.md`。

角色此时没有修为、没有居所、没有自由，每天要完成配额才有饭吃。

**官发的口粮只能让人活着，对修炼毫无益处。** 这一条从第一天就要让玩家明白，因为它是整个前期驱动力的来源。

### 心智负担约束（防过载）

前期系统很多，但**玩家同一天真正要做的决策必须很少**。做法是按进展解锁机制，而不是开局全开：

| 进展 | 玩家只需要学会 | 尚未开放 |
|---|---|---|
| 凡人觉醒前段 | 领配额、三人分工、完成交差 | 夜间出门、藏匿、贿赂 |
| 凡人觉醒后段 | 提前完工换时间；发现灵地／功法；准备第一次突破 | 复杂人情 |
| 刚入炼气 | 敛息隐藏修为；夜间偷练 + 藏匿点 | 多藏匿点 |
| 隐藏修士中后段 | 掩护分工、打听偏好、贿赂守卫 | — |
| 掀桌前 | 收集管事弟子的把柄或战力条件 | 领地经营 UI |

判定标准：任意一天，玩家主动做的**重要决定不超过约 5 次**；其余交给角色自动执行与默认预案（例如一键「三人全力赶配额」「一人修炼、一人采敛息、一人探情报」）。

## 3. 三名初始角色

玩家开局控制 **3 名角色**。三人不是完全固定的剧情人物，采用**半固定背景 + 玩家自定义**的方式。

### 3.1 半固定背景是什么意思

每名角色带有一组预设的背景要素，这些要素会**在后续剧情中真正被引用**——回故乡、遇到旧人、牵出家族关系等。但玩家保留自由修改的空间，可以按自己的想法调整。

这样既避免"三个白板没有故事"，也避免"完全固定导致玩家没有代入感"。

### 3.2 每名角色可拥有的要素

| 要素 | 作用 |
|---|---|
| 家乡 | 地图上真实存在的地点，后续可以回去，可能牵出旧识、旧债、家族 |
| 身世标签 | 出身与经历，例如破落家族、猎户之子、逃荒流民 |
| 性格标签 | 影响对话选项、NPC 反应，以及角色的自动行为倾向 |
| 天赋倾向 | 影响修炼与劳役方向，是三人分工的依据 |
| 外貌 | 玩家自定义的外观 |

### 3.3 设计要求

- 背景要素必须**产出实际内容**，不能只是角色卡上的文字。至少要有对应的地点、NPC 或事件能被触发。
- 三人的天赋倾向应互补，让"派谁去做什么"从第一天就是有意义的决定。
- 玩家修改背景后，被引用的剧情要随之改变，不能出现说辞与设定对不上的情况。

### 3.4 待设计

- 三个初始角色之间的**关系**（是同乡、亲属、路上结伴，还是互不相识）。
- 每类标签具体有哪些选项、各自会引出什么内容。
- 背景要素是完全自由填写，还是从预设池中选取。

## 4. 开局状态：感应境与神识

三名核心角色在游戏开始时就默认处于**感应境**。感应境不是游戏过程中通过事件触发或解锁的阶段。

### 4.1 感应境本身只是境界

感应境代表角色拥有修仙潜质，能感受到天地灵气并进行基础吸收（效率极低，无法形成完整修炼循环），因而可以进入正式修炼准备阶段。**它不是一种特殊视觉能力。**

### 4.2 看见普通人看不见的东西，来自神识

三人之所以能察觉环境异常，是因为**神识、天赋与经历**高于周围的普通劳役者，而不是因为"处于感应境"。规则见 `2B-attributes-and-affinity.md`。

主要体现：

- 感知环境中的灵气浓度。
- 发现隐藏资源、灵物与异常区域。
- 感知部分隐藏的修士身份或修炼痕迹。
- 感知妖气与特殊环境。
- 从开局起逐渐发现隐藏的修仙世界：同一片山林，普通凡人看到的是柴和野兽，神识敏锐者看到的是灵气浓淡、异常区域与妖兽行迹。

由于神识是所有角色共有的属性，一个神识出众的普通凡人同样可能察觉到异常——这为"某个不起眼的 NPC 其实知道很多"提供了自然解释。

### 4.3 关键限制

**感应境不能学习和运转正式功法，也不能真正运转灵力，不能使用修士能力，也不算真正修士。**

角色可以在感应境期间获得、持有第一份功法，但尚不能正式修习。通过探索、NPC 互动、宗门、商人或特殊事件获得功法，并成功按照功法运转灵气后，才正式进入**炼气期**和完整修炼体系。

炼气代表正式进入修仙体系，而不是巨大能力跃迁：感应境是"看见"，炼气是"使用"。详见 `22-realms-and-abilities.md`。

### 4.4 与开局的关系

开局阶段的信息优势来自神识：正是因为三人比周围人敏锐，玩家才能逐步找到秘密修炼地点、发现灵物、察觉某个普通 NPC 身上不寻常的气息。感应境提供的是**修炼资格的起点**，两者不要混为一谈。

**设计目标：** 玩家从游戏开始就感觉自己正在逐渐发现一个隐藏的修仙世界，而不是在某个事件后突然被系统告知"你可以修仙"。

**待设计：** 神识带来的感知范围与精度如何表达和提升；感应境的缓慢吸收能带来什么有限收益。

## 5. 前期两段核心循环

### 5.1 第一阶段：凡人觉醒

玩家控制三名初始角色。状态为感应境。

拥有：

- 感知灵气的能力（配合神识发现异常）
- 成为修士的潜力

没有：

- 正式功法运转
- 真正灵力／灵气池
- 修士战斗与世界交互能力

目标：寻找修炼机会。主要方式：

- 探索
- NPC 互动
- 发现秘密地点
- 获取功法并完成第一次突破

基础循环：

```
接受劳役任务
   ↓
完成任务（换生存与时间）
   ↓
与 NPC 交流／偷偷探索
   ↓
发现秘密地点与修炼资源
   ↓
获得功法
   ↓
主动突破进入炼气期
```

**劳役不是终点，而是获得信息与自由时间的成本。** 真正的进展发生在交流、探索与第一次突破里。

### 5.2 第二阶段：隐藏修士

玩家进入炼气后，**不能立刻公开身份。**

原因：

- 管理他们的主管是**筑基期**修士
- 炼气修士若暴露，会被轻易抓捕或镇压
- 劳役身份仍属于宗门管理对象

玩家需要：

- 继续完成明面配额，维持表面正常
- **隐藏修为**（敛息资源，见 `2F`）
- 三人分工：一人修炼、一人采集敛息／隐藏资源、一人探索与收集情报
- 积累实力与把柄，直到具备掀桌条件

### 5.3 离开荒村：高风险，不是绝对禁止

玩家**不是不能离开**起始区域，而是**离开风险很高**。

原因：

- 身份属于宗门管理劳役
- 炼气实力仍不足
- 被发现后筑基主管可以追捕
- 外界修士或其他势力可能举报

因此前期正确策略通常是：隐藏成长、就地积累，而不是立刻远走高飞。离开作为高风险选项保留，具体事件与追捕规则**待设计**。

### 5.4 时间分配仍是核心决策

- **白天**：完成宗门劳役任务。
- **晚上**：寻找机会修炼、探索、获取资源、采集敛息草等。

玩家需要在**生存、任务、隐藏成长**三者之间分配时间。完整规则见 `2F-obligation-and-concealment.md`。

## 6. 前期 NPC：任务之外的隐藏经历

**NPC 不只是任务发布器。** 前期营地里的每个人都可能藏着自己的经历、秘密与机缘。

### 6.1 例子

一个普通的砍柴人，可能年轻时是低资质修士，修炼失败后落回凡人。他没有传人，希望把自己的功法传承出去。

玩家如果只把他当作一个交任务的 NPC，就永远拿不到这份功法。

### 6.2 玩家如何发现隐藏信息

- **聊天**：反复交谈、在合适的时机问到合适的话题。
- **观察**：注意其行为、住处、随身物件中的异常。
- **神识**：感知到其身上残留的灵气痕迹、情绪波动，或看出他动作里的修炼底子。

第三条是神识在开局的直接价值：**同一个 NPC，迟钝者眼中和神识敏锐者眼中不是同一个人。** 神识提供的是信息优势，不能替代关系经营（见 `28-jianghu-relations.md`）。

### 6.3 设计要求

- 隐藏信息必须**可被玩家主动挖出来**，不能只靠随机事件推送。
- 挖掘要有成本：时间、怀疑度、或者需要先帮对方做点什么。
- 前期至少要有一个 NPC 的隐藏线索通向**功法**，作为进入炼气的可行路径之一。

**待设计：** 前期需要几个有隐藏内容的 NPC、各自的秘密类型与挖掘方式。

## 7. 五个阶段

### 阶段一：凡人觉醒（约 40 分钟～1 小时内进入炼气）

- 玩家最开始控制 **3 名感应境角色**，三人尚不是真正修士，战斗定位互补（承伤 / 远程 / 辅助）。
- 三人被迫进入某个宗门体系下接受**底层劳役**。
- 白天完成宗门管理者安排的任务；**可同时给不同角色下令，像 RTS 一样实时执行；没有每日命令次数上限。**
- 宗门口粮只能维持生存，**对修炼几乎没有帮助**。
- 本阶段不显示领地管理界面。
- 教学目标压缩：指令、时间流逝、提前完工换自由时间、用神识／探索／NPC 找到功法与秘密地点，并完成**第一次炼气突破**。

心智负担仍要控制：机制按进展分层解锁，不要第一天全开；任意一天重要决定仍不宜过多。

### 阶段二：隐藏修士（炼气后至掀桌前）

进入炼气后核心体验变为：**白天服从，晚上偷偷修炼与敛息**，在生存压力与隐藏成长之间做风险／收益选择。

关键进展：

1. 学会隐藏修为（敛息草等资源，见 `2F`）。
2. 三人分工：修炼／采集隐藏资源／探索情报。
3. 继续挖掘 NPC、把柄与战力条件，准备对抗筑基管事。

玩家仍经营明暗两条线：

- 白天照常完成劳役，维持表面正常。
- 夜间或空档潜出去修炼、打猎、采药、采集敛息资源。
- 偷来的资源需要隐藏；被发现可能被没收。
- 可安排掩护；可贿赂守卫获得夜间行动机会。

**炼气不等于可以公开。** 暴露给筑基管事仍极危险。

### 阶段三：掀桌（第一次权力转移）

积累到一定程度后，矛盾必须爆发。触发方式有两类：

- **主动**：玩家掌握把柄，凭借实力与人脉击败、取代或外交接管。（**Historical 叙事用语**；正式战略占点须 War + CaptureObjective，见 [2A](2A-factions-armies-diplomacy-and-capture.md)。）
- **被动**：暗面行动暴露，被清算或驱逐，被迫提前摊牌或流亡。

无论哪条路，结果都是玩家取得第一处破旧村庄或小型洞府的**控制权**。占领核心是夺取控制核心建筑／控制权，**不是必须杀光所有敌人**；详见 `26-territory-management.md`。

首次解锁人口分配、建设、领地资源界面，以及**修改时间表**这一关键管理权限。

### 阶段四：宗门使者的限期审查

此时宗门正在参与**正魔大战**，暂时抽不出力量处理这个偏僻小据点，但也不会永远不闻不问。玩家可以选择暂时寄人篱下，借助大宗门发展。

- 玩家掀桌后获得一段明确的**审查倒计时**，可暂时经营据点、恢复生产并准备说辞。
- 倒计时结束时，宗门派一名使者查看管事弟子的失踪与产出变化。
- 玩家可以提前打听使者的偏好，准备其喜欢的礼物并建立私人关系。
- 若使者被成功打点，可以在回宗报告中把旧管事描述为"治理恶劣、耽误产出"，把玩家描述为"虽有越矩，但接管后地方稳定、产出改善"。
- 使者的好话不是抹除事实，而是把宗门的处理从"立即追责"改成"暂时默许、继续观察或收取更高贡赋"。

审查结果由四项组成，并向玩家公开来源：

| 项目 | 正面证据 |
|---|---|
| 据点产出 | 接管后产量没有下降，最好有所提升 |
| 地方稳定 | 劳役者未逃散、妖兽与治安仍受控制 |
| 旧管事评价 | 掌握其侵吞、虐役或耽误宗门事务的证据 |
| 使者关系 | 送出其真正喜欢的礼物，或替他解决私事 |

结果分为：正式认可、限期观察、加重贡赋、回宗追查。第一阶段只需实现"限期观察"这条主线成功结果，其他结果可先写成事件文本。

这个阶段把开局学到的"打听偏好 → 准备礼物 → 利用关系"第一次用于真正改变政治后果，验证江湖关系不是背景资料。

### 阶段五：第一轮完整闭环

- 分配凡人恢复农业与基础生产。
- 一名角色留守修炼或辅助治理，其余外出探索、招募、获取资源。
- 用领地产出准备第一次重要突破。
- 通过突破获得明确改变玩法的机制能力。
- 用这个新能力击败或绕过此前无法处理的威胁，夺取第二个据点。

到这里玩家完整体验了一遍"个人修炼 → 掀桌夺权 → 关系化解追责 → 领地供养修炼 → 修炼推动扩张"的完整闭环。

## 8. 前后呼应

前期的每一样东西，后期都有对应物。这不是丢掉不用的开场关卡。

| 前期 | 后期 |
|---|---|
| 监工的每日配额 | 宗门贡献指标、对上级势力的岁贡 |
| 偷偷修炼与私藏 | 秘密洞府、暗中扩军、隐藏实力 |
| 贿赂守卫 | 收买敌方要员、外交交易 |
| 藏匿点 | 暗桩与秘密据点 |
| 三人分工掩护 | 多小队协同、佯攻与调虎离山 |
| 从砍柴人手里挖到功法 | 从隐世高人、遗迹与敌对势力处获得传承 |
| 神识察觉灵气异常 | 更高境界的神识与规则感知 |

玩家在开局学会的心智模型，后期直接复用。

## 9. 设计要求

- 阶段三之前不要暴露完整经营 UI，避免开局信息过载。
- 阶段五必须让玩家**亲手用上**新解锁的能力，而不是只看到属性提升。
- 前期总时长控制在实际游玩 1–1.5 小时，配额内容要随天数变化，不能同一组任务重复二十遍。
- 神识感知必须让玩家**看到画面上的实际变化**（能看见此前看不见的东西），不能只是一条状态文字。
- 阶段一到阶段五应当能在原型里连续玩通，这是第一阶段的验收标准。
