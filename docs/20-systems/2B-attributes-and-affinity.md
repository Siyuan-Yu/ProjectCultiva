# 角色属性与修仙成长体系

> 状态：底层规则已定方向，数值与功法内容未展开 | 优先级：P0 | 最后更新：2026-07-30
> 上级：`docs/00-project/00-overview.md`
> 关联：`22-realms-and-abilities.md`、`25-cultivation-and-breakthrough.md`、`2H-manual-system-rules.md`、`2D-manuals-arts-and-equipment.md`、`28-jianghu-relations.md`、`29-karma-and-consequence.md`
> 本章确定**底层规则**，不设计具体数值与具体功法内容。**明确不做传统五行相克。**

## 1. 这个系统解决什么问题

给所有角色一套统一的属性语言，让"为什么同一个技能在不同人手里效果不同"有明确来源，同时让成长不退化成单一等级数字。

## 2. 统一属性体系

**所有角色使用同一套属性结构**，包括：玩家、NPC、凡人、修士、敌人。

区别不是数据结构不同，而是**属性的开发程度不同**。

例如：凡人同样拥有神识、悟性、体魄，只是没有经过修炼开发，因此相关能力较弱。

这条规则的意义：凡人可以真实存在于世界中而不是另一套简化数据；一个猎户可以体魄很强却毫无修仙能力；某个看似普通的老人可能有远超常人的悟性或神识。

## 3. 属性分类

### 3.1 肉身属性

所有生命都有。影响：

- 生命值
- 体力
- 负重
- 普通战斗能力
- 劳作效率
- 抗伤能力

凡人也可以拥有较高肉身属性。例如猎户体魄强，但没有修仙能力。

### 3.2 灵魂属性

#### 神识（灵魂力量，名称暂定）

角色感知、洞察和控制精神力量的能力。所有人都有神识，修士通过修炼可以大幅提升。

**社交方面：**

高神识可以察觉他人情绪变化、判断是否说谎、发现隐藏需求、看穿部分秘密。

当神识远高于对方时，可获得更强的交流优势：更容易提升好感、更容易发现真实想法，某些情况下直接发现隐藏信息。

**但神识不能完全替代 NPC 关系系统。** 它提供的是信息优势与判断力，不是自动通关社交。关系、人情与偏好仍需按 `28-jianghu-relations.md` 经营。

**探索方面：**

感知危险、察觉妖气、发现隐藏灵物、感应特殊地点、察觉修士气息。

**战斗方面：**

提高技能控制能力、操控更复杂的法术、控制更多法宝、对抗精神类攻击。

#### 悟性

理解和学习能力。影响：

- 学习功法速度
- 学习技能速度
- 理解复杂技能
- 功法领悟
- 技能突破潜力

**高悟性不会直接替代技能熟练度。** 它加快到达熟练的过程，不等于跳过练习。

### 3.3 修仙属性

| 属性 | 定位 |
|---|---|
| 灵根 | 与某种天地能量的亲和程度。不是职业，不是固定流派，而是影响角色更适合哪种修炼方向 |
| 灵力 | **战斗资源**：释放技能、灵力护体、使用法宝、特殊能力 |
| 修为 | **成长资源**：提升境界、突破阶段 |
| 境界 | 代表**生命层次**：感应境、炼气、筑基、金丹、元婴等 |

**修为和灵力是两个不同系统**，不要混用：灵力是可消耗可恢复的战斗池，修为是长期积累的成长值。

### 3.4 社会属性

所有角色拥有：性格 Tag、背景、家乡、关系网络、声望、目标、欲望。

用于江湖系统与 NPC 互动。这也是"重要凡人可以有姓名、关系与故事"的数据基础。

### 3.5 心境

影响突破稳定性、心魔抵抗、因果承受能力，以及强大力量使用时的稳定性。与 `29-karma-and-consequence.md` 的道心／业障相接。

## 4. 灵根系统

### 4.1 不做五行相克

**不存在火克木、水克火这类关系。** 不同属性代表不同玩法和流派，而不是相克表。

### 4.2 暂定属性

- 火
- 金
- 土
- 木
- 雷
- 风
- 冰
- 毒

未来可扩展其他特殊属性。

> **待确定｜"水"属性的去留：** 早前草稿中的属性表含「水」，且 `25-cultivation-and-breakthrough.md` 的自然环境表与 `22-realms-and-abilities.md` 的内丹风格表都出现了水。本次名单改为上述八项且不含水。需要决定：水是被冰吸收，还是作为独立属性保留。在决定前，相关文档中的「水」条目暂时保留并标注本问题。

### 4.3 灵根表现为数值

示例（**仅为说明形态，不是定稿数值**）：

```
火灵根  15/30
雷灵根   7/30
```

代表该角色对火属性的亲和更高。

### 4.4 灵根的影响

| 方面 | 影响 |
|---|---|
| 修炼 | 对应属性功法修炼速度更快 |
| 技能 | 对应属性技能学习更快 |
| 威力 | 对应属性技能释放效果更强 |

### 4.5 可以跨属性学习

火灵根角色可以学习雷法，但：

- 学习速度下降
- 熟练提升慢
- 最终效果降低

玩家不应被永久锁死在单一属性路线上。

### 4.6 灵根是否可成长

灵根**基本固定**，但可通过天材地宝、特殊机缘、血脉、特殊资源提升。幅度、上限与稀有度**待确定**。

## 5. 感应境的重新定义

**感应境只是修炼境界，不是特殊视觉能力。**

感应境的能力仅限：

- 可以感受到天地灵气
- 可以进行基础吸收
- 可以进入正式修炼准备阶段

**玩家能看到隐藏信息，不来自感应境，而主要来自神识、天赋与经历。**

这条修正影响开局体验的表述：三名角色能察觉灵物、妖气、隐藏修士，是因为他们的神识与天赋高于普通凡人，而不是因为"处于感应境"这个境界本身。详见 `22-realms-and-abilities.md` 与 `20-opening-experience.md`。

## 6. 属性如何影响技能表现

同一个技能，不同角色使用效果不同。

| 属性 | 主要影响 | 举例 |
|---|---|---|
| 灵根 | 对应属性技能威力、成长速度、功法修炼效率 | 火灵根高者学火系效率高，学雷系可学但效率低 |
| 神识 | 复杂技能的**控制能力与上限** | 普通火球术单目标；高神识可控制多个火球；更高可扩大范围与数量。飞剑同理：低神识御一把，高神识御多把 |
| 悟性 | 学习速度、理解程度、技能成长效率、功法领悟 | 达到相同熟练度所需练习更少 |
| 心境 | 突破稳定性、心魔抵抗、因果承受、强大力量使用稳定性 | 心境不足时越级用力更易失控 |
| 肉身 | 生命、体力、负重、普通战斗与劳作 | 凡人猎户也可能体魄很强 |

## 7. 技能与功法的掌握程度

技能和功法拥有**独立的掌握程度**，与角色属性分开计算。

暂定档位（名称后续调整）：

```
初学 → 入门 → 小成 → 大成 → 圆满 → 化境
```

掌握程度受以下因素影响：

- 使用频率
- 修炼时间
- 悟性
- 灵根适配度

**悟性高不会直接让技能变强**，主要表现为：学习更快、达到相同熟练程度需要更少练习、更容易领悟特殊变化。

## 8. 功法系统方向

功法的主要作用：

- 提升修为获取速度
- 影响灵力恢复
- 提供成长方向
- 影响技能学习和使用

**功法不是单纯的技能列表。** 不同功法决定修士的发展路线。

角色原则上可以学习任何功法；灵根只影响学习、掌握、修炼与发挥效率，不构成属性禁学。功法影响修为积累与灵力系统，但修为和灵力仍是两个独立资源。

完整功法规则见 `2H-manual-system-rules.md`；功法与斗技、装备的边界见 `2D-manuals-arts-and-equipment.md`。

## 9. 设计原则总结

角色成长不是简单升级，而是多条轴共同决定：

| 轴 | 决定什么 |
|---|---|
| 灵根 | 方向 |
| 悟性 | 理解速度 |
| 神识 | 感知和控制 |
| 体魄 | 肉身能力 |
| 心境 | 稳定和突破 |
| 功法 | 修炼道路 |
| 技能熟练度 | 实际掌握程度 |

最终形成不同的修士流派。
