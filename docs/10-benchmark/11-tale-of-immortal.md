# 竞品拆解：鬼谷八荒（Tale of Immortal）

> 状态：初稿 | 最后更新：2026-07-29
> 用途：拆出可复用的系统结构，不是评测。所有标注 `[需验证]` 的条目请实机确认后修正。

## 1. 一句话定位

单人开放世界修仙 RPG：玩家扮演一个修仙者，在八大区域里靠**事件抉择**塑造人生、靠**横版即时战斗**证明实力，死后由后代继承部分遗产继续下一轮。

## 2. 核心循环

```
探索地图 → 触发事件/奇遇 → 获得功法·资源·关系 → 变强（境界/神通/装备）
   → 挑战更高等级区域与 BOSS → 突破境界（渡劫） → 解锁新区域
   → 老死/身死 → 后代继承 → 新一轮（继承式 Roguelite）
```

**两层循环**：
- 短循环（分钟级）：走地图 → 遇事件/遇敌 → 打一场 → 拿掉落 → 变强一点
- 长循环（小时级）：攒资源 → 突破大境界 → 世界难度台阶上移

## 3. 系统清单

| 系统 | 作用 | 关键机制 |
|---|---|---|
| 角色构建 | 差异化 build | 灵根（五行亲和）、命格、天赋、心境 |
| 功法体系 | 战斗与修炼数值来源 | 内功（被动/属性）、身法（位移）、神通（主动技）、绝技 |
| 神通词条 | 构筑深度核心 | 神通带随机/可洗练词条，可组合出质变效果 |
| 境界 | 纵向进度轴 | 炼气→筑基→金丹→元婴→化神→炼虚→合体→大乘，每境分小阶 + 渡劫 |
| 战斗 | 技巧表达 | 横版 2.5D 即时战斗，走位 + 前后摇 + 硬直打断 + 内力资源 |
| 世界 | 内容容器 | 八荒区域分级，含城镇、门派、秘境、野外妖兽 |
| 事件/奇遇 | 叙事与随机性 | 大量文本事件，选项 → 随机结果 + 因果/声望影响 |
| 关系 | 情感留存 | 好感度、道侣、双修、结拜、师徒、仇敌 |
| 传承 | 长线留存 | 后代继承部分属性/功法，形成家族史 |
| 生产 | 资源转化 | 炼丹、炼器、符箓、种植、采集 |
| 经济 | 资源汇聚 | 灵石、门派贡献、商店/拍卖 |

## 4. 它做对了什么（值得借鉴）

1. **构筑自由度 + 越级挑战**：神通词条组合让"低境界打高境界"成立。玩家的成长感来自**理解系统**，不只是数值。这是它口碑的地基。
2. **事件量堆出"人生感"**：修仙的浪漫来自遭遇的密度，不来自画面。事件是最高性价比的内容形式（纯文本 + 配置）。
3. **关系与后代闭环**：把"死亡"从惩罚变成叙事节点，天然支持 Roguelite 结构，也给重复游玩提供理由。
4. **境界作为难度闸门**：用境界同时管理进度、区域解锁、数值区间，一条轴解决三件事，非常经济。

## 5. 它的问题（我们要避开）

1. **中后期数值膨胀**：进入高境界后战斗从"技巧"退化为"数值对撞"，构筑意义下降。
2. **事件复用感强**：同一批事件在不同地区反复出现，且世界不记住玩家做过什么，抉择缺乏回响。
3. **世界反应性弱**：门派/势力基本是静态背景板，不会因玩家行为而变化。
4. **战斗成本极高**：动作手感、动画、特效是重资产。`[对个人开发者而言这是最大的坑]`
5. **后期目标感稀释**：地图跑图重复，缺乏后期的策略层目标。

## 6. 对我们的成本提示

| 部分 | 成本 | 备注 |
|---|---|---|
| 即时动作战斗 | 极高 | 动画、打击感、特效、平衡，个人开发者的死亡区 |
| 事件系统 | 低 | 配置 + 文本，可 AI 辅助批量产出 |
| 神通词条构筑 | 中 | 纯数据与规则设计，性价比最高的深度来源 |
| 开放世界地图 | 高 | 美术与内容填充量巨大 |
| 关系/传承 | 中低 | 状态机 + 数值继承，主要是设计工作 |
