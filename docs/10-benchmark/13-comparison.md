# 横向对照：两条修仙游戏路线

> 状态：初稿 | 最后更新：2026-07-29

## 1. 最本质的区别：玩家是谁

| | 鬼谷八荒 | 了不起的修仙模拟器 |
|---|---|---|
| 玩家身份 | **我是一个修仙者** | **我是宗门背后的天意** |
| 主要动词 | 走、打、选（抉择） | 建、派（调度）、等 |
| 乐趣来源 | 个人成长 + 战斗技巧 + 人生际遇 | 系统嵌套 + 布局策略 + 涌现故事 |
| 失败形态 | 战斗打不过 | 资源崩溃 / 连锁事故 |
| 内容成本大头 | 动画特效、地图美术、事件文本 | 弟子 AI、UI、配置深度 |
| 单人开发可行性 | **低**（动作手感是重资产） | **中**（美术轻、逻辑重） |

这不是"风格差异"，是两个不同的游戏。**必须先选一边**，否则所有后续设计都会摇摆。

## 2. 系统层对照

| 系统 | 鬼谷八荒的做法 | 了不起的做法 | 备注 |
|---|---|---|---|
| 进度轴 | 个人境界（练气→大乘） | 弟子境界 + 宗门规模 | 两者都用"境界"当主轴，可直接沿用 |
| 元素规则 | 灵根影响功法适配 | 五行生克贯穿全系统 | 了不起的复用度更高，更值得学 |
| 随机性 | 文本事件 + 词条随机 | 系统事件 + AI 行为 | 前者可控，后者更省内容 |
| 战斗 | 即时横版，玩家亲手打 | 自动/半自动，看结果 | 决定了美术与动画预算 |
| 死亡 | 后代传承，Roguelite | 弟子转世，宗门延续 | 两者都把死亡变成叙事资产 |
| 内容扩展 | 手写事件为主 | 配置表 + Mod | 后者更适合长期与交接 |

## 3. 两条路线的第三种可能（混合型）

存在一条中间路线，值得认真考虑：

> **以"个人修仙人生"为叙事外壳，以"系统模拟"为玩法内核，战斗采用回合/自动 + 构筑。**

- 保留鬼谷八荒的代入感和事件魅力（低成本、高感染力）
- 保留了不起的系统嵌套与配置化（低美术、高深度）
- 砍掉两者最贵的部分：即时动作手感、大规模弟子 AI 与 3D 世界

参考同类实现思路：文字/界面驱动的修仙模拟（如《修仙模拟器》类页面游戏）、带构筑的自动战斗（如《欺诈之地》《小丑牌》的构筑思维）。

我的初步建议见 `14-borrow-and-differentiate.md`。

## 4. 结论性判断

1. 两款竞品的成本大头都是**内容量**，不是系统复杂度。个人开发者必须选一个**内容可程序化/配置化生成**的方向。
2. 即时动作战斗是个人开发者最容易翻车的地方，建议直接排除，除非战斗手感就是你的核心目标。
3. 无论选哪条路，**数据驱动 + 配置表分离**都必须在第一天就定下来，否则后期无法扩展也无法交接。
