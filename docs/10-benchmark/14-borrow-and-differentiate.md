# 借鉴什么 / 做什么不一样 / 明确不做

> 状态：核心差异化已确认，细则待原型验证 | 最后更新：2026-07-30
> 这是全项目最重要的一份文档。任何后续设计与它冲突时，先改这里再改设计。

## 1. 决定借鉴（照着做，不重新发明）

| 借鉴项 | 来源 | 为什么 |
|---|---|---|
| 境界作为唯一纵向主轴 | 两者 | 一条轴同时管进度、解锁、数值区间，最经济 |
| 五行/灵根作为全局元素规则 | 修仙模拟器 | 一套规则复用到功法、丹药、克制、事件 |
| 事件驱动叙事（配置化文本） | 鬼谷八荒 | 内容性价比最高，可批量产出 |
| 词条化构筑（可组合出质变） | 鬼谷八荒 | 玩家成长感来自"理解系统"而非数值 |
| 死亡即叙事节点（传承/转世） | 两者 | 把失败变成继续玩的理由 |
| 数据与代码分离 | 修仙模拟器 | 直接服务"跨设备开发 + 交接他人" |

## 2. 决定做得不一样（我们的差异化假设）

> 每一条都是**假设**，需要在垂直切片里验证。验证结果写回本节。

### 差异化 1：抉择要有回响，世界要记得

竞品痛点：事件抉择结果只影响数值，世界不记住。
我们的做法：引入**世界状态记账（World Ledger）** —— 玩家的每个重要抉择写入一个全局状态表，后续事件的触发条件、势力态度、NPC 台词都读取它。
判定标准：玩家在 10 小时后能遇到一个明确由自己早期抉择造成的后果。

### 差异化 2：境界突破要带来“斗气化翼式”的规则质变

竞品痛点：后期变成数值对撞，构筑失效。
我们的做法：每个大境界至少解锁一种由玩家实际操作的超凡能力，例如灵力外放、护体铠甲、御物化形、飞行或神识。能力应同时影响战斗、跑图、探索或领地中的多个场景，而不是只作为任务门槛。
判定标准：玩家不看属性面板，也能仅凭可执行的操作判断角色是否已经跨入新境界；同一项境界能力至少在两个玩法场景中有用途。

### 差异化 3：后期从"操作量增长"转为"抽象层上移"

竞品痛点：后期微操疲劳（保姆化）。
我们的做法：随着规模扩大，玩家操作粒度**自动上移**（从管单个弟子 → 管制度/政策 → 管道统方向）。规模变大时操作量应下降而非上升。
判定标准：单位数量翻倍时，玩家每分钟操作次数不增加。

### 差异化 4：可读性优先，因果必须透明

竞品痛点：玩家不知道自己为什么失败。
我们的做法：所有数值与结果**必须可溯源**（悬浮即可看到完整计算链：基础值 + 来源 A + 来源 B）。这是从第一行代码就要定的架构约束，后补极贵。
判定标准：任何数字都能点开看到它的构成。

### 差异化 5：从凡人小队亲手成长为修仙势力

竞品割裂：个人修仙 RPG 通常没有真实领地经营；宗门模拟通常让玩家开局就扮演全知管理者，缺少亲手走过凡人阶段的身份连续性。
我们的做法：玩家从一至三名凡人开始，先经历生存、任务、关系和入门修炼，再取得第一个破旧村庄。此后仍保留核心角色的直接操控，同时逐步解锁人口、建设、外交与战争。玩家身份从个人自然扩展到势力，而不是在两个模式间突然切换。
判定标准：取得首个领地前后使用同一批核心角色；领地产出能帮助角色突破，突破能力又能帮助夺取第二个据点，形成完整双向闭环。

### 差异化 6：修士逐个养成；凡人四层模拟

竞品风险：把所有人口都做成完整角色会造成模拟与操作量爆炸；只做抽象军队又会失去修仙世界的真实感。
我们的做法：核心修士拥有完整属性、境界、装备、功法、技能、关系和经历，长期数量控制在约 30–50 人。世界采用四层模拟：

1. 修士：高精度实体
2. 关键 NPC：实体（商人、村长、剧情人物等）
3. 势力：战略模拟（扩张、外交、战争、资源）
4. 普通凡人：群体／统计模拟；地图用代表性群体单位表现，不逐人存档

**待确定：** 关键 NPC 涌现规则、凡人军队的参战表现方式。
判定标准：玩家走进自己的村庄时能感到这里住着人；同时领地人口增长不会让逐个操作量等比增长。

## 3. 明确不做（写下来是为了以后不反悔）

| 不做 | 原因 |
|---|---|
| 高速即时动作 / 连招型战斗 | 战斗采用 2D 暂停即时战术，核心是指挥与机制，不追求高成本动作手感 |
| 3D 开放世界 | 美术与内容填充量不可控 |
| 多人联网 | 复杂度翻倍，与单机模拟乐趣不冲突但无必要 |
| 全语音 / 大量立绘动画 | 成本线性增长，不影响核心乐趣 |
| 首发即完整八大区域 | 先做一个区域的垂直切片，验证后再扩 |
| ~~逐个模拟和控制全部凡人~~ | **已明确不做。** 普通凡人用群体统计；关键 NPC 与修士实体化 |
| 第一版同时做完整 RPG、全战与自由建造 | 先验证三人、一个村庄、两个据点和一次境界机制质变 |
